{% comment %} Wrapper for rendered markdown. Owns the reading width and the vertical rhythm between blocks, so every page that shows authored content lays it out the same. Headings get extra space above them so each one reads as the start of a new section rather than another paragraph. The first child gets none, so the container's own top edge stays where the caller put it. Props: width - "reading" (default) caps the line length for comfortable reading and centres the column. Anything that has to line up with the content (the course player footer) uses the same max-w-reading. "full" fills the parent, for content that sits alongside other full-width blocks (form questions, a grid column). class - extra classes. Usage: {{ topic.rendered_content }} {% endcomment %}
