{% load fls_base_filters %} {% comment %} Included twice in a full page: once as the first thing inside #interface-main (_base_interface.html), once directly before (_base.html). Only the first of the two to render on a given response pops the session's pending events, so an event is never emitted twice from one response -- whichever include point a page reaches first gets them, and the other renders nothing. An HTMX partial whose view records an event includes this too, so the event fires at the swap and does not wait in the session for the next full page. Each script removes itself once it has run, so htmx's history snapshot of the page (taken after scripts run) does not carry it. Without that, a Back navigation to a cached snapshot would fire the event again. {% endcomment %} {% if analytics_enabled and google_analytics_measurement_id %} {% for event in google_analytics_events %} {% endfor %} {% endif %}
