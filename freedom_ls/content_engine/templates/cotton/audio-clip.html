{% load content_tags l10n %} {% comment %} A card for one longer recording (a listening exercise, a lecture excerpt): the title in bold with an optional kind at its right, a seek bar and the elapsed and total time. Attributes: src File path of the audio file, looked up via get_file_by_path. title The visible name. Required: it names the group and the seek bar. kind Optional short label at the right of the title, set in mono, such as "Listening exercise". The slot, when given, is the transcript: markdown, shown under a Show transcript toggle that works in every state, the error state included. A slot of only whitespace renders no toggle. The panel's x-show hides it from assistive technology while collapsed. data-src holds the redirect URL, never a signed one, so playback after the signature expires still works. Each clip owns its audio element, created by the audioClip Alpine component on first play, so nothing loads with the page and two clips never share a position. The total comes from the stored duration_seconds; a file without one shows --:-- and a seek bar that stays disabled until the audio element reports its own length. Arrow keys seek by five seconds in the component, because the range's step is "any". A seek made before the audio has loaded is applied once its metadata arrives. Both time figures are hidden from screen readers, which read the seek bar's aria-valuetext instead. A missing or non-audio file, or an empty title, renders a red box naming the src instead. The status line is always in the DOM and only its text changes, so screen readers announce each change. When the audio fails to load or play, the card turns red and the seek row gives way to the status text. The play button turns red, shows the retry icon and is named "Try again: "; pressing it reloads through the redirect and plays from the saved position. When the clip ends it returns to 0:00 showing Play, dropping any seek still waiting, so the next press plays from the start. Each icon sits in a flex wrapper so no text baseline pushes it low, and the play triangle moves right a pixel to sit at its optical centre. {% endcomment %} {% with
