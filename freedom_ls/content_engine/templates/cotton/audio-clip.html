{% load content_tags l10n %} {% comment %} A card for one longer recording (a listening exercise, a lecture excerpt): the title in bold with an optional kind at its right, a seek bar and the elapsed and total time. Attributes: src File path of the audio file, looked up via get_file_by_path. title The visible name. Required: it names the group and the seek bar. kind Optional short label at the right of the title, set in mono, such as "Listening exercise". The slot, when given, is the transcript. data-src holds the redirect URL, never a signed one, so playback after the signature expires still works. Each clip owns its audio element, created by the audioClip Alpine component on first play, so nothing loads with the page and two clips never share a position. The total comes from the stored duration_seconds; a file without one shows --:-- and a seek bar that stays disabled. Both time figures are hidden from screen readers, which read the seek bar's aria-valuetext instead. A missing or non-audio file, or an empty title, renders a red box naming the src instead. The status line is always in the DOM and only its text changes, so screen readers announce each change. {% endcomment %} {% with file_obj=src|get_file_by_path:content_instance %} {% if not file_obj or file_obj.file_type != "AUDIO" %} {% elif not title %} {% else %}
