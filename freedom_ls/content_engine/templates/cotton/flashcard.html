{% load content_tags %} {% comment %} Flashcard component — a two-sided flip card for question/answer content. Attributes: size standard (default) | wide. A wide card lifts the large-screen width cap and left-aligns both faces, so an answer holding a table or a code block reads properly. An unknown size falls back to standard. Named slots: front The question / prompt face (markdown rendered). back The answer / reveal face (markdown rendered). Alpine component: `flashcard` (registered in alpine-components.js) manages flipped state, face transforms, and exposes flip() for the trigger button. Accessibility: A real {% comment %} CSS-grid single-cell stack: both faces share one grid area so the card container is sized to the larger face, not whichever renders first. The perspective is set on the parent. The track is minmax(0,1fr) rather than 1fr, and each face carries min-w-0, so neither the track nor the items inherit a min-content floor from the prose inside them. pointer-events-none goes on the stack rather than on each face: the stack is itself a box covering the whole card, so leaving it opaque would take the click meant for the trigger underneath. {% endcomment %}
{% comment %} inert removes the hidden face's subtree from tab order, pointer events, and AT — tabindex="-1" on a wrapper div does not propagate to descendant focusable elements, so inert is needed. backface-hidden is what makes each face disappear once it rotates past 90°; the -webkit- prefix carries older Safari. {% endcomment %}
{% comment %} h-full fills the face, which the grid stack sizes to whichever face is taller — without it the shorter face's content centres against its own min-height and rides high on the card. The generous vertical padding clears the absolutely-placed kicker and flip hint. {% endcomment %}
