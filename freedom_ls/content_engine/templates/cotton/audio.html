{% load content_tags %} {% comment %} A card that plays one recorded audio file: an optional symbol tile, the word in bold with its respelling under it, and a round play button at the right. Attributes: src File path of the audio file, looked up via get_file_by_path. label The visible word. Required: it is the button's accessible name. respelling Optional pronunciation guide, set in mono under the word. A syllable written in capitals among lower-case ones is the stressed one and is drawn bold in the primary colour ("no-VEM-ber"). All capitals means no stress is marked. symbol Optional short text for the tile at the left, such as the letter a word stands for. Decorative, so hidden from screen readers. While the file plays the button fills with the primary colour and shows the audio_playing icon, and the card takes the primary border. Both follow the button's aria-pressed, so no extra state is bound. data-src holds the redirect URL, never a signed one, so playback after the signature expires still works. The audio element is created by the audioFile Alpine component on first press, so nothing loads with the page. The text column and play button live in the audio_card_body partial, shared with c-audio-reveal. A missing or non-audio file, or an empty label, renders a red box naming the src instead. The respelling comes before the button in the DOM so it reads in order (word, respelling, button). Its id comes from Alpine's $id, so two widgets on the same file never share one. The status line is always in the DOM and only its text changes, so screen readers announce each failure. {% endcomment %} {% with file_obj=src|get_file_by_path:content_instance %} {% if not file_obj or file_obj.file_type != "AUDIO" %} {% elif not label %} {% else %}
