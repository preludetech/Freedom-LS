How to read this report

  • "Complete" is recomputed from progress records every time the report is generated, never read from a cached percentage — a cached value can drift from what a student has actually done.
  • A quiz score shown here is always the student's latest completed attempt, not their best or first.
  • Only completed attempts count as an attempt; an attempt started and abandoned is not counted or scored.
  • The question-level confusion tables further on analyse each student's first completed attempt at a quiz only, so a question's difficulty reflects how the cohort met it fresh, not how retries wore it down.
  • Multi-select (checkbox) scoring now requires every correct option to be selected and no incorrect one. A stored score for a checkbox question answered before this change can disagree with the wrong-answer detail shown below it; historical attempts are not rescored.
  • Activities and free-text questions carry no completion or correctness record in FLS, so they are excluded from both the completion figures and the question-level analysis.
  • This report covers only courses registered to the cohort as a whole. A course a student joined individually is not included.

Status legend

  • ✓Quiz passed, or 100% complete.

  • ▲At-risk flag raised for this student.
  • ●In progress.
  • ○Quiz attempted, but no pass mark is configured so no verdict can be given.
