Definitions and method

Complete. Recomputed from progress records every time the report is generated, never read from a cached percentage — a cached value can drift from what a learner has actually done.

Quiz score. Always the learner's latest completed attempt, not their best or first.

Attempt. Only completed attempts count; an attempt started and abandoned is neither counted nor scored.

Cohort analysis. The question-level confusion tables analyse each learner's first completed attempt at a quiz only, so a question's difficulty reflects how the cohort met it fresh, not how retries wore it down.

Multi-select scoring. Checkbox questions now require every correct option to be selected and no incorrect one. A stored score for a checkbox question answered before this change can disagree with the wrong-answer detail shown below it; historical attempts are not rescored.

Answers given. In a learner's own section, every option they ticked is listed and marked individually: ✓ an option that was correct, ✗ one that was not, ○ one the course author never marked either way. A multi-select question is scored wrong as a whole, so a learner can have ticked correct options and still have the question counted against them.

Pass marks. A quiz with no pass mark configured carries a score but no verdict — the learner sat it and the score is real, but nothing in the course says what counts as passing it.

What is excluded. Activities and free-text questions carry no completion or correctness record in FLS, so they are excluded from both the completion figures and the question-level analysis.

What is covered. Only courses registered to the cohort as a whole. A course a learner joined individually is not included.

Status legend

  • ✓Quiz passed, or 100% complete.
  • ✗Quiz failed, or not started.
  • ▲At-risk flag raised for this learner.
  • ●In progress.
  • ○Quiz attempted, but no pass mark is configured so no verdict can be given.
  • —Not applicable — never attempted, or nothing to show.

Every status carries its glyph and its number as well as its colour, so the report stays readable printed in greyscale.
