{% comment %} The one way a learner page shows a deadline: a coloured icon, the main text bold in the same colour, what was missed in the standard text colour, then the date and time in muted mono. Never a chip, border or tint. Props: tier - UPCOMING | TODAY | MISSED | CLOSED | ACCESS_ENDED. Picks the colour, the icon and the main text. word - main text that replaces the tier's own word (e.g. "Access ended"). today_word - truthy: a TODAY deadline reads "Deadline today" instead of "Deadline". closes - truthy: the label is a close date. Main text "Closes", the lock icon, and the colour of `tier`, the due tier of the deadline it sits under. It is always its own label, a separate element under that deadline's label. detail - what the deadline is for (an item or "Course"), normal text. layout - inline: one line that wraps between its parts: [icon] [main text] [detail] [date and time] stacked: the icon in its own column, aligned to the top beside the main text, and three lines: main text / detail / date and time minimal: for outline rows. The icon and the date, both in the tier colour; the main text and detail are for screen readers. Without a date the main text is shown instead. class - extra classes on the outer element. Default slot: the date and time, muted mono on inline and stacked. Callers wrap each date in whitespace-nowrap so text breaks between dates, never inside one (deadline_labels.html#date-text does this). The icon is decorative: the main text, visible or sr-only, carries the meaning. {% endcomment %} {% with date_text=slot|striptags %} {% if closes %}{% firstof word "Closes" as main_text %}{% elif tier == "MISSED" %}{% firstof word "Missed deadline" as main_text %}{% elif tier == "CLOSED" %}{% firstof word "Closed" as main_text %}{% elif tier == "ACCESS_ENDED" %}{% firstof word "Access ended" as main_text %}{% elif tier == "TODAY" and today_word %}{% firstof word "Deadline today" as main_text %}{% else %}{% firstof word "Deadline" as main_text %}{% endif %} {% if tier == "UPCOMING" %}{% firstof "text-primary" as tone %}{% elif tier == "TODAY" %}{% firstof "text-on-warning-light" as tone %}{% else %}{% firstof "text-error" as tone %}{% endif %} {% if closes or tier == "CLOSED" or tier == "ACCESS_ENDED" %}{% firstof "locked" as icon_name %}{% elif tier == "MISSED" %}{% firstof "warning" as icon_name %}{% else %}{% firstof "deadline" as icon_name %}{% endif %} {% if layout == "stacked" %}
