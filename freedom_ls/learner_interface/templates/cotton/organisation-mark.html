{% comment %} The circle that stands for an organisation: its profile logo, else its logo, else an initials monogram, else a generic icon. The mark never carries the accessible name; the name rendered beside it does, so the image is decorative and the monogram is hidden from assistive technology. A profile logo is uploaded for this circle and may be cropped to it (object-cover); a logo is usually a wordmark and must not be (object-contain). The fill is opaque so a transparent logo stays legible on any background. The circle's font size scales the monogram and the icon with it, so each size is declared once. Params: organisation — the organisation to draw size — sm (cards and rows, the default), md (the course page hero), lg (the course page organisation card) class — extra classes merged onto the circle {% endcomment %} {% if organisation.profile_logo %} {% elif organisation.logo %} {% elif organisation.initials %} {{ organisation.initials }} {% else %} {% endif %}
