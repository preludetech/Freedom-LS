{% comment %} The circle that stands for an organisation: its profile logo, else its logo, else an initials monogram, else a generic icon. The mark never carries the accessible name; the name rendered beside it does, so the image is decorative and the monogram is hidden from assistive technology. A profile logo is fitted inside the circle (object-contain): a square one fills it, and any other shape is scaled down rather than cropped. A logo is usually a wordmark, so it is fitted with a little padding. The fill is opaque so a transparent logo stays legible on any background. The circle's font size scales the monogram and the icon with it, so each size is declared once.
