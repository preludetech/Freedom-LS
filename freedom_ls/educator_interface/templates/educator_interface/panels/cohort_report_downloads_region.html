{% comment %} The downloads panel's refresh region. The polling attributes sit on the region itself and only while a report is in flight and not stalled, so a response for a ready, failed or stalled report carries no hx-trigger and polling stops. A stalled report keeps its notice and offers the generate form as well: posting it fails the stalled row and starts a fresh report. The generate form targets the same region; while its POST is in flight the submit button is disabled and shows its loading label, so a click is seen to have done something before the in-flight state arrives. A cohort over the learner limit gets the reason in place of the form and of any failed row, since a retry could only fail the same way; a report generated before it grew is still offered. {% endcomment %}
