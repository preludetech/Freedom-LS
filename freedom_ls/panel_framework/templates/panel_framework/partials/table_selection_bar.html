{% comment %} The selection bar: shown only while rows are selected or a run is going. From lg up it takes the toolbar's row above the table; below lg it is fixed to the bottom of the viewport, where it would otherwise scroll out of reach below a long card list, and the region reserves its measured height after the footer. The first four permitted non-destructive bulk actions are text buttons; the others and every destructive action (last, in error text, under a rule) sit under a "More actions" menu. Server-rendered visible so the actions work without JavaScript; the stylesheet hides it until tableSelection takes over. The bar fades with opacity classes alone: the modifier form of x-transition also sets a transform, which would make the bar the containing block of the fixed "More actions" menu while it fades. The count and link swaps inside it take no transition: a fade on an element that changes width would shift its neighbours. The left group holds the page checkbox, the count, the select-all link and the actions; Clear is a sibling of that wrapping group, so it stays alone at the right edge however the group wraps. Without JavaScript only the action buttons show: the checkbox, count, link and Clear are x-cloak, and the count is empty until tableSelection fills it. {% endcomment %}
Changing page, sort or filters clears the selection.
