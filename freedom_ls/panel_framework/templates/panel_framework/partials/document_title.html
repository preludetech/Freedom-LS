{% comment %} Browser-tab title for a panel-framework interface. Interface navigation is an out-of-band fragment swap and never reloads the page, so the tab would go stale on every move without this. htmx lifts a found at the root of a partial response out of the swapped content and applies it to document.title, which is why the element is emitted bare here rather than wrapped or marked hx-swap-oob. The `document-title` partial is the one source of the string: a hosting page template includes it inside its own {% templatetag openblock %} block head_title {% templatetag closeblock %} so a navigation cannot change the title format. Keep it on a single line — htmx copies the element's text verbatim, so indentation would show up in the tab. panel_framework passes no context for the organisation: like the announcer's message, the fragment sources it from the request, and simply drops the segment for a host that has no such concept. {% endcomment %} {% partialdef document-title %}{% if heading %}{{ heading }} — {% endif %}{% if request.organisation %}{{ request.organisation.name }} — {% endif %}{{ site_name }}{% endpartialdef %}<title>{% partial document-title %}
