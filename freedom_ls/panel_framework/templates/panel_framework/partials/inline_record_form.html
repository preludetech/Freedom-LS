{% comment %} A record's own fields, posted inline to its edit action from a Settings panel rather than a dialog. Returned by the action's GET and its 422 too. Context: form, action_url, form_id. The form holds no button: its submit is partials/inline_record_form_submit.html, which the panel renders in the card footer and which names this form with form=, so the submit works with JavaScript off and survives the form being swapped. The form points hx-indicator and hx-disabled-elt at that button by id, so the button shows its loading label and is disabled while the request runs. The form targets itself, so a 422 swaps the errors in place; a save answers 204 (or 200 with the re-rendered form) and focus returns to the first field by id. A field error is one line under the field row: the message alone, role=alert, with the id Django names in the input's aria-describedby. The form spaces its children with a flex gap, not space-y: the hidden request-error element is the last child, and sibling margins would leave 12px under the field row, where a gap is only laid out between visible children. With JavaScript off the form posts plainly, which is why it carries a method, an action and a CSRF token; the action then redirects to the page with the outcome as a flash. {% endcomment %}
