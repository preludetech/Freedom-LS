{% comment %} The swap target for sidebar and back-link navigation. Every view template extends this, so #main-content is written in exactly one place: a page header band on top (the view's heading and actions and, on a tabbed instance page, the tab row), then the canvas the panels sit on. Both run the full width of the content column and pad themselves. The two surfaces are .panel-surface and .panel-canvas in tailwind.components.css, so a theme retunes them together; the band's bottom padding is a block because a tab row at its foot brings its own. The mobile navigation toggle lives inside the page heading's row, so a page that fills in no heading (the empty path renders this template bare) draws the toggle on its own, or a phone has no way into the navigation. {% endcomment %}
