{% comment %} The footer every dialog and bottom sheet ends with. It renders its own secondary button at the left, the one that leaves without changing anything: `cancel` is its label (Cancel, Close, Keep editing). With `cancel_href` it is a link back to that page, for a dialog the server renders open because JavaScript is off; otherwise it is a button calling the Alpine method named by `cancel_click`. That is `cancel` by default, which closes without the dirty-form guard, since pressing Cancel is a deliberate choice to drop the input; `keepEditing` serves the discard prompt. `cancel_click` is always a literal in a template, never filled from context, and `cancel_href` only ever receives a URL the server built. `focus_cancel` makes the button take initial focus and `cancel_describedby` names the element describing it. The default slot holds the actions, right aligned with the primary last, and wraps onto its own row below sm when it does not fit. Sticky so it stays in view while the dialog, which is the scroll container, scrolls. {% endcomment %}
