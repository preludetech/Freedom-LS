{% comment %} An icon, drawn inline. `name` picks its body, the template panel_framework/icons/.html, which holds the paths of a 24 by 24 icon. A name with no body template raises TemplateDoesNotExist. A host adds an icon by adding a body template under that path, and replaces one the same way. A host with an icon component of its own overrides this template and forwards to it. An icon is decorative unless given an `aria_label`: without one it renders aria-hidden, so a labelled button or a link with text is read by that text alone. width and height are the icon's intrinsic size, so it stays small when the size class has no stylesheet behind it.
