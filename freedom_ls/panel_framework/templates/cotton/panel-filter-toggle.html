{% load panel_tags %} {% comment %} Filter toggle — a pressed/unpressed button for one facet filter, in a toolbar's filters slot. Attributes: label The button's visible text (required). pressed Off (default): unpressed, aria-pressed="false". On: pressed, aria-pressed="true", with a leading decorative check icon. Read through the `flag` filter, so "False", "false", "0", "none" and an empty string all count as off. Pressed differs by more than colour, since colour alone fails a colour-blind or forced-colours reader: a check icon appears, and under forced colours the pressed state switches to the Highlight/HighlightText system colours while the unpressed border switches to ButtonBorder. {% endcomment %}
