{% comment %} Filter toggle — a pressed/unpressed button for one facet filter, in a toolbar's filters slot. Attributes: label The button's visible text (required). pressed Falsy (default): unpressed, aria-pressed="false". Truthy: pressed, aria-pressed="true", with a leading decorative check icon. Pressed differs by more than colour, since colour alone fails a colour-blind or forced-colours reader: a check icon appears, and under forced colours the pressed state switches to the Highlight/HighlightText system colours while the unpressed border switches to ButtonBorder. {% endcomment %}
