{% load panel_tags %} {% comment %} A person shown as a link: the avatar chip and the name, in the row-link style every data-table name cell uses, so a learner or a staff member looks the same wherever they appear (a table row, a phone card, an attention list, a dialog). Attributes: user A user object: the name, the avatar colour and the email line come from it (see panel-avatar-chip). Given, it replaces `name`, `user_id` and `secondary`. name Display name, for a caller with no user object. user_id Picks the avatar colour slot, for a caller with no user object. secondary Email, role or reason on a second line (default none). size "md" (default, table rows) or "sm" (a list row: a small chip and a text-sm semibold name). link_class Extra classes for the link (default none), e.g. the classes that stretch it over its row. href The person's page. Without it the chip and name render as plain text, for a person with no page of their own. quick_view_url When set, a small trigger at the end edge opens that URL in the #quick-view drawer; at least 44px square below md. hx_nav On: the link navigates with HTMX into #main-content, as the data-table link cell does. Read through the `flag` filter. The `badges` slot holds the person's status badges ("You", "Inactive"). They sit on a line under the name and email, outside the link so they stay out of its accessible name, indented to the name's left edge (the avatar's width plus its gap).
