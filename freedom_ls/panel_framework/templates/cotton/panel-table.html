{% comment %} A static table in the data table's look: a visually hidden caption, the data table's header style, and a scroll region that can take keyboard focus and is named from the caption. It has no query state: no sort, filter or selection. Use for a list a user sorts, filters or selects from. Attributes: caption The table's name, for the caption and the region's label. cards Set to also render the `card_rows` slot as a card list below md and hide the table there. The slot holds rows. capped Set to cap the region's height and keep the header row in view while the rows scroll; for a block that can hold more than about ten rows. The sticky header fill is --panel-table-head (default: the surface). class Extra classes for the scroll region. Other attributes (a data-* hook, say) land on the . Slots: `head` holds the header , the default slot holds the body rows. {% endcomment %}
