{% load panel_tags %} {% comment %} Avatar chip — an initials circle beside a name, e.g. a learner row's leading element. Attributes: name Display name, and the accessible name (required). user_id Picks the colour slot, via the `avatar_slot` filter (required). initials Overrides the initials derived from `name` (default none: derive from the first and last words, uppercased; one word gives one letter, an empty name gives none). secondary Email or role, second line, text-muted (default none). size "md" (default, list rows) or "lg" (profile header). name_hidden Falsy (default). Truthy: the name and second line are not rendered, for a caller that shows the name itself (the attention row's subject link, so the row keeps one visible subject rather than two). The initials circle is aria-hidden; the name carries the accessible name. Six colour slots, not the course accent slots theme.css reserves for course branding: `success`, `warning` and `error` are left out so no avatar can be mistaken for a status. Each is a `color-mix` of a role token into `--color-surface` at 22% or 42%, chosen so the mix stays light enough for `text-on-surface` (near-black in both shipped themes) to clear 4.5:1 against it. A theme recolours the set by redefining these properties or shadowing this component. {% endcomment %}
