{% load panel_tags %} {% comment %} Stat tile — a
holding one counted figure. Attributes: label What is counted. Renders as
, first in source so the definition list stays valid; CSS puts it under the value. value The figure. Renders as
, first on screen. sub Plain sub-line under the value (default none). delta Delta text, e.g. "Up 4 points" (default none: no delta line). direction "up" or "down" picks the decorative trend icon next to delta; anything else (including "flat") renders no icon. This is the fact, independent of tone. tone Colour of the delta line (default muted). Independent of direction: a tile can report an "up" delta in a warning tone. variant "boxed" (default): bordered bg-surface card. Anything else: no card, for a tile sitting inside an already-bordered container. href A URL. The whole tile becomes one link to it, with `attrs` (an `aria-label`, a `data-*` hook) landing on the link. The link is at least 44px tall. error Truthy draws the tile's border and text in the error colour, for a count of failures. selected Truthy marks the linked tile as the current choice: `aria-current="true"` and a ring. Needs `href`. The named slot `value_content` replaces `value` with markup, such as a link or a skeleton (default none: `value` renders as text). The default slot renders under the value, e.g. a progress bar embedded in the tile. {% endcomment %} {% if href %}{% endif %}
