{% comment %} Toolbar — the row above a table holding its search and filters, with a second row below md. Attributes: layout "row" (default): from md the search, filters and actions share one bordered, padded row; below md that row gives way to the mobile row. "reserve": no controls, but from lg the row keeps the height and rule of "row", so something that replaces the toolbar does not move the content below. "none": a bare wrapper. bound_class An Alpine expression bound to the wrapper's class (default none). sheet_key Makes the mobile row an Alpine sidePanel, so a button in it can open the dialog it holds. The key is the sidePanel's storage key. Default none: a plain row. Named slots: search (a form, the first child of the row), filters and actions (both shown from md up, the actions pushed to the end by their own ml-auto) and mobile (the row shown below md, skipped when empty or whitespace-only).
