{% comment %} Toolbar — the row above a list or table holding its search, filters and actions, plus the chips naming which filters are applied. Attributes: clear_all_href Set only when a filter is applied: renders a "Clear all" link after the applied chips (default none). Named slots: search, filters, actions (each skipped when empty or whitespace-only) and applied. The root is a plain
, not role="toolbar": these are ordinary form controls, not a widget that manages its own keyboard navigation. From md the search, filters and actions share one row, with the actions right-aligned; below md the search takes the full width, since the flex-col layout stretches its block-level children. Usage: Export {% endcomment %}
