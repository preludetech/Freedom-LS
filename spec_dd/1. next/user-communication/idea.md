We need to handle communication with users in a few different places.

Standard notifications is one. We need to be able to tell people different things about their own activities at different points in time. For example, if somebody applies for a thing and then their application is approved or rejected.

We also need to communicate with learners. learners need to communicate with each other and with educators, etc.  the communication between learners and educators should be available within the educator interface. Educators should be able to open up a quick view panel for a specific learner in order to communicate with them.

we will need to be able to do some different things in order to display messages to the end user so for example a notification bell on the header bar that we are seeing an inbox in the right places. One task here is design work. I will be using Claude design for that work. So we'll just need to spec out or describe what Claude design needs to implement so that we can see how to do it.
