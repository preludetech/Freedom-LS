Learners can have public profiles. This is primarily to help them find work.

For learners we need:
(should we use the panels framework for the user-profile and these settings?)
- profile pics
- allow them to turn their public profile on/off
- allow "public profile" to be named something else in concrete implementations. This is a Site setting. Eg "Talent Database"
- allow schools to upload certificates
- allow learners to upload certificates
- work experience list
- "open to work" flag
- location and "willing to move"
- blurb
- social media urls

External:
- index page:
    list people, sort, filter
- individual profile pages per person

Permissions
Different concrete implementations will allow different people access to the profiles.
Eg: in one implementation, the "talent database" can only be accessed by hiring companies.

That said, the learner should be able to share their own profile whenever they need to. So only the list page should be restricted.
