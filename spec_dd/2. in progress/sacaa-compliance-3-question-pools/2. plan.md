# Plan: question pools, drawing N questions per attempt

Spec: `1. spec.md` in this directory.

## What already exists

The served paper already carries the draw's whole downstream. This plan changes what
`build_served_paper` writes and adds the author-facing plumbing. It rebuilds nothing below:

- `freedom_ls/form_engine/served_paper.py`: `new_seed()` (tests patch it), `_scope_rng(seed, scope)`
  (one generator per scope), `shuffle_units(children)` (a run of one group is one unit, every other
  child its own unit), `_served_children(page, form, seed)`, `build_served_paper(form)`,
  `ensure_served_paper(form_progress)` (written once per sitting; a retake is a new `FormProgress`

  never reaches scoring (`FormProgress._quiz_questions`, `compute_quiz_scores`), the results page

  `get_incorrect_quiz_answers`, paging counts (`form_engine/paging.py` `answered_counts`),
  navigation, resume or reports (`reports/indexes.py` `build_sat_questions`, which pairs a sitting
  only with `served_child_ids`).
- Answer guards: `form_engine/page_flow.py` `submit_page` saves only `current.questions`, the
  served questions of the current page; `form_engine/views.py` `_owned_file_question` 404s a
  question `sitting_path(...).has_question` refuses.
- `freedom_ls/form_engine/factories.py`: `served_paper_of(...)` and `seed_serving(form, wanted)`
  (finds a seed whose paper satisfies a predicate; never hard-code a seed).
- `freedom_ls/content_engine/validate.py`: `_form_pages`, `_PageSections.children`,
  `_form_error`, `_target_label`, `_shuffle_error`, `_split_group_errors`,
  `_first_member_of_each_group`, `validate_form_shuffle`, and the `validate()` chain.
  `validate_form_conditions` already rejects `when` on any QUIZ form.
- `freedom_ls/form_engine/schema.py`: `_reject_bare_sections` and `Condition._literal_as_str` are
  the precedent for a `mode="before"` guard. A `mode="before"` field validator only runs when the
  key is present, so an explicit `None` there means a bare key.
- `content_save.py` `save_form_page` already passes `condition_option` explicitly because
  `save_with_uuid` dumps with `exclude_none=True`.
- `freedom_ls/tests/demo_content_fixtures.py::loaded_demo_content`, and the shuffled demo tests
  `freedom_ls/content_engine/tests/demo_content/test_shuffled_quiz.py` and

**The draw** (`freedom_ls/form_engine/served_paper.py`):

```python
def _drawn_units[T](units: list[T], page: FormPage, seed: int) -> list[T]:
    """The units a sitting is served from the page, in authored order.

    The draw has its own generator, so turning a shuffle knob on or off, or
    editing another page, leaves the drawn set unchanged for the same seed.
    Sorting the picked indices keeps authored order; the page shuffle, when
    it is on, reorders afterwards. A draw above the unit count serves every
    unit rather than refusing the sitting.
    """
    if page.draw is None:
        return units
    rng = _scope_rng(seed, f"draw:{page.id}")
    picked = sorted(rng.sample(range(len(units)), min(page.draw, len(units))))
    return [units[index] for index in picked]


def _served_children(page: FormPage, form: Form, seed: int) -> list[FormChild]:
    units = _drawn_units(shuffle_units(page.children()), page, seed)
    if form.shuffle_questions:
        _scope_rng(seed, f"page:{page.id}").shuffle(units)
    return [child for unit in units for child in unit]
```

A page with no draw creates no draw RNG. `build_served_paper` already emits `options` only for
served children, so undrawn questions get no options entry. Update its seed comment:

```python
# The seed drives the one-time draw and shuffle when the paper is written.
# `random.sample` and `random.shuffle` output is not stable across Python
# versions, so nothing rebuilds a paper from it; the stored lists are the record.
```

### Slice 2: a bare, boolean or decimal `draw` is a schema error

Behaviour: `draw:` with no value, `draw: true` and `draw: 2.0` fail to parse, each with a message
that says what to write, instead of silently meaning "no draw" or 1 or 2.

**Builds on:** slice 1

**Touches:** freedom_ls/form_engine/schema.py, freedom_ls/form_engine/tests/test_schema.py

On `FormPage`, beside the `draw` field:

```python
@field_validator("draw", mode="before")
@classmethod
def _draw_is_a_whole_number(cls, value: object) -> object:
    # Runs only when the key is present, so None here is a bare `draw:`,
    # which would otherwise switch the draw off without saying so. YAML reads
    # `true` as a bool and `2.0` as a float, and lax int parsing accepts both.
    if value is None:
        raise ValueError(
            "draw: has no value. Write the number of questions or groups to draw, "
            "or remove the key to serve them all."
        )
    if isinstance(value, bool | float):
        raise ValueError(
            "draw must be a whole number of questions or groups, such as draw: 5."
        )
    return value
```

**Tests** (`form_engine/tests/test_schema.py`, parametrized): bare key, `true`, `false`, `2.0`
and `2.5` each fail with the guard's message; a page with no `draw` key still parses with
`draw is None`.

### Slice 3: `content_validate` reports every draw error in one run

Behaviour: a new pass, `validate_form_draw`, runs after `validate_form_shuffle` and reports the
four rules in the spec's validator table under the header `"Invalid draw"`. The split-group and

page that predicate flags.

**Builds on:** slice 1

**Touches:** freedom_ls/content_engine/validate.py, freedom_ls/content_engine/tests/test_validate.py

**Shared predicate.** Extract the group-layout checks from `validate_form_shuffle`:

```python
def _group_layout_errors(form_pages: _FormPages) -> list[list[str]]:
    """Per page, in page order, the errors that make its groups malformed: a
    group split by another child, or a group used on an earlier page.

    Units are formed from consecutive runs of one group, so a page with any of
    these has no well-formed units. Returns exactly one list per page, empty
    for a page with no FORM_PAGE section and for every page of a non-QUIZ
    form, since only QUIZ forms group.
    """
```

It holds the `first_page_of_group` dict and the `_split_group_errors` and cross-page loop that
`validate_form_shuffle` runs today, unchanged. `validate_form_shuffle` calls it once per form and,
inside its per-page loop, extends `errors` with that page's list at the point where it calls
`_split_group_errors` today, so its error order and every existing shuffle test stay the same.

**Units.** The validator forms units itself (it is Django-free and never imports
`served_paper`), with the same rule as `shuffle_units`:

```python
def _shuffle_units(
    children: list[tuple[_FormChildSection, str]],
) -> list[list[tuple[_FormChildSection, str]]]:
    """A run of children sharing a group is one unit; every other child is its own."""
    units: list[list[tuple[_FormChildSection, str]]] = []
    for group, run in itertools.groupby(children, key=lambda c: c[0].group):
        members = list(run)
        units.extend([members] if group else [[member] for member in members])
    return units
```

**The pass.**

```python
def _draw_error(
    item: _FormSection, label: str, problem: str, fix: str, field: str
) -> str:
    return _form_error(
        item.file_path, label, problem, fix, field=field, header="Invalid draw"
    )


def validate_form_draw(all_parsed: Sequence[BaseBaseContentModel]) -> list[str]:
    """Check each drawing page against its form's strategy and its units.

    Every error is reported, never just the first. A page whose groups are
    malformed is skipped: the shuffle pass reports it, and its units cannot
    be counted.
    """
    errors: list[str] = []
    for form_pages in _form_pages(all_parsed):
        form = form_pages.form
        layout = _group_layout_errors(form_pages)
        for page, page_layout_errors in zip(form_pages.pages, layout, strict=True):
            if page.page is None or page.page.draw is None or page_layout_errors:
                continue
            errors.extend(_page_draw_errors(page, form))
    return errors
```

`_draw_error` takes the same arguments as its sibling `_shuffle_error`. Widen `_form_error`'s
docstring so it also names a bad draw.

`_page_draw_errors(page: _PageSections, form: Form) -> list[str]` forms the page's units with
`_shuffle_units(page.children)` and returns, in this order:

1. Non-QUIZ form: the table's first message, target `_target_label(page.page, 0)`, field `draw`;
   return straight away, since the other rules only apply to QUIZ pages.
2. `draw > len(units)`: the second message with `<N>` and `<M>`; target the page label, field
   `draw`.
3. One error per unit holding no `FormQuestion` (a loose `FormContent`, or a group of content
   only): the third message, `<unit label>` and target the unit's first child label, field
   `group`.
4. Among the units that hold at least one question, the first whose question count differs from
   the first unit's: the fourth message naming both units by their first child's label and both
   counts; target the page label, field `draw`. One error per page. Units with no question are
   left out here because rule 3 already names them.

Questions per unit count `FormQuestion` children only. Use the problem and fix text from the
spec's table verbatim.

Add to `validate()`, straight after the `validate_form_shuffle` loop:

```python
for message in validate_form_draw(all_parsed):
    failed_files.append((path, message))
```

**The count** (`freedom_ls/form_engine/queries.py`, beside `count_form_questions`, which stays for
the QA seed commands):

```python
@dataclass(frozen=True)
class DrawingPageCounts:
    drawn_unit_count: int
    unit_count: int
    questions_per_unit: int
    units_are_groups: bool

    @property
    def drawn_question_count(self) -> int:
        return self.drawn_unit_count * self.questions_per_unit


def drawing_page_counts(page: FormPage) -> DrawingPageCounts | None:
    """What one sitting draws from the page, or None when the page has no draw.

    Questions per unit are read off the first unit: every unit of a drawing
    page holds the same number once the content validator accepts it.
    """
    if page.draw is None:
        return None
    units = shuffle_units(page.children())
    questions_per_unit = (
        sum(isinstance(child, FormQuestion) for child in units[0]) if units else 0
    )
    return DrawingPageCounts(
        drawn_unit_count=min(page.draw, len(units)),
        unit_count=len(units),
        questions_per_unit=questions_per_unit,
        units_are_groups=any(child.group for unit in units for child in unit),
    )


def count_sitting_questions(form: Form) -> int:
    """How many questions one sitting of the form is served.

    A drawing page counts only what it draws, so the number never reveals
    how many questions the page draws from.
    """
    load_form_tree(form)
    total = 0
    for page in form.pages.all():
        counts = drawing_page_counts(page)
        total += (
            len(page_questions(page)) if counts is None else counts.drawn_question_count
        )
    return total
```

```python
@property
def summary(self) -> str:
    """One line saying what a sitting draws from the page."""
    if not self.units_are_groups:
        return ngettext(
            "Draws %(drawn)d of %(total)d question per attempt",
            "Draws %(drawn)d of %(total)d questions per attempt",
            self.unit_count,
        ) % {"drawn": self.drawn_unit_count, "total": self.unit_count}
    groups = ngettext(
        "Draws %(drawn)d of %(total)d group",
        "Draws %(drawn)d of %(total)d groups",
        self.unit_count,
    ) % {"drawn": self.drawn_unit_count, "total": self.unit_count}
    questions = ngettext(
        "%(count)d question", "%(count)d questions", self.drawn_question_count
    ) % {"count": self.drawn_question_count}
    return f"{groups} ({questions}) per attempt"
```
