# Frontend QA: question pools, drawing N questions per attempt

A QUIZ page with `draw: N` serves each sitting N of its questions or groups, drawn at random when
the sitting starts and fixed for that sitting. The learner sees only the drawn questions, and no
count anywhere tells them how many the page draws from. The educator content preview says what
each drawing page draws. Quizzes without `draw` look and behave as before.

## Setup

- Start the server: `uv run python manage.py runserver $PORT`
- Base URL: `http://127.0.0.1:$PORT`
- Admin login: `demodev@email.com` / `demodev@email.com`
- The educator interface is at `/educator/`. The Django admin is at `/admin/`; form progress
  records (with their `served_paper`) are under Form engine.

### Data needed

Ask the data helper for these. Each learner needs a password you are given.

1. **Demo content loaded**, including the new course "Functionality Demo - question pools"
   (`demo_content/functionality_demo_question_pools/`), through `content_save` on `demo_content`.
2. **Two learners**, learner A and learner B, registered on the question-pools course and on
   "Functionality Demo - shuffled quiz", neither of whom has started either quiz.
3. **The admin user can see the question-pools course in the educator interface** (staff on its
   site, as for the other demo courses).

Before starting, open the files in `demo_content/functionality_demo_question_pools/01. quiz/` and
note: each page's title and `draw` value, every question's text on the page of single questions,
and each group's content passage and its questions on the page of groups. Work out the per-sitting
count: page 1's `draw`, plus page 2's `draw` times the questions in one group (7 with the planned
values), and the pool total (14 with the planned values).

## Test 1: the start screen counts the questions a sitting is served

1. Log in as learner A. Open the question-pools course and click into its quiz, stopping on the
   start screen.

Expect:

- The question chip shows the per-sitting count (7), not the pool total (14).
- The page chip shows the number of pages in the quiz files (2).
- Nothing on the screen mentions a pool, a draw, or a larger number of questions.

## Test 2: a sitting serves exactly the drawn questions

1. As learner A, start the quiz. On each page, write down the page title, every question's text
   in order, and every content passage.
2. Move through both pages with Next, answering every question (get at least one wrong on
   purpose on each page).

Expect:

- The page of single questions shows exactly its `draw` value of questions (3), each one from that
  page's file.
- The page of groups shows exactly its `draw` value of groups (2). Each group is whole: its
  passage comes first, then both of its questions, with nothing between them.
- Questions are numbered 1 to 7 across the sitting, with no gaps or repeats.
- The "N of M answered" count, where shown, has M equal to 7.
- The page indicator reads "1 of 2" and "2 of 2".
- No console errors.

## Test 3: the drawn set survives reload, back, page jumps and resume

Start a fresh sitting as learner B (or, as learner A, before finishing Test 2).

1. On the second page, reload.
2. Click Previous, then Next; use the browser Back button once, then Forward.
3. If page jump links show, click the first page, then the last.
4. Answer a question, leave the quiz for the course page, come back and resume.

Expect after each step: the same questions and passages on each page, the same numbers, and the
saved answer still selected on resume.

## Test 4: results show drawn questions only

1. As learner A, finish the sitting from Test 2. Look at the results page.

Expect:

- The score is out of 7. Count the wrong answers yourself and check the score matches.
- Each wrong answer card names a question learner A was served, labelled with the number it had in
  the sitting. No question learner A was not served appears.
- No notice says the score is outdated.
- Nothing mentions the pool size.

## Test 5: a retake draws afresh, and another learner gets their own draw

1. As learner A, start a new attempt if the course allows a retake. Write down the questions on
   each page.
2. As learner B, start the quiz (if not already done in Test 3) and write down the questions.

Expect:

- At least one of the retake and learner B's sitting serves a different set of questions on at
  least one page from learner A's first sitting. (With 3 of 6 and 2 of 4 drawn, an identical draw
  on both pages is unlikely; if all three match, start one more sitting and compare.)
- Every sitting has the same number of questions per page, and the start screen and results show 7
  each time.
- Finishing the retake shows a score out of 7.
- In `/admin/`, the two sittings' `served_paper` page children lists differ in at least one page
  and have equal length per page.

## Test 6: a forged answer for an undrawn question is not stored

1. As learner B mid-sitting, on the page of single questions, note a question from the page's file
   that is not shown.
2. Using the browser dev tools, add a hidden input to the page form named as the shown questions'
   inputs are, but with the undrawn question's id (find the id in `/admin/` under Form engine →
   Form questions), with a valid option value. Submit the page.
3. In `/admin/`, open learner B's question answers for this sitting.

Expect: the page submits normally (or shows the usual required-answer message), and no answer is
stored for the undrawn question. The results page after finishing does not list it.

## Test 7: the educator preview says what each page draws

1. Log in as the admin. Go to `/educator/`, open the question-pools course and its content
   outline.
2. Use the Preview action on the quiz row (the start page).
3. Use the Preview action on each of the quiz's page rows.

Expect:

- The quiz start page preview shows the question chip with 7, and the page chip with 2.
- The page of single questions shows, under its heading, the line "Draws 3 of 6 questions per
  attempt" (with the file's values), and lists all 6 questions with the answer key.
- The page of groups shows "Draws 2 of 4 groups (4 questions) per attempt" and lists all 4 groups.
- The preview opens and closes as before; no console errors.

## Test 8: quizzes without a draw are unchanged

1. As the admin, preview a page of the "Functionality Demo - shuffled quiz" quiz in the educator
   outline.
2. As learner B, open that quiz's start screen.

Expect:

- No "Draws …" line in the preview; the question chip counts every question in the quiz files.
- The learner start screen question count equals every question in the quiz files.
- Sitting it serves every question on every page, as before.

## Test 9: layout at each viewport

Repeat the page of groups from Test 2, the results page, and the educator preview of the page of
groups at 1920×1080, 768×1024 and 375×812.

Expect: the content passage and its questions fit the column with no horizontal scroll; the
"Draws …" line wraps cleanly under the page heading and does not overlap the condition line or the
first child.
