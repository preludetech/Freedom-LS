# Frontend QA: learner interface deadlines

Every learner-facing deadline now carries a deadline tier (`UPCOMING`, `TODAY`, `MISSED`,
`CLOSED`) shown as a tier-coloured icon and text: never a chip, band, border or tinted box. Every
deadline, "Access ended" included, renders through one component, `<c-deadline-label>`, so every
surface looks the same. The
dashboard card's deadline is its last line, below the progress bar, with Details at the right;
the course row puts it at its bottom after a thin divider. The course player's outline header
shows a plain-text outline deadline under the progress bar, outline rows carry their date on the
row's own line at the right, and the current item's deadline sits on a header deadline line above
the item title. The closed-item page shows a large centred lock icon with its text under it. The
"Closed" deadline on the dashboard card now names the item.

Tier colours, on the icon and the bold main text: `UPCOMING` the primary colour (`text-primary`);
`TODAY` the warning text colour (`text-on-warning-light`); `MISSED`, `CLOSED` and "Access ended"
the error colour (`text-error`). What was missed and the date are normal text in the standard
text colour (`text-on-surface`), never muted. There are no separator dots between the parts. No
deadline surface has a `-light` background.

Layouts: the card and row bottom line and the outline deadline are *stacked*: the icon in its own
column, vertically centred on the block, beside three lines (bold main text / what was missed /
date). The header deadline line is *inline*: icon, bold main text, then the date on one line that
wraps between parts. Outline rows are *minimal*: the icon and the short date, both bold in the
tier colour, with the main text sr-only.

This run covers:
- the card deadline line for every tier, missed beating next, "Closes", "Access ends", "Access
  ended" and the no-deadline cases, and the course row's bottom line
- the outline deadline for every tier, the time limit end as "Course", HTMX Previous/Next
- outline rows: the minimal label (icon and date) on the row line, truncation at 375px, completed and part rows, no
  deadline information at all in the course detail outline, sequential lock
- the header deadline line on topic pages, form pages and the closed-item page, and the
  closed-item page's icon and text
- the `mark_overdue` switch, the site-zone "Today" boundary, short and full dates in the
  browser's zone
- the dashboard's course row, the all-courses page, the course finish page, the results page under
  `nothing`, the exam runner, and the accessibility tree
- the ways it could go wrong: deadline text in the card hero, the organisation byline moved, a
  chip or tint around a deadline, a long title squeezing a date, "Due" / "Overdue" copy, an icon
  announced by its semantic name, a year missing from a date in another year

**Wording.** Learner pages say "Deadline", "Deadline today", "Missed deadline", "Closed",
"Closes", "Access ends" and "Access ended". If "Due", "Overdue", "was due", "Next deadline:"
(with a colon) or "Expired" shows on a learner page, that is a bug. Every tier carries visible or
sr-only text beside its icon, never colour alone.

Substitute the literal port number chosen by `.claude/ds/scripts/find_available_port.sh` wherever
this document writes `$PORT`. Shell variables do not survive between tool calls.

The site zone for this run is `Africa/Johannesburg` (UTC+2, no DST). An end-of-day deadline is
21:59:59 UTC. The browser is set to the same zone. The browser prints full dates as
"Jan 31, 2024, 11:59 PM" and short dates as "Jan 31, 2024" (another year) or "Mar 2" (this year).
A deadline with a set time adds its time to the short date ("Mar 2, 5:00 PM", "Today, 11:59 PM").
The browser may print a two-digit hour ("05:00 PM"); that is not a bug. "Today" is the date of the
run in that zone.

Design screenshots are under
`spec_dd/2. in progress/design_learner-interface-deadlines/design_screenshots/`. They are a
visual reference: compare layout and hierarchy, not colours, fonts, icons or copy. Where a design
draws a pill or chip around a deadline (`hero__hero-c`, `mobile__m-toc`), the build draws icon and
text instead; that is expected.

## Regressions that must never come back

Check these on every screenshot in this run. Any one failing is a bug.

- [ ] A dashboard card's hero (`[data-testid="course-card-hero"]` or the coloured block) contains
      only the course icon: no deadline text, word, date or strip inside it or along its bottom
      edge.
- [ ] The organisation byline (`[data-testid="organisation-byline"]`) straddles the hero's bottom
      edge as on main, avatar overlapping the edge and the name beside it.
- [ ] No `.chip` element inside any deadline surface: the card and row bottom line
      (`course-deadline-line`), `outline-deadline`, the outline row dates and
      `player-item-deadline`. Check with `document.querySelectorAll` in the browser.
- [ ] `[data-testid="outline-deadline"]` has no border and no background (computed
      `border-width` 0 and `background-color` transparent).
- [ ] On a card and on a row the deadline block (the deadline, then "Access ends" when it applies)
      is the last line, below the progress bar.
- [ ] "Access ends" is a stacked `[data-testid="deadline-label"]` like the deadline above it: icon
      in its own column, bold "Access ends", the date under it. Never a plain or muted text line.
- [ ] The course detail page's outline (`/courses/<slug>/detail/`) shows no deadline information
      on any row, closed rows included: no date, no visible "Closed", no lock or tier icon at the
      row's right, no `[data-testid="outline-row-date"]` or `[data-testid="deadline-label"]`.
- [ ] The closed-item page has no callout box.
- [ ] The header deadline line has visible space above it and below it, before the item title.
- [ ] No deadline surface shows a "·" separator, and no deadline date is in the muted colour. An
      upcoming deadline's icon and main text are in the primary colour, never grey.
- [ ] On a stacked label (card, row, outline deadline, "Access ended") the icon sits in its own
      column, vertically centred on the whole block, and the title wraps rather than being cut off.
- [ ] No deadline is hand-built: every one is a `[data-testid="deadline-label"]` element (see 5.2).
- [ ] The card line, the outline deadline, the outline rows and the header line look like the same
      component: the same icon colour for a tier, the same bold main text in that colour, the same
      date colour (the standard text colour; on outline rows the date takes the tier colour, as
      the minimal layout does).
