# Frontend QA: educator interface looks good

Browser checks for the restyled educator interface and the shared panel framework templates under
it. The restyle changes no behaviour, so every test pairs a look check against the design
screenshot with a behaviour check that what was there before still works. Tests marked **desktop**
run at 1442 wide; tests marked **phone** run at 392 wide; where it matters, 768 (the `md`
breakpoint) is named too. The design screenshots are a visual reference only: compare layout,
order, hierarchy and density, never colour, font or icon glyphs, which come from the FLS theme.

## 0. Setup

1. Pick a port and start the server:

   ```
   PORT=$(.claude/ds/scripts/find_available_port.sh)
   uv run python manage.py runserver $PORT
   ```

   The base URL is `http://127.0.0.1:$PORT`.

2. Seed data. The `DemoDev` site and the `demodev` organisation exist in the dev database. Ask the
   `fls-dev:qa-data-helper` agent for:

   - a second organisation (`QA Second Org`) that `demodev@email.com` can reach, so the
     organisation switcher is a dropdown;
   - a cohort `QA Looks Cohort` in `demodev` with 30 learners (so the learners table pages at 25)
     and one course registration, for example
     `uv run python manage.py qa_create_large_cohort DemoDev --cohort-name "QA Looks Cohort" --num-learners 30`;
   - one learner in that cohort with a long email address (40+ characters) and a long first name,
     for the overflow checks.

3. Log in at `http://127.0.0.1:$PORT/accounts/login/` as `demodev@email.com` /
   `demodev@email.com`.

4. Open `http://127.0.0.1:$PORT/educator/`. You are redirected to `/educator/demodev/dashboard`.
   Below, `ORG` stands for `demodev`.

## 1. Desktop left navigation (desktop)

Design: `design_screenshots/sidebar__264.png`.

1. Go to `/educator/ORG/learners`.
2. Check against the design checklist:
   - [ ] "Organisation" label sits above the switcher in small caps
   - [ ] the switcher is a bordered rounded box showing the current organisation name with a chevron
   - [ ] "Teaching" heading precedes the four nav items
   - [ ] each nav item shows an icon then its label; the active item (Learners) is tinted and bold,
         with no left border bar

   `/educator/ORG/cohorts`, and the tint to move to Cohorts.

   and bold, and the expand/collapse control beside "Cohorts" to toggle it.
5. Click the organisation switcher. Expect a list with `demodev` checked and `QA Second Org`
   unchecked. Pick `QA Second Org`. Expect the switcher label to change, the URL to carry the new
   slug, and the content to show that organisation's cohorts list.
6. Keyboard: Tab through the sidebar. Expect a visible focus ring on the switcher, every nav link
   and the expand control. Open the switcher with Enter and move with the arrow keys.
7. Shrink the window to 1024 wide. Expect the sidebar still docked and nothing overflowing its
   column (no horizontal scrollbar on the sidebar).

## 8. Cross-cutting checks

1. Dark mode (set the OS or browser to dark). Repeat the look checks of tests 1, 3 and 7 at a
   glance. Expect every surface, tint and text to come from the theme (no white flashes, no
   unreadable muted text on the sidebar, table header or sheet).
2. Contrast: with the browser's accessibility inspector, sample the small-caps labels
   ("Organisation", "Teaching", table header, definition labels), the muted secondary line in a
   mobile row, and "Page X of Y". Expect at least 4.5:1 against their background in both modes.
3. Hit areas: on the phone, measure the navigation toggle, the sheet close control, the expand
   control beside "Cohorts" and the dialog close control. Expect each at least 24 px square
   (toggle and close controls 44 px or more).
4. Focus: Tab through the learners page on desktop and the phone with the sheet open. Expect a
   visible focus ring on every control, and no sticky header or footer covering the focused
   element. Inside the sort sheet, Tab from Reset to the last option and on to Cancel and "Show
   results" without leaving the sheet.
5. Reduced motion: with `prefers-reduced-motion: reduce`, open the navigation sheet and the create
   cohort dialog on the phone. Expect them to appear without a slide and close without one.
6. Learner interface untouched: as a learner, open the course list, a course page and the player
   at both widths. Expect no visual change except the course outline toggle now sitting at the
   left of the player's top row. The notifications list pagination (base `c-pagination`) shows the
   smaller buttons; its Previous/Next still page.
7. Panel framework reference page: open `/panel-framework/components/`. Expect every component
   example to render with no layout breakage.
8. Console: on every page visited above, expect no JavaScript errors or Alpine warnings in the
   browser console.
