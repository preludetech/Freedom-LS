## Shared format rules (server and browser must agree)

Both the template filters (slice 3) and the Alpine helpers (slice 3) implement these, so the server-rendered text and the browser-updated text never disagree:

- `clip_time(seconds, total)`: floor both. If `total` is `None` → elapsed in `m:ss`. If `total >= 3600` → `h:mm:ss`, else `m:ss`. Seconds always two digits, minutes two digits only under an hour mark, leading unit not padded. A null total renders `--:--` in the template and in `totalText`; `clip_time` is never called for it.
- `spoken_duration(seconds)`: floor; units `hour`/`minute`/`second`, singular for 1, zero units left out, `0` → `"0 seconds"`. `72` → `"1 minute 12 seconds"`, `198` → `"3 minutes 18 seconds"`, `3605` → `"1 hour 5 seconds"`.
- `aria-valuetext`: `"<spoken elapsed> of <spoken total>"`; with a null total it is just `"<spoken elapsed>"`.

Floor, not round, so elapsed can never read past the total at the end of a clip.

import mutagen

def read_audio_duration(file_path: Path) -> float | None:
    """Seconds of audio in the local source file, or None when mutagen can't read it."""
    try:
        audio = mutagen.File(file_path)
    except (mutagen.MutagenError, OSError):
        return None
    if audio is None:
        return None
    length = float(audio.info.length)
    # A header-only file reports 0.0, which would give a seek bar with no range.
    return length if length > 0 else None

3. Alpine: the playback half of `audioClip`.

```js
// Module scope, beside sharedAudio:
// The one widget, c-audio or c-audio-clip, whose audio is playing or loading,
// as {id, pause}. Starting any widget pauses this one first.
let activeAudio = null;
// Audio elements live outside Alpine's reactive data: a proxied media element
// misbehaves, and each clip keeps its own so a paused clip keeps its buffer.
const clipElements = new Map();

// Added to the audioClip registration:
    get showPlayIcon() { return this.state === "paused" || this.state === "failed"; },

    toggle() {
        if (this.state === "playing" || this.state === "loading") { this._element().pause(); return; }
        this._start(this._element());
    },
    _element() {
        let audio = clipElements.get(this._id);
        if (audio) return audio;
        audio = new Audio();
        audio.preload = "none";
        audio.src = this._src;
        audio.addEventListener("playing", () => { this.state = "playing"; });
        audio.addEventListener("waiting", () => { if (!audio.paused) this.state = "loading"; });
        audio.addEventListener("pause", () => { if (this.state !== "failed") this.state = "paused"; });
        audio.addEventListener("timeupdate", () => { this.elapsed = audio.currentTime; });
        // The stored length is an estimate for some VBR files; the element's own is exact.
        audio.addEventListener("loadedmetadata", () => { if (Number.isFinite(audio.duration)) this.duration = audio.duration; });
        audio.addEventListener("ended", () => { audio.currentTime = 0; this.elapsed = 0; this.state = "paused"; });
        audio.addEventListener("error", () => this._fail());
        clipElements.set(this._id, audio);
        return audio;
    },
    // The redirect URL, never a signed one, so a page left open past the signature still plays.
    get _src() { return this.$refs.play.dataset.src; },
    _start(audio) {
        if (activeAudio && activeAudio.id !== this._id) activeAudio.pause();
        activeAudio = { id: this._id, pause: () => audio.pause() };
        this.state = "loading";
        // Called synchronously inside the click so iOS treats it as user-initiated.
        audio.play().catch((error) => { if (error.name !== "AbortError") this._fail(); });
    },
    _fail() { this.state = "failed"; },
    destroy() {
        const audio = clipElements.get(this._id);
        if (audio) { audio.pause(); audio.removeAttribute("src"); audio.load(); clipElements.delete(this._id); }
        if (activeAudio?.id === this._id) activeAudio = null;
    },
}));
```

The `pause` closure in `activeAudio` keeps the position because it only calls `pause()`. `audioFile` does not yet register itself in `activeAudio`; slice 5 does.

Alpine additions:

```js
pendingSeek: null,
dragging: false,
get seekMax() { return this.duration ?? 0; },
get seekDisabled() { return this.duration === null; },
// floor() makes this change at most once a second during playback
get valueText() { const e = spokenDuration(this.elapsed); return this.duration === null ? e : `${e} of ${spokenDuration(this.duration)}`; },
get playedStyle() { return { "--played": `${this.duration ? (this.elapsed / this.duration) * 100 : 0}%` }; },

seekInput(event) { this.dragging = true; this.elapsed = Number(event.target.value); },
seekChange(event) { this.dragging = false; this._seekTo(Number(event.target.value)); },
seekKey(event) {
    // step="any" leaves the browser's arrow step undefined, so arrows are handled here.
    const delta = { ArrowLeft: -5, ArrowRight: 5 }[event.key];
    if (delta === undefined || this.seekDisabled) return;
    event.preventDefault();
    this._seekTo(Math.min(Math.max(this.elapsed + delta, 0), this.seekMax));
},
_seekTo(seconds) {
    this.elapsed = seconds;
    const audio = clipElements.get(this._id);
    if (!audio || audio.readyState < HTMLMediaElement.HAVE_METADATA) { this.pendingSeek = seconds; return; }
    audio.currentTime = seconds;   // paused stays paused: no play() here
},
```

In `_element()`: `timeupdate` is ignored while dragging or while a seek is pending, because assigning `src` resets `currentTime` to 0 and a `timeupdate` would overwrite the saved position: `if (!this.dragging && this.pendingSeek === null) this.elapsed = audio.currentTime;`. `loadedmetadata` applies `pendingSeek` (`audio.currentTime = pendingSeek; pendingSeek = null`) and the clip stays `loading` until the `playing` event, which fires again after every seek, so no `seeked` listener is needed. `loadedmetadata` also re-applies the range's value (`this.$refs.seek.value = this.elapsed`), because a `max` that grows from 0 for a null-duration clip leaves the browser's clamped value behind. Home and End are native on a range and fire `input`/`change`, so they need no handler.

Media in the Playwright live server is served by `django.views.static.serve`, which ignores `Range`. Chromium can still seek inside a fully buffered 30 s file; if a seek test snaps back to 0, have the test fulfil the redirect target with a route handler that answers `Range` with `206` instead of weakening the assertion.

- component: a clip with a known duration renders the range input without `disabled`; a null-duration clip still renders it `disabled`. Seek behaviour itself is proved in the browser below.
