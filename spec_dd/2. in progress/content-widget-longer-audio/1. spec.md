# Spec: longer audio clip widget (`c-audio-clip`)

## Purpose

`c-audio` plays a word of a few seconds. It cannot pause, seek or show a duration, so course authors have no way to put a listening exercise of a few minutes into a topic. This spec adds `c-audio-clip`, a content widget for longer recordings. It is a card with a title, an optional kind label, a round play/pause button, a seek bar, elapsed and total time, and an optional transcript. The mockups are `image.png` (idle), `image-1.png` (loading), `image-2.png` (playing) and `image-3.png` (error), beside `idea.md`.

## Terminology

| Term | Status | Meaning / source |
| --- | --- | --- |
| audio clip | coined | One `c-audio-clip` widget on a page, playing one `File` of `file_type` `AUDIO`. Not a model. Needed to tell it apart from the `c-audio` pronunciation card |
| kind | coined | The `kind` attribute of `c-audio-clip`: short author text shown as a label beside the title ("Listening exercise") |

## Scope

In:
- The `c-audio-clip` cotton widget, with its Alpine component, allowlist entry and error boxes.
- `File.duration_seconds`, filled by `content_save` from the audio file's headers.
- One playing audio per page, shared with `c-audio`.
- An optional transcript written inside the tag.
- A demo clip, author docs, product docs and upgrade notes.

Out:
- Skip buttons, playback speed, volume, loop and autoplay.
- Lock-screen metadata (Media Session API).
- Remembering the position across page loads.
- Progress tracking or completion for listening.
- Access control on `content_engine:audio_file`, which belongs to the roadmap spec `content-widget-sayit-reveal-4-audio-access-control`.
- Any change to `c-audio`'s look or attributes.

## Decisions

- **New tag, not a `c-audio` variant.** The two cards share no attributes beyond `src`.
- **Duration is read at `content_save` with `mutagen`.** The total shows before any byte loads, and `c-audio`'s rule that nothing loads before the first press still holds. `mutagen` is pure Python and reads mp3, m4a/aac, ogg, flac and wav. The only alternative, an `ffprobe` subprocess, puts a system binary on every FLS host.
- **Each audio clip owns its own `HTMLAudioElement`, created on first Play.** `c-audio` shares one element across the page and swaps its `src` on every takeover. That would throw away a paused clip's buffer and position. One page-level "active player" handle keeps one-at-a-time across both widgets.
- **The play button keeps one accessible name and toggles `aria-pressed`**, as `c-audio` does. Changing the name as well makes screen readers say "Pause …, pressed".
- **The seek bar is a native `<input type="range">`.** It gives arrow, Home and End keys, touch drag and the slider role. A `role="slider"` div would need all of that written in the CSP Alpine build.
- **On `ended` the clip returns to paused at 0:00.** The next press plays it again from the start, so no replay icon state is needed.
- **The transcript is a disclosure, collapsed by default.** Showing it open would give away the answers to a listening exercise.

## Requirements

### Data: `freedom_ls/content_engine/models/files.py`

- Add `File.duration_seconds = models.FloatField(null=True, blank=True)`, with help text saying it is the audio length read at save time and null for non-audio or unreadable files.
- New migration after `0013_course_shared_with.py`. Existing rows stay null until their next `content_save`.

### Loader: `freedom_ls/content_engine/management/commands/content_save.py`

- Add `mutagen` to `[project].dependencies` with `uv add mutagen`. It is a runtime dependency, because host projects run `content_save`.
- In `save_file_to_db`, for `File.FileType.AUDIO`, read the length from the local source path (`mutagen.File(path).info.length`) before `file_obj.file.save(...)`. Set it in the `get_or_create` `defaults` and in the `not created` branch. For any other file type, set `duration_seconds = None`, so a file that stops being audio loses a stale value.
- An unreadable or unrecognised audio file (`mutagen.File` returns `None`, or raises `mutagen.MutagenError`) stores `None`. It echoes one indented warning line naming the file, and the run continues. Catch only those cases.
- The existing echo lines stay byte-identical, because tests assert on them.

### Widget template: `freedom_ls/content_engine/templates/cotton/audio-clip.html`

Attributes: `src` (required, file path resolved with `get_file_by_path`), `title` (required), `kind` (optional, default blank). The default slot is the transcript.

- **Error boxes** use `<c-content-error>`, following `audio.html`:
  - missing file, or `file_type != "AUDIO"`: "Audio not found: {{ src }}"
  - empty `title`: "Audio needs a title: {{ src }}"
- **Layout** (normal states): a round play button at the left, then a column with the title row on top and the seek row below.
  - The title row holds the title in bold, cut to one line with an ellipsis. Its `title` attribute holds the full text. When `kind` is set, it sits at the right as small muted mono text that does not shrink. When `kind` is blank, nothing renders in its place.
  - The seek row holds the seek bar, then `elapsed / total` in `tabular-nums`. Elapsed is in `text`, and `/ total` is in `text-muted`.
  - The card uses the same border, surface and radius as `c-audio`. Wrap it in `role="group"` with `aria-labelledby` set to the title's id, made with `x-id`/`$id` so two clips on one file never share an id.
- **Play button**: a real button of at least 44 px in the primary colour, using `c-button` as `audio.html` does.
  - `aria_label="Play {{ title }}"`, with `aria-pressed` bound to playing.
  - It shows the `media_play` icon when paused, the `loading` icon spinning (`motion-reduce:animate-none`) while loading, and `media_pause` while playing.
  - `data-src` is `{% url 'content_engine:audio_file' file_obj.pk %}`, never a signed URL.
- **Seek bar**: `<input type="range" min="0" step="1">`, with `max` set to the floor of `duration_seconds`.
  - `aria-label="Seek {{ title }}"`. `aria-valuetext` is spoken time ("1 minute 12 seconds of 3 minutes 18 seconds"), updated at most once a second and on change.
  - The hit area is at least 44 px high around a thin track. The visible thumb shows in every state, the played part is filled in the primary colour, and focus shows a visible ring.
  - The visible time text is `aria-hidden="true"`, because `aria-valuetext` carries it.
- **Null duration** (a row saved before this spec, or unreadable): the total shows `--:--` and the seek bar is disabled. After the first Play both come from the element's `duration` once it is finite.
- **Time format**: `m:ss` under an hour and `h:mm:ss` from an hour up, chosen from the total so that elapsed and total always share one format. Seconds are zero-padded and the leading unit is not.
- **Error state** (image-3.png): the card takes the error border and tint, the play button turns muted and disabled, and the title may wrap.
  - The seek row is replaced by "This audio couldn't load." and a small secondary `c-button` "Try again" (accessible name "Try again: {{ title }}").
  - A `role="status"` element stays in the DOM in every state, and only its text changes on failure, so each failure is announced.
- **Transcript**: when the slot holds more than whitespace, a text toggle under the seek row reads "Show transcript" / "Hide transcript".
  - The toggle has `aria-expanded` and `aria-controls`, and a chevron icon (`expand`/`collapse`).
  - The panel renders `{% markdown slot %}`. It is hidden from assistive technology while collapsed and uses `x-collapse` (`motion-reduce` respected).
  - The toggle and panel stay usable in the error state.
  - A whitespace-only slot renders no toggle.

### Alpine: `freedom_ls/content_engine/static/content_engine/js/alpine-components.js`

- Register `Alpine.data("audioClip", ...)`, and add it to the file's header list of components. All formatting, percentages and labels live in getters and methods, because the CSP build allows no complex inline expressions.
- **Element.** Create `new Audio()` on the first Play, with `preload="none"` and no `crossorigin`. Set `src` to `data-src`. Call `play()` synchronously in the click handler so iOS counts it as a user gesture.
- **States.** The states are `paused`, `loading`, `playing` and `failed`, and the button and labels follow the element's own events: `playing` and `pause`, plus `waiting` back to loading. An interruption (a phone call, another tab) leaves the button showing Play.
- **Pending seek.** A seek before the first Play, or while loading, stores a pending position. It is applied on `loadedmetadata`, and loading shows until `seeked`.
- **Dragging.** While the learner drags, update the thumb and time from `input` and ignore `timeupdate`. Set `currentTime` on `change`. Seeking while paused stays paused.
- **Ended.** Reset to 0:00 and paused.
- **Failure.** An `error` event or a `play()` rejection other than `AbortError` sets `failed` and keeps the current position. "Try again" sets `src` again through the redirect, which gets a fresh signed URL. It restores the position as a pending seek and plays, all inside the click.
- **One at a time.** Add a page-level active-player handle that both `audioClip` and `audioFile` use. Starting either widget pauses whatever the handle holds.
  - A paused audio clip keeps its element and position.
  - `audioFile`'s takeover code calls the handle instead of touching only its own `owner`. Starting an audio clip while a `c-audio` card plays stops that card, which keeps its current stop-and-rewind behaviour.
- **Cleanup.** `destroy()` pauses the element, clears its `src` and releases the handle if it holds this clip, so nothing plays after an HTMX swap.

### Icons: `freedom_ls/icons/semantic_names.py`, `freedom_ls/icons/mappings.py`

- Add `media_play` (a play triangle) and `media_pause` (two bars) to the `# Audio` group of `SEMANTIC_ICON_NAMES`, with an entry in each of the four packs: heroicons, lucide, tabler and phosphor. `audio_play` is a speaker icon and `paused` is a circled status icon, so neither fits the round button.

### Markdown allowlist: `config/settings_base.py`

- `MARKDOWN_ALLOWED_TAGS["c-audio-clip"] = {"src", "title", "kind"}`.
- Add `c-audio-clip` to `BANNED_TAGS` in `freedom_ls/base/tests/invariants/test_app_templates_use_app_components.py`.

### Nesting limits

`c-audio-clip` has the same limits as `c-audio`: it does not work inside `c-table`, `c-accordion`, `c-admonition`, `c-flashcard` or `c-card`, and a file-resolving widget inside its transcript fails. Both limits come from `{% markdown slot %}` rendering without `content_instance`. Authors separate transcript paragraphs with blank lines inside the tag.

### Demo content

- Add an "Audio clip" section to `demo_content/functionality_demo_content_widgets/2. media/content.md`, after "## Audio". It uses one longer clip (one to four minutes, under 2 MB, public domain or CC0) with a `title`, a `kind` and a transcript, plus one example without `kind` or transcript. Record the clip's source and licence in `2. media/audio/LICENCES.txt`.
- Update `freedom_ls/content_engine/tests/demo_content/test_audio.py`: `test_the_demo_mp3_files_load_as_audio` (exact file set) and `test_the_media_topic_renders_four_audio_widgets_without_red_boxes` (`data-src=` count).

### Serving

There are no code changes. Seeking relies on the redirect target answering `Range` with `206`. Object storage does this. QA confirms it on the dev media server and in Safari.

## Testing

- **`content_save`** (`tests/management/commands/test_content_save.py`):
  - A new audio file stores its duration (use the existing `BEEP_MP3` fixture bytes).
  - A re-save updates the duration.
  - An audio file replaced by a non-audio file clears it.
  - An unreadable `.mp3` stores `None`, echoes the warning and does not abort the run.
  - The existing echo-line assertions still pass.
- **Widget render** (new `tests/components/test_audio_clip_component.py`, modelled on `test_audio_component.py`):
  - The `x-data="audioClip"` attribute and the `data-src` redirect URL render.
  - The button name is "Play <title>".
  - The seek `max` and the total text come from `duration_seconds`.
  - `m:ss` and `h:mm:ss` totals format correctly.
  - A null duration gives `--:--` and a disabled seek bar.
  - A `kind` label shows when set and nothing renders when it is blank.
  - The transcript toggle shows for a transcript and is absent for a whitespace-only slot.
  - An unlisted attribute is stripped.
  - A missing file, a non-audio file and an empty title each render their red box.
  - Two clips on one file get distinct ids.
- **Sanitising** (`markdown_rendering/tests/test_markdown_utils.py`): a `<script>` and an `onerror` in the transcript are stripped.
- **Icons**: the existing mapping tests pass with `media_play` and `media_pause` in every pack.
- **Playwright** (`learner_interface/tests/playwright/`, alongside the `c-audio` flow):
  - No audio request happens before the first Play.
  - Play, pause and resume keep the position.
  - A seek before Play starts from the chosen point.
  - Arrow keys move the seek bar.
  - Starting a second clip pauses the first at its position.
  - Starting a `c-audio` card pauses a playing clip, and the reverse also holds.
  - A blocked `/content/audio/` request shows the error state, and "Try again" recovers.
  - Ending returns the clip to 0:00.
  - The transcript toggle opens and closes and sets `aria-expanded`.
- **Frontend QA**: idle, loading, playing and error at the three QA viewports against the mockups. Seeking works on the dev server and in Safari (`206` from the media URL).

## Open questions

- Q: On a narrow screen, should a long title wrap instead of being cut to one line? → A: Cut to one line with an ellipsis in idle, loading and playing, wrap in the error state, as the mockups show. The full title is in the `title` attribute and in the button and seek bar names (assumed default: it matches the mockups and keeps the card's height steady while playing. To overrule, edit the Layout bullet under "Widget template").

## Success criteria

- `<c-audio-clip src="audio/x.mp3" title="T" kind="Listening exercise">` in a topic renders the card in `image.png`, with the total time taken from `File.duration_seconds`.
- After `content_save`, every audio `File` that `mutagen` can read has a non-null `duration_seconds`.
- Loading a page with audio clips makes no request to `/content/audio/` until a Play press.
- Pausing, then playing another clip or a `c-audio` card, then pressing Play again resumes the first clip where it stopped.
- The seek bar works with the mouse, touch and the arrow, Home and End keys, and screen readers hear the time as words.
- A failed load shows the `image-3.png` state, and "Try again" plays from the saved position.
- A transcript in the tag shows behind "Show transcript". A tag with no transcript shows no toggle.
- The `uv run pytest` suite passes, including the updated demo-content tests.
