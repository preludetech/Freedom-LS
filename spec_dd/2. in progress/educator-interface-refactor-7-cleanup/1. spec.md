# Spec: Educator interface refactor, cleanup of the flat modules

## Purpose

Specs 1 to 6 of the Educator interface code layout effort moved each area into
`freedom_ls/educator_interface/panels/<area>/`. They left three docstring-only flat modules, the
flat test files that keep them mirrored, tests for moved code still sitting in `tests/test_views.py`,
four baselined shell test files, two stale docstrings and an invariant that scans only the flat
modules. This spec removes the leftovers, puts every remaining test beside the module it tests, and
writes the effort's upgrade note. The idea is `idea.md`; the effort's decisions are in the
"Educator interface code layout" section of `spec_dd/1. next/roadmap.md`.

## Scope

In:

- Delete `freedom_ls/educator_interface/actions.py`, `quick_views.py` and `reporting.py`.
- Move the tests left in `tests/test_actions.py`, `tests/test_quick_views.py` and the non-shell part
  of `tests/test_views.py` to mirrored homes, and fold the four baselined shell test files into
  `tests/test_views.py`.
- Clear the `educator_interface` lines in `test_organisation/mirroring_baseline.txt`.
- Widen `EDUCATOR_PYTHON_FILES` in `tests/invariants/test_panel_template_rules.py` to the `panels/`
  tree.
- Fix the two stale docstrings.
- Write `upgrade_notes.md`.

Out:

- Any behaviour, UI, URL name, URL path, template path or app label change. No migration, no
  re-export shim.
- `views.py` and `urls.py`. Both already hold only the end state: `views.py` is the shell
  (`interface_config`, `interface_root`, `_resolve_organisation`, `_attach_organisation`,
  `scope_request`, `standalone_page_context`, `interface`) with the stale `# TODO` block at
  `views.py:41-49`, which stays. `urls.py` imports `partial_oversight_thread_older` and the import
  views from `panels/learner/import_views.py` and `cohort_report_download` from
  `panels/cohort/report_download.py`.
- The flat domain modules (`forms.py`, `staff.py`, `learner_import.py`, `messaging.py`, `paths.py`,
  `events.py`, `user_display.py`, `tasks.py`, `notification_urls.py`, `admin.py`, `apps.py`,
  `avatars.py`, `exceptions.py`) and their tests.
- The lazy `interface_config` import in `panels/staff/actions.py`, and the imports from `views` in
  `panels/cohort/report_download.py` and `panels/learner/import_views.py`. Both directions are
  deliberate.
- Migrations `0001`, `0002`, `0003` and their tests under `tests/migrations/`: the old dotted paths
  there are history.
- Everything under `spec_dd/3. done/`, the generated `test_organisation/test_cost_ranking.md` and
  `.test_durations`, and the stale pointer in `freedom_ls/panel_framework/tests/test_views.py`
  (now line 378).
- Layering rules and baseline lines other than `educator_interface` mirroring:
  `test-organisation-and-hygene-15-educator-interface` owns them.

## Decisions

- **A test's home is the test file mirroring the module that defines the behaviour it checks**, under
  `tests/panels/<area>/` or `tests/panels/common/`. A test that only reaches `views.py` code stays
  in `tests/test_views.py`. A new test file is created only beside an existing module.
- **The cross-table message invariants go to `tests/panels/common/test_tables.py`**, which mirrors
  `panels/common/tables.py`. The idea's `test_data_tables_messages.py` has no module to mirror.
- **The course quick-view 404 test goes to `tests/panels/course/test_config.py`**, because
  `CourseConfig` declaring no quick view causes the 404. `panels/course/` has no `quick_view.py`.
- **The `gather.py` docstring drops its path pointer** and keeps the guard's statement. The guard it
  cites no longer exists in `educator_interface`, so there is nothing to repoint to.
- **The upgrade note indexes the sibling notes instead of restating their name lists.** The six
  sibling notes list every moved name per area. Restating them adds a second copy to keep in step
  and adds nothing new.

## Requirements

### Flat modules

- `freedom_ls/educator_interface/actions.py`, `quick_views.py` and `reporting.py` are gone. Each
  holds only `"""Emptied module: it holds no names."""` today. `filters.py` is already gone.
- `tests/test_actions.py` and `tests/test_quick_views.py` are deleted in the same commit as their
  modules. `check_test_mirroring.py` flags them as orphans otherwise.

### Tests

- `tests/test_actions.py` (about 1,240 lines, top-level functions): each test moves to the area or
  common file that mirrors the module defining what it checks. Most go to existing files:
  `tests/panels/learner/test_actions.py`, `test_bulk_actions.py`,
  `tests/panels/cohort/test_actions.py`, `test_bulk_actions.py`, and
  `tests/panels/common/test_bulk_actions.py`. Two groups need a new file:
  - Audit entries written by actions, the atomic-rollback test, the reason field and the stale-picker
    422s go to `tests/panels/common/test_actions.py` (new, mirrors `panels/common/actions.py`) when
    they check `panels/common/actions.py` behaviour. When a test checks one area's action, it goes to
    that area's `test_actions.py`.
  - Bulk threshold, background confirmation and dialog weight, title, focus and loading text go to
    `tests/panels/common/test_bulk_actions.py` or the area's `test_bulk_actions.py`, by the same rule.
  A test that already exists in its target file is deleted, not copied twice.
- `tests/test_quick_views.py`: its one test,
  `test_a_course_quick_view_404s_since_courses_declare_none`, moves to
  `tests/panels/course/test_config.py`.
- `tests/test_views.py`: the shell tests stay: breadcrumb and navigation toggle (103-186), the
  Administration-group and Dashboard visibility tests (306-330), the messages-section 404s and the
  removed unread-count route (358-385). Every other test moves to its mirrored home, including its
  private helpers and fixtures:
  - audit-log access and export (190-232) to `tests/panels/audit_log/`;
  - members rows and add-to-cohort pickers (235-305) and the move-history test (330-357) to the
    learner or cohort area;
  - bulk-run status polling (`_run_for`, `run_world`, `_poll` and the six tests, 388-510) to
    `tests/panels/common/test_bulk_actions.py`;
  - the learners and cohorts bulk bars (514-564) to the learner and cohort `test_bulk_actions.py`;
  - `EDUCATOR_TABLES` and its four message tests (567-620) to `tests/panels/common/test_tables.py`;
  - cohort-role export 404s (623-654), picture surfaces (656-735) and shared-course owner lines
    (737-780) to the area that renders them.
  Line numbers are from the current tree. A helper used by tests in more than one destination goes
  to `tests/helpers.py`.
- `tests/test_document_title.py`, `test_interface_urls.py`, `test_organisation_switcher.py` and
  `test_sidebar.py` fold into `tests/test_views.py`, then are deleted. A test in one of them that
  checks a `panels/` module moves to that module's test file instead.
- Every moved test keeps its name and assertions. Fixtures, `mock.patch` strings and marks move with
  it. The pytest collected count for `freedom_ls/educator_interface` is the same before and after.
- Every new test directory has an empty `__init__.py`.

### Baselines and invariants

- `test_organisation/mirroring_baseline.txt` has no line naming `freedom_ls/educator_interface/`.
  Its `# educator_interface` header stays only if the file keeps headers for apps with no lines.
- `import_baseline.txt:47` and `import_contracts.toml:199` already name
  `tests.panels.course.test_data_tables`. No edit is needed. If a moved test adds a new cross-app
  test import, it goes into those files the way the existing line does.
- `tests/invariants/test_panel_template_rules.py:21`: `EDUCATOR_PYTHON_FILES` covers every `.py`
  file under `freedom_ls/educator_interface/` except `tests/` and `migrations/`.
  `test_no_educator_module_sets_the_modal_trigger_template_by_hand` passes over the wider set. If
  it finds an offender, the offender is fixed by extending the framework's modal action class, with
  no change to the rendered output.

- `freedom_ls/qa_helpers/management/commands/qa_create_learner_registrations_panel.py:4`: the
  docstring names `freedom_ls/educator_interface/panels/learner/data_table_panels.py` as the home of
  `LearnerRegistrationsPanel`.
- `freedom_ls/reports/gather.py:371`: the docstring no longer names `educator_interface/views.py`.
  It still states the guard: `quiz_percentage()` raises on unreadable input, `passed()` raises when
  `quiz_pass_percentage` is unset, and that field is nullable.
- After the edits, a grep of `freedom_ls/`, `config/`, `claude_plugins/fls-dev/`,
  `test_organisation/` and `docs/` for `educator_interface.(actions|filters|quick_views|reporting)`,
  `educator_interface/(actions|filters|quick_views|reporting)` and
  `educator_interface(.|/)views` finds only the out-of-scope items above and true references to the
  shell `views`. The same holds for strings passed to `mock.patch`, `monkeypatch.setattr` and
  `import_string`.
