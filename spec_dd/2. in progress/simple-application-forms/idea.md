If there is an application gated course then we need a way for people to fill out an application form. the application forms might be different per course.  Initially, these will be simple forms.

First use case will be an application form that includes the following info:

- age
- why_here	fun / work / own_work / own_company
- pay_how	myself / employer / finance / not_sure
- town + province	text + nine-value enum
- working_status	yes / no / studying
- travel_distance	local / 200km / anywhere / accommodation
- heard_about + heard_about_detail	google / facebook / dealer / friend / other + text; prefilled "Dealer — [name]" when ref is set, editable
- Are you south African

If it's easy we can do multi-page forms.
