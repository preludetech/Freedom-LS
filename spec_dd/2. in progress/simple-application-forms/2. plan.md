# Plan: simple application forms

Implementation plan for `1. spec.md`. Every noun here is the spec's noun. Where the spec cites a line
number, this plan verified it against the worktree at `abf30607`; the few places the code disagrees
with the spec's citation are called out inline.

## Working rules

- **TDD throughout.** Each step names the test that fails first. Write that test, watch it fail, then
  make it pass. Do not write the whole suite up front.
- **Skills.** Load the skills a step names before touching its files. Two constraints the skills add
  that the spec does not spell out, and that every step below honours:
  - Alpine runs the `@alpinejs/csp` build (`.claude/ds/config.md`). No inline expressions anywhere:
    every component is registered with `Alpine.data()` and directives reference method or property
    names only.
  - Every admin class extends `SiteAwareModelAdmin` from `freedom_ls.site_aware_models.admin`.
- **Comments** follow `code-comments`: keep the reasoning the spec gives, never cite a decision
  number or a spec section.
- **Pseudocode is not the diff.** The blocks below leave out type hints for brevity. The real code
  types every signature (`HttpRequest`, `HttpResponse`, `UUID`, `**kwargs: object`, and so on),
  matching the style already in each file it touches, with no `Any`.
- **Migrations** are made with `uv run manage.py makemigrations <app>` and applied with
  `uv run manage.py migrate`. Never edit an existing migration. Each of the three apps that change
  (`form_engine`, `content_engine`, `course_applications`) is on `0001_initial` today, so each gains a
  `0002`.
- **The runner is the regression oracle.** `freedom_ls/learner_interface/tests/` must pass at the end
  of every batch, with the one documented exception in step 3.
- **App edges.** `form_engine` imports nothing from `content_engine`, `learner_progress`,
  `learner_interface` or `course_applications`, before or after this work. `paging.py` is where that
  is easiest to get wrong.

```python
    # Moved from learner_interface/views.py:1150-1164.

               _furthest_answered_page(form_progress, pages))


def resume_page_number(form_progress: FormProgress) -> int:

def page_accessibility_limit(form_progress: FormProgress, current_page_number: int) -> int:
    return max(resume_page_number(form_progress), current_page_number)


def build_page_links(
    form: Form, form_progress: FormProgress, current_page_number: int,
    url_for_page: Callable[[int], str],
) -> list[dict[str, object]]:

    limit = max(_resume_page_number(form_progress, pages), current_page_number)
    return [
        {"number": n, "title": page.title, "url": url_for_page(n),
         "is_current": n == current_page_number, "is_accessible": n <= limit}
        for n, page in enumerate(pages, start=1)
    ]


def unanswered_required_on_page(
    questions: list[FormQuestion], post_data: QueryDict, form_progress: FormProgress

        q for page in form_progress.form.pages.all() for q in page_questions(page)
        if q.required and q.id not in answered_ids
```

Pseudocode:

```python
MAX_UPLOAD_BYTES = 6 * 1024 * 1024
ALLOWED_EXTENSIONS = frozenset({".jpg", ".jpeg", ".png", ".pdf"})
ALLOWED_IMAGE_FORMATS = {"JPEG": ".jpg", "PNG": ".png"}
ACCEPT_ATTRIBUTE = ",".join(sorted(ALLOWED_EXTENSIONS))
PDF_MAGIC = b"%PDF-"


def validate_and_sanitise(uploaded_file: UploadedFile | None) -> tuple[ContentFile, str]:
    if uploaded_file is None:
        raise ValidationError("Choose a file to upload.")
    if Path(uploaded_file.name).suffix.lower() not in ALLOWED_EXTENSIONS:
        raise ValidationError("Upload a JPEG, PNG or PDF.")
    if (uploaded_file.size or 0) > MAX_UPLOAD_BYTES:
        raise ValidationError("That file is larger than 6 MB.")
    try:
        uploaded_file.seek(0)
        raw = uploaded_file.read(MAX_UPLOAD_BYTES + 1)
    finally:
        uploaded_file.seek(0)
    if len(raw) > MAX_UPLOAD_BYTES:
        raise ValidationError("That file is larger than 6 MB.")
    if raw.startswith(PDF_MAGIC):
        return ContentFile(raw), ".pdf"
    return _reencode_image(raw)


def _reencode_image(raw: bytes) -> tuple[ContentFile, str]:
    with bomb_warnings_as_errors():
        try:
            Image.open(io.BytesIO(raw)).verify()      # full decode, destroys the object
            img = Image.open(io.BytesIO(raw))
            image_format = img.format
            img.load()
        except BOMB_FAILURES as err:
            raise ValidationError("Image is too large to process safely.") from err
        except DECODE_FAILURES as err:
            raise ValidationError("File is not a readable image or PDF.") from err
    ext = ALLOWED_IMAGE_FORMATS.get(image_format or "")
    if ext is None:
        raise ValidationError("Upload a JPEG, PNG or PDF.")
    img = ImageOps.exif_transpose(img)          # keep orientation, then drop the EXIF
    if image_format == "JPEG": img = img.convert("RGB")
    buf = io.BytesIO()
    img.save(buf, format=image_format)          # no exif= kwarg, so EXIF including GPS is gone
    return ContentFile(buf.getvalue()), ext
```

Pseudocode for `models.py`:

```python
def get_user_uploads_storage() -> Storage:
    """The fixed user_uploads alias; nothing names it, so the second argument is the alias."""
    return storage_for_alias("user_uploads", "STORAGES['user_uploads']")


def question_answer_file_upload_to(instance: QuestionAnswerFile, filename: str) -> str:
    # `filename` is the name FLS chose in the upload view (f"file{ext}"), never the applicant's.
    # This is the key the first upload lands at. user_uploads never overwrites, so a replace at the
    # same extension is stored under a storage-suffixed sibling and save() deletes the old key.
    ext = Path(filename).suffix.lower()
    return f"user_uploads/{instance.answer.form_progress.user_id}/form_answers/{instance.pk}{ext}"


class QuestionAnswerFile(SiteAwareModel, TimestampedModel):
    answer = OneToOneField(QuestionAnswer, CASCADE, related_name="answer_file")
    file = FileField(upload_to=question_answer_file_upload_to, storage=get_user_uploads_storage)
    original_filename = CharField(max_length=255)

    def save(self, *args, **kwargs):
        superseded = self._stored_file_name()      # via QuestionAnswerFile._base_manager, like
        super().save(*args, **kwargs)              # Organisation._stored_logo_names
        if superseded and superseded != self.file.name:
            self.file.storage.delete(superseded)
```
