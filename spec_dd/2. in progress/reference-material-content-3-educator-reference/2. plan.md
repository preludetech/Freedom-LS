2. Extract the `CoursePart` branch of `_outline_item_rows` into `_part_row` and call it from there.
   The learning-path output must not change.

   ```python
   def _part_row(part: CoursePart, number: str, *, nested: bool) -> OutlineRow:
       """A part's group row holding a row for each of its collection items,
       or a note when it has none."""
       children = tuple(
           _outline_item_rows(item, f"{number}.{position}", nested=True)
           for position, item in enumerate(part.collection_items(), start=1)
       )
       return OutlineRow(
           number=number if nested else f"{number}.",
           title=part.title,
           kind="part",
           children=children
           or (
               OutlineRow(
                   number="", title="", kind="part", note="No items in this part."
               ),
           ),
       )
   ```

3. Extract the forms-and-prefetch lines at the top of `outline_rows` into a helper, and call it from
   `outline_rows` with `course.collection_items()`:

   ```python
   def _prefetch_form_pages(items: list[ContentCollectionItem]) -> None:
       """One pages query covers every form among the items at any depth, so
       the count stays flat as forms grow."""
       forms = [
           item.child
           for item in _all_collection_items(items)
           if isinstance(item.child, Form)
       ]
       prefetch_related_objects(forms, "pages")
   ```

4. Add `_reference_parts` and `reference_rows`; export `reference_rows` in `__all__`:

   ```python
   def _reference_parts(course: Course) -> list[CourseReferencePart]:
       """The course's own reference parts in order, each with its part."""
       return list(course.reference_parts.select_related("course_part"))


   def reference_rows(course: Course) -> list[OutlineRow]:
       """One group row per reference part of the course, in order, numbered
       within the reference list. There is no course details row: the course
       content outline already carries it."""
       parts = [reference_part.course_part for reference_part in _reference_parts(course)]
       _prefetch_form_pages(
           [item for part in parts for item in part.collection_items()]
       )
       rows = [
           _part_row(part, str(position), nested=False)
           for position, part in enumerate(parts, start=1)
       ]
       return rows or [
           OutlineRow(
               number="",
               title="",
               kind="course",
               note="No reference material in this course yet.",
           )
       ]
   ```

### Slice 2: a reference topic previews, and each preview URL answers only for its own panel

The Reference panel's topic rows carry "Preview", which opens "<title> (Preview)" with the Topic
chip. A preview URL answers only for a row its panel lists.

**Builds on:** slice 1
**Touches:** freedom_ls/educator_interface/panels/course/content_preview.py, freedom_ls/educator_interface/tests/panels/course/test_content_preview.py, freedom_ls/educator_interface/tests/helpers.py

Tests first (`test_content_preview.py`). Give `_content_action_url` (`tests/helpers.py`) and
`_preview_url` a keyword `panel: str = "content"` so they build and read
`courses/{pk}/__panels/{panel}/__actions/{action}`; existing callers are unchanged.

- A reference topic row carries a "Preview <title>" trigger whose `hx-get` ends with
  `/__panels/reference/__actions/preview_content?item=<pk>`.
- GET that URL with `HX-Request: true` → 200, "<title> (Preview)", "Topic", `max-w-reading` (the
  reading-column contract the educator-interface skill names).
- 404, each in its own test, with `HX-Request: true`:
  - the id of a collection item in one of the course's reference parts on the "Course content"
    panel's `preview_content` URL;
  - the id of a collection item on the course's learning path on the Reference panel's URL;
  - the id of a collection item in a reference part listed only by another course;
  - the id of a collection item on another site (`site_context(SiteFactory())`);
  - the id of the collection item placing a `CoursePart` nested inside a reference part;
  - a `CourseReferencePart` pk;
  - empty, malformed and unknown `item` values (parametrised like
    `test_a_preview_with_a_missing_or_malformed_item_is_a_404`);
  - the reference URL without `HX-Request`, and by POST.
- A part shared by two courses: `test_a_topic_in_a_shared_reference_part_previews_through_each_listing_course`
  (parametrised over the two courses, 200) and
  `test_a_topic_in_a_reference_part_is_a_404_through_a_course_that_does_not_list_it`.

Implementation in `content_preview.py`:

1. A module-level helper replaces the action's inline lookup:

   ```python
   def _course_list_items(
       course: Course, course_list: CourseList
   ) -> list[ContentCollectionItem]:
       """The collection items one list of the course places, at any depth.
       Reference parts are reached through the course's own reference parts,
       so a part the course does not list is never searched."""
       if course_list == "learning_path":
           return _all_collection_items(course.collection_items())
       return [
           item
           for reference_part in _reference_parts(course)
           for item in _all_collection_items(reference_part.course_part.collection_items())
       ]
   ```

2. `PreviewContentAction.__init__(self, course_list: CourseList = "learning_path")` stores
   `self.course_list`; `get_context_data` calls `_course_list_items(course, self.course_list)`.
   Everything else in it stays: the `HX-Request` check, `uuid_or_404`, the `CoursePart` 404, `page`
   only on a form. `_form_preview_context` and `show_answer_key` stay in this module.

3. `CourseReferencePanel.preview_actions` returns `[PreviewContentAction(course_list="reference")]`.
