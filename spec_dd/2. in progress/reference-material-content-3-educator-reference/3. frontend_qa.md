# Frontend QA: educator reference panel and reference topic preview

## Setup

- Start the server: `uv run python manage.py runserver $PORT`. Base URL `http://127.0.0.1:$PORT`.
- Log in at `/accounts/login/` with the QA admin account from `## QA Login` in `.claude/sdd/config.md`.
- Load the demo content if "Functionality Demo - Reference Material" is missing
  (`uv run python manage.py content_save ./demo_content DemoDev`).
- Open the educator interface, pick an organisation the admin administers, go to **Courses** and
  open "Functionality Demo - Reference Material". Note its URL: `/…/<org-slug>/courses/<course-pk>`.
- Run every test at the three QA viewports (phone, tablet, desktop). Hide the Django debug toolbar
  before each screenshot.

## Test 1: the Reference panel on the demo course

1. On the course page, scroll past "Course content".
2. Expect, in order: the course details panel, "Course content", "Reference", then the cohorts and
   learners panels.
3. In "Reference": two group rows, `1.` "Airspace Rules" and `2.` "Glossary", each open by default,
   with topic rows `1.1`, `1.2`, `2.1` ….
4. No "Course details" row in Reference, no in-development callout, no button in the panel header.
5. The footer reads "N reference outline items", N being parts plus topics.
6. "Course content" still starts with "Course details", lists only "Flying Basics" and its topic,
   and its footer counts only those rows.
7. Collapse and re-expand a reference part with its chevron; its topics hide and return.
8. At phone width the panel shows as cards, with no horizontal scroll.

Checklist:
- [ ] Reference sits directly after Course content
- [ ] Rows numbered `1.`, `1.1` within the panel
- [ ] No details row, no callout, no header button
- [ ] Footer count counts parts and topics; Course content's count unchanged
- [ ] Cards at phone width, no horizontal overflow

## Test 2: previewing a reference topic

1. Click "Preview" on a reference topic row (`1.1`).
2. Expect the wide dialog titled "<topic title> (Preview)", a "Topic" chip and the content in the
   reading column. Nothing in it saves, and there is no "Mark complete".
3. Press Escape: the dialog closes and focus returns to the Preview button.
4. Repeat for a topic in the shared glossary part.
5. Preview a learning-path topic in "Course content": it still opens as before.
6. Use the keyboard only: Tab to a reference Preview button, press Enter, check focus lands on the
   dialog title.

Checklist:
- [ ] "<title> (Preview)" heading and Topic chip
- [ ] Content in the reading column, read-only
- [ ] Escape closes and returns focus
- [ ] Learning-path previews unaffected

## Test 3: a course with no reference parts

1. Open any other demo course with no reference parts.
2. Expect the "Reference" panel showing "No reference material in this course yet." as an empty
   state, with no table numbers and no footer count.
3. "Course content" looks as it did before this change.

## Test 4: preview URLs answer only for their own panel

Use the browser's address bar or devtools fetch with the `HX-Request: true` header.

1. Copy a reference topic's Preview URL (`…/__panels/reference/__actions/preview_content?item=<id>`).
2. Change `reference` to `content` in the path and request it: expect 404.
3. Copy a learning-path topic's Preview URL, change `content` to `reference`: expect 404.
4. Request the reference URL with `item=not-a-uuid`: expect 404.
5. Request the reference URL without the `HX-Request` header: expect 404.

## Test 5: a registration-only organisation

1. In the admin, find or create an organisation that does not own the reference demo course and has
   no share of it, and give one of its cohorts a registration on the course. Make the QA admin an
   organisation admin there (use the data helper if needed).
2. Open the course page under that organisation.
3. Expect both "Course content" and "Reference" to show "Content preview isn't shared with your
   organisation." with no rows and no Preview buttons.
4. Request a reference preview URL copied from Test 4 with this organisation's slug: expect 404.

## Test 6: other pages unchanged

1. Open a cohort page and a learner page: no Reference panel appears there.
2. On the course page, check the cohorts and learners panels still load and paginate.
3. Check the browser console shows no errors on the course page or while previewing.
