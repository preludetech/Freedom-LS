# Frontend QA: shuffled quiz pages, questions and answer options

A QUIZ form with the shuffle knobs on serves each sitting its own order of pages, page children
and answer options, fixed for that sitting. A keep-together group moves as one block and a locked
option stays where it was authored. The results page labels each wrong answer with the number the
learner saw. Forms without the knobs look and behave as before.

## Setup

- Start the server: `uv run python manage.py runserver $PORT`
- Base URL: `http://127.0.0.1:$PORT`
- Admin login: `demodev@email.com` / `demodev@email.com`
- The Django admin is at `/admin/`. Form progress records (with their `served_paper`) are under
  Form engine.

### Data needed

Ask the data helper for these. Each learner needs a password you are given.

1. **Demo content loaded**, including the new course "Functionality Demo - shuffled quiz"
   (`demo_content/functionality_demo_shuffled_quiz/`), through `content_save` on `demo_content`.
2. **Two learners**, learner A and learner B, registered on the shuffled-quiz course and on
   "Functionality Demo - show end with Quiz", neither of whom has started either quiz.

Before starting, open the demo quiz files in `demo_content/functionality_demo_shuffled_quiz/2. quiz/`
and note the authored order: page titles, each page's children, each question's options, the
locked "All of the above" option's position, and the group's three members (a content block with
a picture and its two questions).

## Test 1: a sitting gets a shuffled order that stays put

1. Log in as learner A. Open the shuffled-quiz course and start its quiz.
2. On each page, write down the page title, the order of content and questions, the question
   numbers and each question's option order. Move through every page with Next.

Expect:

- The pages, or the children on at least one page, or the options of at least one question come
  in an order different from the authored one. (With three pages and several questions, an order
  identical to the authored one on every scope is very unlikely; if it happens, use learner B for
  Test 3 and compare there.)
- The page indicator counts 1, 2, 3 in the order the pages are shown, whatever their authored
  order. The URL carries the authored page number, so it may not match the indicator.
- Questions are numbered 1, 2, 3 … down the sitting in the order shown, with no gaps or repeats.
- The group's content block, with its picture, comes directly before its two questions, in the
  authored order, on the same page. Nothing sits between them.
- The "All of the above" option is at its authored position (last, if authored last), however
  the other options on that question are ordered.
- Multiple-choice, checkboxes and dropdown questions all show their options in the shuffled order;
  in the dropdown, open the list to check.

## Test 2: the order survives reload, back, page jumps and resume

Continue as learner A, mid-sitting.

1. On page 2 (by indicator), reload the page.
2. Click Previous, then Next.
3. Use the browser Back button once, then Forward.
4. If the page jump links show, click the link for the first page, then the last.
5. Answer a question on the current page, then leave the quiz (exit or navigate to the course
   page) and come back to it and resume.

Expect after each step: the same page order, children order, numbers and option order as written
down in Test 1. A selected answer is still selected on resume. No console errors.

## Test 3: a re-sit and a second learner get a new order

1. As learner A, finish the quiz (answer some questions wrongly on purpose, at least one on a
   later page). Start a new attempt if the course allows a retake; write down its order.
2. Log in as learner B and start the same quiz. Write down the order.

Expect: learner A's re-sit and learner B's sitting each have an order different from learner A's
first sitting on at least one scope (page, children or options). The group stays together and the
locked option stays in place in both.

## Test 4: the results page shows the number the learner saw

After finishing in Test 3 step 1, on the results page (with `quiz_show_incorrect` on):

Expect:

- Each wrong answer's card shows "Question N" where N is the number the question had in that
  sitting, not its authored number. Check one question whose shown number differed from its
  authored position.
- Cards are listed in the order the questions were shown.
- The score and percentage match the answers given: count the wrong answers yourself.

## Test 5: unshuffled quizzes are unchanged

1. As learner B, open "Functionality Demo - show end with Quiz" and take its quizzes.

Expect: pages, questions and options appear in the authored order from its files, on two attempts
alike, and the results page numbers match the authored question numbers.

## Test 6: layout at each viewport

Repeat a page of Test 1 (the grouped page) and the results page at 1920×1080, 768×1024 and
375×812.

Expect: the picture in the grouped content block fits the column, no horizontal scroll, option
lists and the dropdown are usable, and the results "Question N" label sits where it did before.
