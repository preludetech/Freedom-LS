# Plan: shuffle quiz pages, questions and answer options

Spec: `1. spec.md` in this directory.

## What already exists

`sacaa-compliance-1-served-paper-record` built almost everything a shuffled order needs downstream.
This plan reuses it and does not rebuild any of it:

- `freedom_ls/form_engine/served_paper.py`: `build_served_paper(form)` writes
  `{"seed", "pages", "options"}` in authored order; `ensure_served_paper` writes it once per sitting.
- `freedom_ls/form_engine/conditions.py`: `served_path` rebuilds a `SittingPath` from the paper in
  served page order, served child order and served option order. `SittingPath.question_positions()`
  gives each question's served number, `page_position()` the served page position,
  `options_of(question)` the served option order. Navigation, page-jump links,
  `record_page_reached`, resume and scoring already read the path.
- `freedom_ls/form_engine/templatetags/form_engine_tags.py:74` renders options through
  `path.options_of`.
- `freedom_ls/form_engine/factories.py::served_paper_of` builds a hand-written paper for tests.
- `freedom_ls/content_engine/validate.py::validate_form_conditions` walks forms, page files and
  content blocks. Its walk is extracted here and shared, not copied.
- `freedom_ls/tests/demo_content_fixtures.py::loaded_demo_content` loads `demo_content/` once per
  module.

So the shuffle only has to change the order `build_served_paper` writes. Everything that reads the
paper follows it.

### Slice 2: `shuffle_options` shuffles each question's options once per sitting, locked options stay put

Behaviour: with `shuffle_options` on, the served paper lists each question's options in a
seeded order where a locked option keeps its authored index. With every knob off, the paper is
exactly today's and no RNG is created.

**Builds on:** slice 1

**Touches:** freedom_ls/form_engine/served_paper.py, freedom_ls/form_engine/factories.py, freedom_ls/form_engine/tests/test_served_paper.py

In `served_paper.py`:

```python
import secrets
from collections.abc import Callable, Sequence
from random import Random

def new_seed() -> int:
    """The seed a new served paper is shuffled from. Tests patch this, never `random`."""
    return secrets.randbits(63)


def _scope_rng(seed: int, scope: str) -> Random:
    # One private generator per scope, so editing one page or question
    # leaves every other scope's order unchanged for the same seed.
    return Random(f"{seed}:{scope}")


def shuffle_with_locks[T](
    items: Sequence[T], is_locked: Callable[[T], bool], rng: Random
) -> list[T]:
    """Locked items keep their index; the rest are shuffled into the free positions.

    Shuffling everything and swapping the locked ones back would bias where
    the free items land.
    """
    free_positions = [i for i, item in enumerate(items) if not is_locked(item)]
    free_items = [items[i] for i in free_positions]
    rng.shuffle(free_items)
    result = list(items)
    for position, item in zip(free_positions, free_items, strict=True):
        result[position] = item
    return result
```

`build_served_paper` draws the seed with `new_seed()` first, and reads each question's options
through a helper, so each knob stays one small function:

```python
def _served_options(question: FormQuestion, form: Form, seed: int) -> list[QuestionOption]:
    options = list(question.options.all())
    if not form.shuffle_options:
        return options
    return shuffle_with_locks(
        options, lambda o: o.locked, _scope_rng(seed, f"options:{question.id}")
    )
```

`factories.py::served_paper_of` calls `new_seed()` instead of `secrets.randbits(63)`, so the seed

**Tests** (`test_served_paper.py`; pure-function tests need no database; no `for`, `if` or
`try` in a test body: parametrize instead):

- `shuffle_with_locks`, parametrized over a fixed seed range (for example `range(200)`) and over
  the lock layouts: none, all locked, one free, lock at index 0, lock at the last index, two
  adjacent locks, a lock in the middle. Each layout carries its locked positions as data, so the
  test asserts `sorted(result) == sorted(items)` and
  `[result[i] for i in locked_positions] == [items[i] for i in locked_positions]`, with no loop.
- A stub `Random` subclass whose `shuffle` reverses the list proves the free items fill the free
  positions in shuffled order: `[a, L, b, c]` with `L` locked gives `[c, L, b, a]`.
- Distribution: a plain helper beside the test counts the orders `shuffle_with_locks` gives three
  free options over a fixed seed range (for example 6 000 seeds) and returns a `Counter`. The test
  is parametrized over the six permutations and asserts each count sits inside a wide band (for
  example 800–1 200). Deterministic, so not flaky.
- `build_served_paper` with `shuffle_options` on and `new_seed` patched to a fixed value: each
  question's option list is a permutation of its options, a locked option keeps its index, and the

  The paper builds and equals the authored order (the existing authored-order test keeps passing

### Slice 4: `shuffle_questions` shuffles shuffle units, so a keep-together group moves as one block

Behaviour: each page's children are split into shuffle units. With `shuffle_questions` on, the
units are shuffled with that page's RNG; either way they are flattened back. A group with
`shuffle_questions` off stays in authored order.

**Builds on:** slice 3

**Touches:** freedom_ls/form_engine/served_paper.py, freedom_ls/form_engine/tests/test_served_paper.py

```python
class Groupable(Protocol):
    @property
    def group(self) -> str | None: ...


def shuffle_units[T: Groupable](children: Sequence[T]) -> list[list[T]]:
    """Split a page's children into the lists that move as one when the page shuffles.

    A run of consecutive children sharing a group is one unit, in authored
    order; every other child is a unit of its own. Schema items carry None
    for no group and model rows carry "", so both count as ungrouped.
    """
    units: list[list[T]] = []
    for child in children:
        if child.group and units and units[-1][0].group == child.group:
            units[-1].append(child)
        else:
            units.append([child])
    return units
```

The final shape of `build_served_paper`:

```python
def _served_children(page: FormPage, form: Form, seed: int) -> list[FormChild]:
    units = shuffle_units(page.children())
    if form.shuffle_questions:
        _scope_rng(seed, f"page:{page.id}").shuffle(units)
    return [child for unit in units for child in unit]


def build_served_paper(form: Form) -> ServedPaper:
    """The paper a sitting starting now is served, shuffled as the form's knobs say."""
    prefetch_related_objects([form], *SERVED_TREE_LOOKUPS)
    seed = new_seed()
    page_rows = list(form.pages.all())
    if form.shuffle_pages:
        _scope_rng(seed, "pages").shuffle(page_rows)
    pages: list[ServedPage] = []
    options: dict[str, list[str]] = {}
    for page in page_rows:
        children = _served_children(page, form, seed)
        pages.append({"id": str(page.id), "children": [str(c.id) for c in children]})
        for child in children:
            if isinstance(child, FormQuestion):
                option_ids = [str(o.id) for o in _served_options(child, form, seed)]
                if option_ids:
                    options[str(child.id)] = option_ids
    return {"seed": seed, "pages": pages, "options": options}
```

With every knob off, `_scope_rng` is never called, so no `Random` is created.

Question pools will import `shuffle_units`, so it is public and does not touch the database or
global random state.

**Tests:**

- `shuffle_units` on schema `FormContent`/`FormQuestion` instances (group `None`) and on model rows
  built with factories (group `""`): runs become units, singletons stay singletons, members keep
  authored order, two adjacent different groups are two units.
- Parametrized over a seed range, `build_served_paper` with `shuffle_questions` on keeps the
  group contiguous and in authored order: the test finds the group's first member's index once

- Same seed: adding a question to page 1 leaves page 2's child order and every page order
  unchanged; all three knobs on together give a paper whose pages, children and options are each
  permutations of the authored lists.

```python
def validate_form_shuffle(all_parsed: Sequence[BaseBaseContentModel]) -> list[str]:
    """Check group and locked against the form's strategy and shuffle knobs.

    Every error is reported, never just the first.
    """
    errors: list[str] = []
    for form_pages in _form_pages(all_parsed):
        form = form_pages.form
        is_quiz = form.strategy == FormStrategy.QUIZ
        first_page_of_group: dict[str, tuple[int, str]] = {}  # group -> (page index, page title)
        for page_index, page in enumerate(form_pages.pages):
            children = page.children
            for child, label in children:
                errors.extend(_locked_option_errors(child, label, form))
                if child.group and not is_quiz:
                    errors.append(_shuffle_error(child, label, <non-QUIZ problem>, <fix>, "group"))
            if not is_quiz or page.page is None:
                continue
            errors.extend(_split_group_errors(children))
            # A group repeats within a page; one cross-page error per later page is enough.
            for child, label in _first_member_of_each_group(children):
                first_index, first_title = first_page_of_group.setdefault(
                    child.group, (page_index, page.page.title)
                )
                if first_index != page_index:
                    errors.append(_shuffle_error(child, label, <two-pages problem with first_title, page.page.title>, <fix>, "group"))
    return errors


def _split_group_errors(children: list[tuple[_FormChildSection, str]]) -> list[str]:
    """One error per group that opens a second run on this page, naming the
    first child after its first run."""
    errors: list[str] = []
    ended_by: dict[str, str] = {}  # group -> label of the child that ended its first run
    reported: set[str] = set()
    runs = [list(run) for _, run in itertools.groupby(children, key=lambda c: c[0].group)]
    for run, next_run in itertools.pairwise([*runs, []]):
        child, label = run[0]
        group = child.group
        if not group:
            continue
        if group not in ended_by:
            if next_run:
                ended_by[group] = next_run[0][1]
        elif group not in reported:
            errors.append(_shuffle_error(child, label, <split problem naming ended_by[group]>, <fix>, "group"))
            reported.add(group)
    return errors
```

`_first_member_of_each_group` returns the first `(child, label)`
of each distinct group on the page.

`_locked_option_errors` returns `[]` for a content block (guard with
`isinstance(child, FormQuestion)` inside it), and otherwise one error per option with
`locked: true` on a question of a form whose `shuffle_options` is off. Problem and fix wording is
exactly the spec's table:

| Rule | Problem | Fix |
| --- | --- | --- |
| group on non-QUIZ | `group is only allowed on QUIZ forms (this form is <strategy>).` | `Remove group, or change the form's strategy to QUIZ.` |
| locked with `shuffle_options` off | `option "<text>" is locked, but shuffle_options is off for this form, so it never moves.` | `Set shuffle_options: true in the form front matter, or remove locked.` |
| group on two pages | `group "<name>" is used on page "<A>" and page "<B>". A group stays on one page.` | `Rename one of the groups, or move its members onto one page.` |
| split group | `group "<name>" is split: <child label> sits between its members.` | `Move the members together, or give <child label> the same group.` |

`<A>` and `<B>` are page titles, taken from the `FormPage`, not from `_target_label` (which
already wraps them in `page "…"`). Append the pass to `validate()` after
`validate_form_conditions`.
