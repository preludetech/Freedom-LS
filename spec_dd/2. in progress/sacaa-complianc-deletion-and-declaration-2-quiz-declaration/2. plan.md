**Rule helpers (new `form_engine/declarations.py`).** The rule lives only here:

```python
from freedom_ls.form_engine.enums import FormStrategy


def form_requires_declaration(form: Form, user: User | AnonymousUser) -> bool:
    """A quiz that asks a signed-in learner to sign before each attempt."""
    return (
        form.strategy == FormStrategy.QUIZ
        and form.requires_declaration
        and user.is_authenticated
    )


def sitting_needs_declaration(form_progress: FormProgress) -> bool:
    """Whether this sitting is still waiting for its declaration."""
    return (
        form_progress.user is not None
        and form_requires_declaration(form_progress.form, form_progress.user)
        and not FormDeclaration.objects.filter(form_progress=form_progress).exists()
    )


def declaration_text_hash(text: str) -> str:
    """SHA-256 of the declaration as rendered, so a POST can prove it signed that text."""
    return hashlib.sha256(text.encode("utf-8")).hexdigest()
```

**Django form (new `learner_interface/forms.py`).**

```python
class FormDeclarationForm(forms.Form):
    agreed = forms.BooleanField(
        required=True,
        error_messages={"required": _("Tick the box to make the declaration.")},
    )
    typed_name = forms.CharField(
        max_length=200,
        strip=False,
        error_messages={"required": _("Type your full name to sign.")},
    )
    text_hash = forms.CharField(widget=forms.HiddenInput)

    def __init__(self, *args: object, declaration_text: str, **kwargs: object) -> None:
        super().__init__(*args, **kwargs)
        self.expected_hash = declaration_text_hash(declaration_text)
        self.fields["text_hash"].initial = self.expected_hash

    def clean_typed_name(self) -> str:
        name = self.cleaned_data["typed_name"]
        if not name.strip():
            raise ValidationError(_("Type your full name to sign."), code="required")
        return name  # stored as typed, spaces kept

    def clean_text_hash(self) -> str:
        # The page re-checks the text it showed, so the stored text is always
        # the text the learner read.
        value = self.cleaned_data["text_hash"]
        if value != self.expected_hash:
            raise ValidationError("stale", code="stale")
        return value

    def declaration_changed(self) -> bool:
        return self.has_error("text_hash", code="stale")
```

Type `*args`/`**kwargs` the way other `forms.Form` subclasses in the project do, if they differ

### Slice 2: a rejected signature is explained and stores nothing

An unticked box, a blank or whitespace-only name, or a declaration text that changed since the page
rendered each re-render the page with HTTP 422, accessible errors and nothing stored.

**Builds on:** slice 1
**Touches:** learner_interface/views.py, learner_interface/forms.py, learner_interface/templates/learner_interface/form_declaration.html, learner_interface/tests/views/test_form_declaration.py

**View.** On POST, when `not bound.is_valid()`, re-render with `status=422` and store nothing. When
`bound.declaration_changed()`, re-render a fresh unbound `FormDeclarationForm(declaration_text=text)`
(both fields cleared, current hash) with `text_changed=True`. Otherwise re-render the bound form
with its errors.

**Template.**

- When `text_changed`, put `<c-callout tone="error">The declaration has changed. Read it again and sign.</c-callout>`
  above the declaration text.
- Under each field in error, show `<p id="<field>-error" class="text-error text-sm">{{ error }}</p>`
  (the `consent-checkboxes.html` style). On that input, set `aria-invalid="true"` and add the error
  id to `aria-describedby`. The tick box keeps `declaration-text` followed by the error
  id; the name's `aria-describedby` holds only its error id.
- On a bound form with errors, redisplay the typed name only when that field has no error. A ticked
  box stays ticked unless it is the field in error.
- Focus goes to the first field in error through a server-side `autofocus` on that one input. The
  tick box comes first, then the name. No JavaScript is needed.

**Tests prove:** for each of an unticked box, a blank name, a whitespace-only name and a stale
`text_hash`, the response is 422, no `FormProgress`, `CourseFormAttempt` or `FormDeclaration` row
exists, and the matching field's error element (`agreed-error` or `typed_name-error`) is present.
A field error carries `aria-invalid` and an
`aria-describedby` that names its error, and the first field in error has `autofocus`. A stale hash
shows the callout, both fields empty, and a fresh hash.

### Slice 3: front matter that misuses the keys fails validation

An author who puts the keys on a survey or application form, sets text without the flag, or names a
declaration quiz as a course's `application_form` gets a validation error from `content_save`.

**Builds on:** slice 1
**Touches:** form_engine/schema.py, form_engine/tests/test_schema.py, content_engine/validate.py, content_engine/management/commands/content_save.py, content_engine/tests/test_validate.py, content_engine/tests/management/commands/test_content_save.py

**`validate_quiz_fields`.** In the non-QUIZ branch, add `requires_declaration` (when true) and
`declaration_text` (when non-empty) to the checks, in the existing message style
`"<name> should only be set when strategy is QUIZ (in {self.file_path})"`. Folding them into the
`knobs` dict is fine. For every strategy, add:
`declaration_text` non-empty with `requires_declaration` false → `"declaration_text should only be set when requires_declaration is true (in {self.file_path})"`.

**Cross-file rule (`content_engine/validate.py`).**

```python
def validate_application_form_declarations(all_parsed: Sequence[BaseBaseContentModel]) -> list[str]:
    """A form a course names as its application_form cannot ask for a declaration:
    the application flow mints its own sittings, anonymous applicants included,
    so no signature step would run."""
    forms_by_path = {resolved file_path: form for each parsed Form}
    for each parsed Course:
        author_path = (course.access_config or {}).get("application_form")
        if author_path is None: continue
        form = forms_by_path.get(resolve_author_path(course.file_path, author_path))
        if form is not None and form.requires_declaration:
            errors.append(<message naming the course file, the form path and the fix>)
    return errors
```

Call it from the aggregate runner next to `validate_form_shuffle`. Match how the existing
validators key parsed forms by path; `resolve_author_path` returns the same path type that
`content_by_path` uses in `content_save`.

**`content_save.py`.** The comment above the `application_form` binding says this is "the one
place in core that reads an access_config key by name". Reword it to name both readers: this
binding and the validator rule.

**Tests prove:** each rejected combination raises with the expected message: the flag on a survey,
text on a survey, and text without the flag on a quiz. A quiz with both is accepted. A course whose
`application_form` names a form with `requires_declaration: true` fails validation; one naming a
form without the flag passes. Removing both keys from a form's front matter and running
`content_save` again resets `requires_declaration` to false and `declaration_text` to `""`.

### Slice 4: no route serves or completes an unsigned sitting

`form_fill_page` and `form_submit_and_exit` send an unsigned sitting of a declaration quiz to the
declaration page and write nothing. This covers "Continue Form", a direct link, and sittings
opened before the author turned the declaration on. A closed quiz, or one whose access has ended,
still finalises an unsigned sitting.

**Builds on:** slices 1, 2
**Touches:** learner_interface/views.py, learner_interface/tests/views/test_form_runner.py, learner_interface/tests/views/test_form_declaration.py, learner_progress/attempts.py, learner_progress/tests/test_attempts.py

**Signing an unsigned sitting (`start_attempt`).** An unsigned open sitting can still exist: one
opened before the author turned the declaration on. Signing it through `form_declaration` must sign
that sitting, not finalise it. Restructure the reuse test in `start_attempt` so `open_sitting` is
narrowed inside each expression:

```python
open_sitting = get_latest_incomplete(course_progress, collection_item)
reusable = open_sitting is not None and not open_sitting.answers.exists() and (
    open_sitting.start_time >= timezone.now() - START_REUSE_WINDOW
    # Nothing is served for an unsigned sitting until it is signed, so the
    # learner never left it; finalising it would leave an attempt with no
    # declaration.
    or (
        declaration is not None
        and not FormDeclaration.objects.filter(form_progress=open_sitting).exists()
    )
)
if not reusable:
    finalise_stale_incomplete(
        course_progress,
        collection_item,
        kept_if_untouched_since=kept_if_untouched_since,
    )
```
