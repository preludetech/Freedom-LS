# Frontend QA: cohort administration

This change finishes the cohorts section of the educator interface and makes the courses section
read-only and organisation-scoped.

What a browser can see:

- **The cohort list** shows a status badge, an active learner count, the active courses and the
  created date; sorts and searches; hides inactive cohorts until "Show inactive" is set; filters by
  course.
- **Create** offers "Save and add another". A name clash, including with an inactive cohort,
  answers in the dialog.
- **The cohort page** has Overview, Learners, Courses and Settings tabs, a header with a status
  badge, learner and course counts, Edit and Deactivate or Reactivate.
- **Overview** holds a details card, course completion per active registration, a needs-attention
  placeholder and, for organisation admins, an educators block.
- **Courses** lists the cohort's registrations and offers Register and, per active row,
  Unregister with a confirmation naming who keeps access.
- **Settings** offers Deactivate or Reactivate, and Delete only for an empty cohort; otherwise it
  says why delete is unavailable.
- **An inactive cohort grants no course access** through its registrations, and is read-only:
  Edit, Register and Unregister are gone.
- **The courses section** shows only courses the educator can see in this organisation, no
  actions, and a status for both the cohort and the registration on each course page.

Beyond the golden path, this run hunts for:

- **Access leaking through an inactive cohort**, or being lost through an active route (an
  individual registration, another cohort).
- **Stale pages.** A second browser tab that still offers Edit, Register, Unregister or Delete
  after the cohort changed must answer with a reason, never silently succeed.
- **Over-granting.** A cohort admin reaching the settings tab, the educators block or another
  cohort's actions; a cohort viewer seeing any write control.
- **Enumeration.** Another organisation's cohort, registration or hidden course answers 404.
- **Counts that disagree** between the list, the header, the quick view and the overview card.

## §0 Setup

### 0.1 Server

1. `PORT=$(.claude/ds/scripts/find_available_port.sh)`. Use that number literally from here on.
2. `uv run python manage.py runserver $PORT`, backgrounded.
3. Base URL: `http://127.0.0.1:$PORT`. Check that `#debug-branch-badge`, bottom left, names
   `educator-interface-6-cohort-administration`.

## §1 Cohort list (as `org.admin@qa.test`)

1. Open `/educator/northside/cohorts`.
   - Columns: Cohort Name, Status, Learners, Courses, Created.
   - Rows are Cohort A, Cohort B, Cohort Empty, Cohort Removed, Cohort Stale, in name order.
     **Cohort Old is absent.**
   - Every badge reads "Active".
   - Cohort A: Learners 3, Courses lists Course Pub and Course Hid, one per line, no dates.
   - Cohort Removed: Learners **0** (the removed learner is not counted).
   - Cohort Stale: Courses shows a dash (the inactive registration is not listed).
2. Click the Learners header: rows reorder by count ascending; click again, descending. Same for
   Created and Cohort Name. The toolbar says "Sorted by …".
3. Search "Emp": only Cohort Empty remains. Clear the search.
4. Open the filter chip "Show inactive" and choose it. Cohort Old appears with an "Inactive"
   badge; the applied chip reads "Show inactive". Remove the chip: Cohort Old is gone.
5. Open "Add filter" → "Course", pick Course Hid: only Cohort A and Cohort B remain. Pick Course
   Pub instead: Cohort A only (Cohort Stale's registration is inactive, Cohort Old is hidden).
   Set "Show inactive" too: Cohort Old joins. Clear all.
6. In the address bar, append `?cohorts-course=<pk of Course Other>`. The list is unchanged
   (an out-of-scope value is ignored) and no filter chip is applied.
7. Below 768px (resize or device toolbar): the Filter and Sort buttons open the sheet; "Show
   inactive" and "Course" are listed there; applying works the same.
8. Click the quick-view icon beside Cohort Old (with Show inactive on): the drawer's Status row
   reads "Inactive". Cohort A's drawer: "Active", Learners 3, Courses Pub and Hid.
