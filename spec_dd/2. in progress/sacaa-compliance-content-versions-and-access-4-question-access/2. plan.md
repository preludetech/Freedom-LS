## How to work

- TDD: for each slice write the failing tests first, then the code. Run tests through the project's
  test runner (`claude_plugins/django-stack/resources/test_runner.md`), never a hand-picked command.
- Comments and docstrings state the reasoning. They never name a spec, plan, slice or section
  (`sdd:planning-references-in-code`, `ds:code-comments`).
- Never delete an existing TODO or `@claude` comment.

   ```python
   _QUESTION_VIEW_SURFACES = {
       "preview": "Course preview",
       "cohort_report": "Cohort report",
       "attempt_review": "Attempt review",
   }

   def _describe_question_view(entry: AuditLogEntry) -> str:
       """Where the question detail was shown and which quizzes it belonged to."""
       surface = _QUESTION_VIEW_SURFACES.get(str(entry.details.get("surface", "")), "")
       forms = entry.details.get("forms")
       titles = (
           ", ".join(
               str(form["title"])
               for form in forms
               if isinstance(form, dict) and "title" in form
           )
           if isinstance(forms, list)
           else ""
       )
       return ": ".join(part for part in (surface, titles) if part)
   ```

   does, so an entry with unexpected details still renders. The Audit log cell

New file `educator_interface/panels/common/question_detail.py`, used by this slice and slice 5:

```python
QUESTION_DETAIL_HIDDEN_NOTE = (
    "Question detail is hidden: you do not have permission to view questions."
)
QUESTION_DETAIL_NEEDS_JAVASCRIPT_NOTE = (
    "Question detail loads only with JavaScript turned on."
)


def question_detail_withheld_note(
    request: HttpRequest, organisation: Organisation
) -> str:
    """The note to show in place of question detail, or "" when it may render.

    Question detail renders only on the page's own htmx request: a plain GET
    (a prefetch, or the no-JavaScript link of a lazy panel) would show it
    without the view being recorded. The permission is checked first, so
    someone who could never see the detail is not told to turn JavaScript on.
    """
    if not can_view_course_questions(request.user, organisation):
        return QUESTION_DETAIL_HIDDEN_NOTE
    if request.headers.get("HX-Request") != "true":
        return QUESTION_DETAIL_NEEDS_JAVASCRIPT_NOTE
    return ""
```
