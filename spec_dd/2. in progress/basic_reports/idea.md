We need to be able to create a pdf report showing the progress of a cohort on a course. Initially we will generate this report either through the admin panel. Later on we will work it into an automated email, that is out of scope for now.

All pages should be standard A4 size. Landscape or portrait as appropriate

The report should have the following information:

0. title page
- Which cohort
- date

1. Summary of all students progress
This table can become quite wide. These summary pages should be landscape if needed
If the table splits over multiple pages, make sure each page has the right headers
Use colors to highlight who is doing well/badly

Draw a table showing all students. For each student, show:
- how much of the course they have completed (this can show item counts, or a percentage. Can have a graphical representation like a bar)
- what course item they completed last, and when
- each quiz/test they have done. Show the latest score and number of attempts

2. details per student

- Show each item they have done, and when they finished it
- Show each quiz attempt:
    - final score
    - when
- for each quiz:
    - each question they got wrong
    - how many times they got it wrong
    - incorrect answers selected (how many times each)
    (we want to see where the student got confused)

3. Quiz confusions over the whole cohort
we want to see where the content itself was confusing

For each quiz:
- each question people got wrong
- what incorrect answers they chose, how many times
