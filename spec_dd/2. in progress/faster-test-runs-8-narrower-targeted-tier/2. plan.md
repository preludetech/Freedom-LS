## Shape of the change

### `TierConfig` (Slice 1)

```python
@dataclass(frozen=True)
class TierConfig:
    none: tuple[str, ...]
    builtin_escalation: tuple[str, ...]
    project_escalation: tuple[str, ...]
    dependency: tuple[str, ...]
    tooling: tuple[tuple[str, tuple[str, ...]], ...]
    markers: str | None = None
    narrow: bool = False

    @property
    def escalation(self) -> tuple[str, ...]:
        # Built-ins first, so the glob a reason names is the one it named before the split.
        return self.builtin_escalation + self.project_escalation
```

`decide_upstream` and the non-narrow branch path keep reading `config.escalation`, so their output
is byte for byte today's.

```python
def narrow_setting(table: dict[str, object]) -> bool:
    value = table.get("narrow", False)
    if not isinstance(value, bool):
        raise ConfigError("[tool.test_tiers] 'narrow' must be true or false")
    return value
```

`main()` adds `--wide` (`action="store_true"`); after loading, `if args.wide: config =
replace(config, narrow=False)`. After the `tier:` line, `if config.narrow: print("mode: narrow")`.

### `module_graph.py` (Slices 2 and 3)

New sibling of `select_tests.py`, stdlib only, imported the same way the selector imports its
siblings (`sys.path[0]`).

```python
def path_module_name(path: str) -> str:
    # "a/b/c.py" -> "a.b.c"; "a/b/__init__.py" -> "a.b". Works for a path the checkout no
    # longer has, so a deleted module keeps its name.

def imported_names(tree: ast.Module, module: str, is_package: bool) -> set[str]:
    # ast.walk the whole tree: imports inside functions and `if TYPE_CHECKING:` count.
    # ast.Import "a.b.c"            -> {"a", "a.b", "a.b.c"}
    # ast.ImportFrom "a.b", names c -> {"a", "a.b", "a.b.c"}
    # Relative: level n strips n-1 parts from the importing package (the module itself when
    # is_package, else its parent); `from . import c` names "<package>.c". A level deeper
    # than the package has parts names nothing, so that node adds no name.
    # "a.b.c" is added for every imported name, whether it is a module or an attribute:
    # edges are keyed by name, so an attribute name matches no module and never fires, and a
    # module the change deleted is still matched by the files that import it.

def conftests_above(test_path: str, conftests: set[str]) -> set[str]:
    # every "<dir>/conftest.py" in `conftests` for the test file's directory and each
    # ancestor up to the root ("conftest.py")

@dataclass(frozen=True)
class ModuleGraph:
    # module name -> names of the modules that import it
    importing_modules: dict[str, set[str]]
    # module name -> repo-relative path, for every tracked module
    paths: dict[str, str]

    def test_files_reaching(self, modules: set[str]) -> set[str]:
        # BFS over `importing_modules` from `modules`; return the paths of every reached module
        # whose file name is_collected(). The changed modules themselves are not in the result.

def build(project_root: Path, tracked: list[str]) -> ModuleGraph:
    # `tracked` is the `git ls-files` list of `.py` paths, minus in_skipped_dir. One pass:
    # parse each file once. A tracked file the working tree has deleted is skipped without a
    # warning, since it is simply gone; SyntaxError and UnicodeDecodeError skip with a warning
    # to stderr, as iter_app_trees does. Record imported_names, and add an edge from each
    # collected test file to the module name of every conftest above it, since pytest loads
    # those without an import.
```

`module_graph.py` runs no git command. `select_tests.py` lists the tracked files with its own
`git_paths(["git", "ls-files", "-z", "--", "*.py"])` and passes them in, so there is one
`subprocess.run` wrapper.

`decide()` and `branch_test_decisions` take a required `graph: Callable[[], ModuleGraph]`, one call
convention for both; `branch_test_decisions` passes it through and never triggers it, because its
decisions all come from the test-file rule. `main()` builds it as
`functools.cache(lambda: module_graph.build(project_root, tracked_python_files()))`, so the graph is
built at most once and only when a narrowed branch path asks for it. The comprehension in `main()`
that calls `decide()` sits inside the same `except (subprocess.CalledProcessError,
FileNotFoundError) as exc: parser.error(f"git failed: {exc}")` the other git calls use.

`NARROW_TAIL = "(narrow; the rest is left to a full run)"` is a module constant in
`select_tests.py`, beside `BRANCH_TEST_REASON`.

### `decide()` under `narrow` (Slices 2 to 6)

The order stays: `none` globs, test files, dependency files, escalation, owning app, tooling,
unmapped. With `config.narrow` false, `decide()` runs exactly today's code. With it true:

```python
app = owning_app(apps, project_root, path)

escalation (narrow):
    if first_match(path, config.project_escalation): full              # project globs win
    builtin = first_match(path, config.builtin_escalation)
    "**/migrations/**"                     -> full
    "**/conftest.py"                       -> narrowed(conftest_decision(path, apps, project_root))
    app is None                            -> skip the rows below; continue at the no-owner rule
    "**/factories.py", "**/signals.py",
    "**/middleware.py"                     -> narrowed(narrow_app_python(path, app, graph, project_root))
    "**/urls.py", "**/apps.py"             -> narrowed(narrow_app_python(...) + one_app_hop(path, app, apps, edges, project_root))
    "**/fixtures/**"                       -> narrowed(narrow_app_python(...)) for a .py file,
                                              narrowed(narrow_app_file(path, app, apps, edges, project_root)) otherwise
owning app (narrow):
    path ends ".py"                        -> narrowed(narrow_app_python(...))
    otherwise                              -> narrowed(narrow_app_file(...))
no owning app, path ends ".py" (narrow):
    found = narrow_loose_python(path, config, graph, project_root)
    if found is not None: return narrowed(found)                    # None falls through
tooling, then unmapped                     -> as today
```

- `narrow_app_python(path, app, graph, project_root) -> list[Decision]`: `owner_decision(...)` plus
  `imports_decision`, one `select` decision of the test files selected through imports:
  `graph().test_files_reaching({path_module_name(path)})`, minus each file `f` for which
  `targets_overlap(f, tests_dir_of(app, project_root))` holds. Its reason is
  `"<n> test files through imports"`; with `n == 0` it is a `none` decision with that reason. No
  `importer_decisions`, and no app map needed.
- `narrow_loose_python(path, config, graph, project_root) -> list[Decision] | None`, for a `.py`
  file no app owns: the graph's files (as an `imports_decision`) plus `decide_tooling(path)`'s
  decisions. When both select nothing it returns `None`, so `decide()` falls through to the
  unmapped rule (`full`, or `none` for an untracked file). An ownerless `urls.py`, `apps.py`,
  `factories.py`, `signals.py`, `middleware.py` or `fixtures/` module takes this rule too.
- `narrow_app_file(path, app, apps, edges, project_root) -> list[Decision]`: `owner_decision(...)`
  plus `one_app_hop`. With `edges is None` it is `full` with today's
  `"docs/app_structure.md missing"` reason.
- `one_app_hop(...)` is `importer_decisions(path, app, apps, edges, project_root, chain=False)`.
  `importers()` and `importer_decisions()` gain `chain: bool = True`; in `importers()` a runtime
  importer is queued only when `chain` is true (`if dep == "runtime dep" and chain:`). With the
  default, every existing caller, `decide_upstream` included, is byte for byte today's. The
  reasons are the existing ones (`"beta has a runtime dep on alpha"`). `urls.py` and `apps.py`
  with `edges is None` are `full`, as `narrow_app_file` is.
- `conftest_decision(path, apps, project_root) -> list[Decision]`: `directory =
  PurePosixPath(path).parent`, `root = project_root / directory`. When
  `any(root != app.directory and root in app.directory.parents for app in apps)` (the root
  conftest, where `root == project_root`, and the package-root conftest), it is `full` with
  `"matches **/conftest.py"`. Otherwise `select (directory.as_posix(),)`, reason
  `"conftest scope <directory>"`.
- `narrowed(decisions) -> list[Decision]`, a one-line helper beside `from_main`:
  `[replace(d, narrowed=True) if d.kind != "full" else d for d in decisions]`. `Decision` gains
  `narrowed: bool = False`, and `main()` prints ` {NARROW_TAIL}` after the reason of a narrowed
  line. A `full` decision is never narrowed, so its line keeps the ` -> full (` substring
  `full_run_record.run_selector` parses.
- The browser-test filter in `narrow_app_python` and `narrow_loose_python` drops a reached file
  `f` when `playwright_tests_root(PurePosixPath(f)) is not None and first_match(path, UI_GLOBS)
  is None`, reusing the existing helper.

`decide_upstream` is not touched. It reads `config.escalation` (the property), and it is never
given the graph.

Decisions taken at plan review:

- A test file the import graph reaches that sits under a `tests/playwright/` directory is kept
  only when the changed path matches `UI_GLOBS`, the same rule `owner_decision` applies to the
  owning app's browser tests. Today an importer's browser tests are left out by
  `--ignore=<dir>/playwright`; reaching them by import would add the slowest tests to every
  leaf-module change.
- Parent-package edges stay: importing `a.b.c` runs `a/__init__.py` and `a/b/__init__.py`. An app
  whose `__init__.py` imports its own submodules therefore narrows less; the replay measures it.
- All the graph's tests live in `tests/test_select_tests.py` and run through the selector in temp
  repos, since the scripts directory is not importable. No `tests/test_module_graph.py`.
- Slice 7 keeps the checkpoint wording and the upstream parity test together, and Slice 9 is a
  recorded measurement with no automated test.

Behaviour: a project can set `narrow = true`; the selector validates it, prints `mode: narrow` when

**Touches:** claude_plugins/django-stack/scripts/select_tests.py, tests/test_select_tests.py

  "escalation")`.
- Add `narrow` with `narrow_setting`, the `--wide` flag and the `mode: narrow` line (shapes above).
  Update the module docstring's usage line with `[--wide]`.
- Tests (temp repo, `alpha_app()`):
  - `narrow = "yes"` and `narrow = 1` exit 2 with `[tool.test_tiers] 'narrow' must be true or
    false` on stderr.
  - `narrow = false` gives the same stdout as no key.
  - `narrow = true` prints `mode: narrow` right after `tier:`; no key, `narrow = false` and `--wide`
    print no `mode:` line.
  - `--wide` with `narrow = true` gives the same stdout as no key, for a module path, an

  - `--wide` combines with `--working-tree`, `--range`, `--upstream-range` and

- Test conventions for this and every later slice: names follow
  `test_<subject>_<condition>_<expected>` with no rule or slice numbers; a bullet with several

  tests inherit their file's existing `pytestmark` and add no per-test marker.

### Slice 2: a changed app module selects its owning app and the test files that import it

Behaviour: under `narrow`, a change to a Python module in an app selects the owning app's tests
directory plus the test files that reach the module through absolute imports, at any depth, and
no importer app directories. Narrowed `why:` lines end with the narrow tail.

**Builds on:** slice 1
**Touches:** claude_plugins/django-stack/scripts/module_graph.py,
claude_plugins/django-stack/scripts/select_tests.py, tests/test_select_tests.py

- Create `module_graph.py` with `path_module_name`, `imported_names` for absolute `import` and
  `from` imports (parent packages included), `ModuleGraph`, `test_files_reaching` and `build`.
  Add `tracked_python_files` to `select_tests.py` (through `git_paths`) and wrap the `decide()`
  comprehension in `main()` in the `git failed` handler.
- Thread the cached `graph` callable through `decide()` and `branch_test_decisions`; add
  `narrowed` to `Decision`, `NARROW_TAIL` and the print change; add the owning-app `.py` branch
  (`narrow_app_python`, `imports_decision` and the `narrowed` helper) and the Playwright filter from the assumed default.
- Tests (temp repo with `git init` and a commit, since the graph reads `git ls-files`; apps
  `alpha`, `beta`, `gamma` with an app map where `beta` and `gamma` import `alpha` at runtime):
  - A leaf `pkg/alpha/leaf.py` imported only by `pkg/beta/tests/test_uses_leaf.py` selects
    `pkg/alpha/tests` and that file, not `pkg/beta/tests` or `pkg/gamma/tests`.
  - `pkg/gamma/other.py` imports a different `alpha` module: `pkg/gamma/tests` is not selected.
  - Transitive: `pkg/gamma/tests/test_x.py` imports `pkg.gamma.helpers`, which imports
    `pkg.alpha.leaf`; the test file is selected.
  - The owning-app line reads `... (owning app alpha) (narrow; the rest is left to a full run)`
    and the imports line names the count.
  - A reached test file appears in `command:` as a file path, and one inside an already selected
    directory is collapsed into it. Adjust `minimal_selection` or `compose_command` only if this
    test fails.
  - A reached file under `pkg/beta/tests/playwright/` is dropped for `leaf.py` and kept for a
    change to `pkg/alpha/views.py`.
  - The graph is not built for a run whose paths never reach the `.py` rule: a temp repo with a
    file that fails to parse prints no parse warning when only a docs path changed.
