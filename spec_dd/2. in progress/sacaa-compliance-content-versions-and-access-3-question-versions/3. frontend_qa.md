# Frontend QA: immutable question versions, pinned per sitting

Every page here must look as it did before the change; what changes is which wording and which
correct answers it shows. Judge each page against the checks listed, on this branch's server.

## §0 Setup

1. Pick a free port with `.claude/ds/scripts/find_available_port.sh`; call it `$PORT`.
2. `uv run python manage.py migrate`.
3. Start the server: `uv run --directory <PROJECT_ROOT> python manage.py runserver $PORT`
   (background). Base URL `http://127.0.0.1:$PORT`. Confirm the `debug-branch-badge` shows this
   branch.
4. Admin login: `demodev@email.com` / `demodev@email.com`, at `/accounts/login/`.
5. Seed data. Run `uv run python manage.py qa_create_attempt_review_scenario` for the educator
   review course and its learners. Then the QA data helper builds the versioned scenario below on
   the DemoDev site. Every version is made with `save_question_version(question,
   list(question.options.all()), "")` from `freedom_ls.form_engine.models`, never by editing the
   version table.

   **Versioned quiz "QA Versioned Quiz"** (QUIZ, pass mark 50, `quiz_show_incorrect` on), placed in
   a course the learner `versions-learner@email.com` (password = email) is registered on. One page,
   two multiple-choice questions:
   - Q1 "What is the reserve fuel for a VFR day flight?", options "30 minutes" (correct),
     "45 minutes", "10 minutes".
   - Q2 "Which colour is the left navigation light?", options "Red" (correct), "Green".

   Give both questions version 1. Then:
   - **Sitting S1 (completed):** the learner sits it through the product (served paper built,
     `save_answers`, `complete()`), answering Q1 "45 minutes" (wrong) and Q2 "Red" (right). Score
     1/2.
   - **Revise Q1 to version 2:** wording "What is the minimum reserve fuel for a VFR day flight?",
     correct option moved to "45 minutes" ("30 minutes" no longer correct). Save version 2.
   - **Sitting S2 (in progress):** a second learner `versions-learner-2@email.com` starts the quiz
     (served paper written) **before** the revision above is saved; leave it open on page 1 with
     no answers. Create it first, then do the revision.

   **Versioned application:** an application course whose form has a short-text question "Your
   licence number" (version 1). The applicant `versions-applicant@email.com` answers it and reaches
   check-your-answers; then the question is revised to "Your pilot licence number" (version 2).

   **Versioned survey:** an UNSCORED form, one multiple-choice question "How did you hear about us?"
   options "Friend", "Advert" (version 1); `versions-learner@email.com` answers "Friend" and
   completes it; then the question is revised to "How did you first hear about us?" (version 2).

   The helper prints the course slugs, item indexes, sitting pks and application pk.

## Test 1: results page shows the answered version (S1)

1. Log in as `versions-learner@email.com`.
2. Visit `/courses/<course_slug>/<index>/complete` for the versioned quiz.

Check:
- [ ] Score shows 1 out of 2 (50%), and the pass/fail verdict matches the stored score.
- [ ] No "your score may be out of date" notice.
- [ ] The incorrect-answers list names Q1 with the wording "What is the reserve fuel for a VFR day
      flight?" (version 1), not version 2's wording.
- [ ] The learner's answer reads "45 minutes"; the correct answer reads "30 minutes".
- [ ] Q2 is not in the incorrect list.
- [ ] Layout matches the results page elsewhere in the app; no console errors at 1920x1080,
      768x1024 and 375x812.

## Test 2: a new sitting is served the new version

2. Page 1 renders.

- [ ] Q1 reads "What is the minimum reserve fuel for a VFR day flight?" (version 2).
- [ ] Answer Q1 "45 minutes" and Q2 "Red", submit: the results page shows 2 out of 2.

## Test 3: a sitting in flight keeps its pinned version (S2)

1. Log in as `versions-learner-2@email.com` and resume the versioned quiz (from the course page).

Check:
- [ ] Q1 reads "What is the reserve fuel for a VFR day flight?" (version 1) even though version 2

- [ ] Answer Q1 "30 minutes" and Q2 "Red", submit: the results page shows 2 out of 2 (marked on

- [ ] Reload the page mid-sitting (before submitting, in a fresh repeat if needed): the wording

- [ ] Press Back to page 1 after submitting: the app handles it as it does for any completed
