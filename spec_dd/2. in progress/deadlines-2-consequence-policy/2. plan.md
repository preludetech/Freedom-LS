## Slice order

1. Config models, migration, factories, admins.
2. Settings layer, loader, checks, policy contract, `LayeredDeadlinePolicy`, effective policy on `CourseProgressAdmin`.
3. `shows_overdue` and the `mark_overdue` switch (TOC, player header, dashboard card and row) through the shared labels partial.
4. Closing: close instant, `CLOSED` status, "Closes"/"Closed" labels, closed notice, player gates.
5. Closed form with an open attempt: "Submit your answers".
6. Fixed time-limit override.
7. Access ending: decision fields, `DeadlineEnforcingBackend`, loader wrapper, the gate's route rules, dashboard, course detail, course home, restore.
8. What an ended learner can open: the ended outline and the complete-item route under `after_access_ended`.
9. QA seed states.

Each slice leaves the full test suite and the pre-commit hooks passing and is committed alone.

> **Assumed default:** slice 1 keeps all six config models and admins together, and slice 4 keeps the close instant, the labels, the notice and the gates together. Why: the six models are one repeated shape with one test file, and "Closes"/"Closed" copy and the gates must agree on one `now`, which a split would only make harder to test. To change: split slice 1 into `SiteDeadlineConfig` first and the rest in slice 2, or slice 4 into labels then gates (Slice order).

## Slice 1: Config models, migration, factories, admins

**Behaviour:** staff can create one deadline config row per site, organisation, course, cohort or registration in the admin, each switch reading Inherit / On / Off, and the database refuses an out-of-choices value, a negative grace window or a second row per owner.

### `freedom_ls/deadlines/models.py`

```python
class DeadlineSwitch(models.TextChoices):
    INHERIT = "inherit", "Inherit"
    ON = "on", "On"
    OFF = "off", "Off"


class AfterAccessEnded(models.TextChoices):
    INHERIT = "inherit", "Inherit"
    OUTLINE_AND_RESULTS = "outline_and_results", "Outline and results"
    NOTHING = "nothing", "Nothing"


SWITCH_FIELDS: tuple[str, ...] = (
    "mark_overdue", "close_items", "end_course_access", "notify_educators",
)
CONFIG_FIELDS: tuple[str, ...] = (*SWITCH_FIELDS, "grace_window", "after_access_ended")


def _switch_field(passes_to: str) -> models.CharField:
    # help_text names what "inherit" passes to, e.g. "the next layer up".
    return models.CharField(
        max_length=7, choices=DeadlineSwitch, default=DeadlineSwitch.INHERIT,
        help_text=f'"Inherit" uses {passes_to}.',
    )


class DeadlineConfigFields(models.Model):
    """The six settings a layer may set. Abstract: each layer keeps its own table."""
    mark_overdue = _switch_field(...)
    close_items = _switch_field(...)
    end_course_access = _switch_field(...)
    notify_educators = _switch_field(...)
    grace_window = models.DurationField(null=True, blank=True, help_text=...)  # null inherits; zero is a value
    after_access_ended = models.CharField(max_length=19, choices=AfterAccessEnded, default=AfterAccessEnded.INHERIT, help_text=...)

    class Meta:
        abstract = True
        constraints = [
            *(CheckConstraint(condition=Q(**{f"{f}__in": DeadlineSwitch.values}),
                              name=f"%(class)s_{f}_is_a_deadline_switch") for f in SWITCH_FIELDS),
            CheckConstraint(condition=Q(after_access_ended__in=AfterAccessEnded.values),
                            name="%(class)s_after_access_ended_is_an_after_access_ended"),
            CheckConstraint(condition=Q(grace_window__isnull=True) | Q(grace_window__gte=timedelta(0)),
                            name="%(class)s_grace_window_is_not_negative"),
        ]
```

Concrete models, each `(SiteAwareModel, TimestampedModel, DeadlineConfigFields)` with `class Meta(DeadlineConfigFields.Meta)` and a `__str__` naming the owner ("Deadline config for <owner>"):

| Model | Owner field |
| --- | --- |
| `SiteDeadlineConfig` | none; its own `Meta` sets `constraints = [*DeadlineConfigFields.Meta.constraints, UniqueConstraint(fields=["site"], name="unique_deadline_config_per_site")]` |
| `OrganisationDeadlineConfig` | `organisation = OneToOneField(Organisation, CASCADE, related_name="deadline_config")` |
| `CourseDeadlineConfig` | `course = OneToOneField(Course, ...)` |
| `CohortDeadlineConfig` | `cohort = OneToOneField(Cohort, ...)` |
| `CohortCourseRegistrationDeadlineConfig` | `cohort_registration = OneToOneField(CohortCourseRegistration, ...)` |
| `LearnerCourseRegistrationDeadlineConfig` | `learner_registration = OneToOneField(LearnerCourseRegistration, ...)` |

Import `Organisation` from `freedom_ls.organisations.models` (new edge `deadlines -> organisations`; `learner_management` already imports it, so no cycle). Then `makemigrations deadlines`, `migrate`, and `/ds:app_map` to regenerate `docs/app_structure.md` for the new edge.

### `freedom_ls/deadlines/policy.py`

```python
@dataclass(frozen=True)
class ResolvedDeadlinePolicy:
    mark_overdue: bool
    close_items: bool
    end_course_access: bool
    notify_educators: bool
    grace_window: timedelta
    after_access_ended: str          # an AfterAccessEnded value, never "inherit"
    sources: Mapping[str, str]       # field -> layer name


class DeadlinePolicy:
    def resolve(self, course_progress: CourseProgress) -> ResolvedDeadlinePolicy:
        return self.resolve_for([course_progress])[course_progress.pk]

    def resolve_for(self, records: Sequence[CourseProgress]) -> dict[UUID, ResolvedDeadlinePolicy]:
        raise NotImplementedError


def _rows_by_owner[RowT: DeadlineConfigFields](
    model: type[RowT], owner_field: str, owner_ids: Collection[UUID | int], site_id: int
) -> dict[UUID | int, RowT]:
    """One layer table, read for the given owners on one site. _base_manager, because the
    resolver also runs outside a request, where the thread-local site is unset; the explicit
    site_id keeps another site's rows out."""
    return {getattr(row, f"{owner_field}_id"): row
            for row in model._base_manager.filter(site_id=site_id, **{f"{owner_field}__in": owner_ids})}


class LayeredDeadlinePolicy(DeadlinePolicy):
    LAYER_ORDER = ("registration", "cohort", "organisation", "course", "site", "settings")

    def resolve_for(self, records):
        if not records: return {}
        site_id = records[0].site_id
        # The record carries course_id, learner_id, site_id and the two registration ids;
        # the cohort and the organisation sit one hop further, read once for all records.
        cohort_regs = {pk: (cohort_id, organisation_id) for pk, cohort_id, organisation_id in
                       CohortCourseRegistration._base_manager.filter(site_id=site_id, pk__in=...).values_list("pk", "cohort_id", "cohort__organisation_id")}
        learner_orgs = dict(Learner._base_manager.filter(site_id=site_id, pk__in=...).values_list("pk", "organisation_id"))
        site_row = SiteDeadlineConfig._base_manager.filter(site_id=site_id).first()
        course_rows = _rows_by_owner(CourseDeadlineConfig, "course", {...}, site_id)
        organisation_rows = _rows_by_owner(OrganisationDeadlineConfig, "organisation", {...}, site_id)
        cohort_rows = _rows_by_owner(CohortDeadlineConfig, "cohort", {...}, site_id)
        cohort_registration_rows = _rows_by_owner(CohortCourseRegistrationDeadlineConfig, "cohort_registration", {...}, site_id)
        learner_registration_rows = _rows_by_owner(LearnerCourseRegistrationDeadlineConfig, "learner_registration", {...}, site_id)
        return {record.pk: self._resolve_one(self._layers(record, ...)) for record in records}

    def _layers(self, record, ...) -> list[tuple[str, DeadlineConfigFields | None]]:
        """(layer name, row) in LAYER_ORDER; a missing owner gives None. The registration layer
        is the row of whichever registration minted the record; the cohort layer applies only
        to a cohort registration's record; the organisation is the cohort's, else the learner's."""

    def _resolve_one(self, layers) -> ResolvedDeadlinePolicy:
        defaults = config.DEADLINE_POLICY_DEFAULTS
        sources: dict[str, str] = {}

        def switch(field: str) -> bool:
            for layer, row in layers:
                value = getattr(row, field) if row is not None else None
                if value in (DeadlineSwitch.ON, DeadlineSwitch.OFF):
                    sources[field] = layer
                    return value == DeadlineSwitch.ON
            sources[field] = "settings"
            return bool(defaults[field])

        def grace_window() -> timedelta: ...   # first non-null row value, else defaults, typed timedelta
        def after_access_ended() -> str: ...   # first non-inherit row value, else defaults, typed str

        return ResolvedDeadlinePolicy(
            mark_overdue=switch("mark_overdue"), close_items=switch("close_items"),
            end_course_access=switch("end_course_access"), notify_educators=switch("notify_educators"),
            grace_window=grace_window(), after_access_ended=after_access_ended(), sources=sources,
        )
```

Explicit typed resolution per field kind, no dict splat. Nothing reads the `deadline_config` reverse accessors. Query budget: at most eight (two owner lookups and six layer tables), for one record and for many; `site_id` comes off the record, no site query.

## Slice 3: `shows_overdue` and the `mark_overdue` switch

**Behaviour:** with `mark_overdue` off, the "Missed deadline" chip disappears from the TOC row, the player item header and the dashboard card and row, and the date stays. Everything else is unchanged. This is the first end-to-end path from a config row to a learner page, and it introduces the shared labels partial that slice 4 extends.

### `freedom_ls/deadlines/consequences.py`

```python
def shows_overdue(resolved: ResolvedDeadline, policy: ResolvedDeadlinePolicy, completed: bool, now: datetime) -> bool:
    return policy.mark_overdue and is_overdue(resolved, completed, now)

def access_end_instant(time_limit: ResolvedDeadline, policy: ResolvedDeadlinePolicy) -> datetime | None:
    if not policy.end_course_access or time_limit.due_at is None: return None
    return time_limit.due_at + policy.grace_window
```

Pure, no queries. `access_end_instant` is read by the admin panel here; the close and access-ended functions arrive with the slices that use them.

def close_instant(resolved: ResolvedDeadline, policy: ResolvedDeadlinePolicy) -> datetime | None:

  ```python
  class DeadlineEnforcingBackend(CourseAccessBackend):
      def __init__(self, inner: CourseAccessBackend) -> None: self._inner = inner

      def _ended_decision(self, *, user: User, course: Course, inner_decision: CourseAccessDecision) -> CourseAccessDecision | None:
          """The decision for a learner whose access has ended, or None when the inner decision stands.

          Deadlines are read only once the inner backend has granted content, so a refused
          decision costs nothing extra. The imports are function-local: deadlines depends on
          learner_progress, and a module-level import here would pull both in at import time."""
          from freedom_ls.deadlines.consequences import access_end_instant, has_access_ended
          from freedom_ls.deadlines.loader import get_deadline_policy
          from freedom_ls.deadlines.resolver import course_deadlines
          from freedom_ls.learner_progress.queries import course_progress_for
          if not inner_decision.can_access_content: return None
          record = course_progress_for(user, course)
          if record is None or record.completed_time is not None: return None     # a finished course never ends
          policy = get_deadline_policy().resolve(record)
          if not policy.end_course_access: return None                              # nothing can end: skip the time-limit read
          time_limit = course_deadlines(record).time_limit
          if not has_access_ended(time_limit, policy, timezone.now()): return None
          # The funnel copy stays: the detail page's stats strip still describes the course.
          return dataclasses.replace(inner_decision, cta_label=None, cta_url=None, can_self_register=False,
                                     can_access_content=False, access_ended_at=access_end_instant(time_limit, policy),
                                     after_access_ended=policy.after_access_ended)

      def get_access(self, *, user, course):
          inner = self._inner.get_access(user=user, course=course)
          if not user.is_authenticated: return inner
          return self._ended_decision(user=user, course=course, inner_decision=inner) or inner

      def get_access_for_request(self, *, request, course):
          inner = self._inner.get_access_for_request(request=request, course=course)
          if not request.user.is_authenticated: return inner
          return self._ended_decision(user=request.user, course=course, inner_decision=inner) or inner

      # every other method delegates to self._inner, as VisibilityEnforcingBackend does
  ```
