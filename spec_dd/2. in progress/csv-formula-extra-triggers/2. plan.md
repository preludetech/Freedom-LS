## Slice 2: a trigger after leading whitespace

**Behaviour.** A cell whose first non-whitespace character is a trigger gets `'` prefixed, keeping
its leading whitespace. "Whitespace" is whatever `str.isspace()` accepts (space, NBSP, U+3000,
`\v`, `\f`, U+2028 and the rest). A cell made only of whitespace is unchanged.

**Code.** Extract the per-line test into a private helper, which Slice 3 reuses for every line:

```python
def _starts_formula(line: str) -> bool:
    # str.lstrip() strips exactly what str.isspace() accepts. The first character
    # is checked on its own because tab is both a trigger and whitespace. An
    # empty slice is "", which is never a trigger.
    return (
        line[:1] in FORMULA_TRIGGERS
        or line.lstrip()[:1] in FORMULA_TRIGGERS
    )


def escape_csv_formula(value: str) -> str:
    if _starts_formula(value):
        return f"'{value}"
    return value
```

(In this slice the whole cell is still one "line"; `"\n=1"` keeps escaping via the first-character
check.)

**Tests.** In `test_csv_safety.py`:

- Add rows to `test_escape_csv_formula_expected_results`: `" =1+1"` → `"' =1+1"`,
  `"\u00a0@SUM(A1)"` → `"'\u00a0@SUM(A1)"`, `"\u3000=1+1"` → `"'\u3000=1+1"`.
- Add `"   "` to the parametrisation of `test_escape_csv_formula_leaves_other_values_alone`.

## Slice 3: a trigger at the start of any line

**Behaviour.** A multi-line cell gets `'` inserted at the start of each line that starts a formula
(by the Slice 2 rule, searched within that line only), not only the first. Line breaks are `\r\n`,
`\r` and `\n` only. Separators and each line's leading whitespace are kept, so a clean cell comes
back identical. A cell starting with CR or LF still has its (empty) first line escaped.

**Code.** In `csv_safety.py`, split on a capturing regex so separators survive the round trip.
`str.splitlines()` is not used: it also splits on `\v`, `\f`, U+2028 and others, which spreadsheets
do not break on. Put `import re` in the import block at the top of the module, after
`from __future__ import annotations`.

```python

# Spreadsheets break cell lines on these and nothing else; \r\n comes first so it
# is taken as one break, not two.
_LINE_BREAK = re.compile(r"(\r\n|\r|\n)")


def escape_csv_formula(value: str) -> str:
    """<one sentence on the widened rule>"""
    if not value:
        return value
    # re.split with a capturing group alternates line, separator, line, ...
    parts = _LINE_BREAK.split(value)
    # A cell opening with CR or LF has an empty first line that the per-line
    # check cannot see, yet the cell still starts with a trigger.
    cell_starts_with_trigger = value[0] in FORMULA_TRIGGERS
    for index in range(0, len(parts), 2):
        if _starts_formula(parts[index]) or (index == 0 and cell_starts_with_trigger):
            parts[index] = f"'{parts[index]}"
    return "".join(parts)
```

Update the docstrings, one sentence each, without listing the characters:

- Module docstring: the helper escapes a cell when any of its lines starts with a formula trigger,
  even after leading whitespace.
- `escape_csv_formula` docstring: it prefixes `'` to each line of the cell that a spreadsheet could
  run as a formula, leaving everything else as it was.

The docstrings and comments state the reasoning only; none cites the spec, the plan or a slice.
