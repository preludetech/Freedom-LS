## Things to know before starting

- `FormProgress.objects.filter(...).update(...)` does not touch `last_updated_time`. That is
  wanted: `finalise_stale_incomplete` compares that column, and writing the paper must not make a
  sitting look touched.
- `FormProgress.save()` with no `update_fields` writes every column from the instance, so a stale
  instance would write `served_paper` back to null. Every request that can do a full save calls
  `ensure_served_paper` first, which leaves the paper on the instance. Keep that order.
- PostgreSQL `jsonb` does not keep object key order. The order of `pages`, each `children` list and
  each option list is kept because they are arrays. Never read meaning from the key order of
  `options`.
- `record_page_reached` gains a required `path` argument (Slice 3). Its existing tests in
  `form_engine/tests/test_models.py`, `form_engine/tests/test_paging.py` and
  `learner_interface/tests/views/test_form_runner.py` pass the path they already build. Their
  assertions do not change.
- The next `form_engine` migration is `0010`. If `main` gains a `form_engine` migration first, the
  rebase renumbers this one.
- Leave `compute_path` and `_condition_holds` untouched.
- `ensure_served_paper` runs inside GET requests. That is accepted: the write happens once, is
  built only from the form's own tree and changes nothing a caller chooses. Every call sits after
  its view's ownership lookup and access gate, at the exact point each slice names. Do not move a
  call above a gate, and do not add calls to views this plan does not list.
- The slices run in order, one at a time. An existing test that fails because a completed quiz sitting is read
  from its served paper is updated in the slice that makes it fail, to expect the served paper.
  Slice 7 changes only report code and report tests.

   ```python
       id: str
       children: list[str]


   class ServedPaper(TypedDict):

       pages: list[ServedPage]
       options: dict[str, list[str]]
   ```

4. New `form_engine/served_paper.py`. It imports `models` and `conditions` at module level;
   `models` only ever imports it inside a function.

   ```python
   """The paper one quiz sitting is served: its pages, their children and each
   question's options, in the order the learner sees them.

   Written once per sitting and never changed, so the sitting can be shown and
   scored the same way however the form is edited afterwards.
   """

   def build_served_paper(form: Form) -> ServedPaper:
       """The paper a sitting starting now is served: the form's current tree in authored order."""
       prefetch_related_objects([form], *SERVED_TREE_LOOKUPS)
       pages: list[ServedPage] = []
       options: dict[str, list[str]] = {}
       for page in form.pages.all():
           children = page.children()
           pages.append({"id": str(page.id), "children": [str(c.id) for c in children]})
           for child in children:
               if isinstance(child, FormQuestion):
                   option_ids = [str(o.id) for o in child.options.all()]
                   if option_ids:
                       options[str(child.id)] = option_ids
       # Provenance only: nothing rebuilds an order from the seed.
       return {"seed": secrets.randbits(63), "pages": pages, "options": options}


   def ensure_served_paper(form_progress: FormProgress) -> None:
       """Write the sitting's served paper if it is an open quiz sitting without one."""
       if (
           form_progress.served_paper is not None
           or form_progress.completed_time is not None
           or form_progress.form.strategy != FormStrategy.QUIZ
       ):
           return
       # Conditional on the column still being null, then re-read: two requests
       # racing on a sitting's first page both end up holding the first writer's paper.
       FormProgress.objects.filter(
           pk=form_progress.pk, served_paper__isnull=True
       ).update(served_paper=build_served_paper(form_progress.form))
       form_progress.served_paper = FormProgress.objects.values_list(
           "served_paper", flat=True
       ).get(pk=form_progress.pk)
   ```

### Slice 2: a sitting's path is read from its served paper

Behaviour: `current_path` and `sitting_path` return the served paper's pages, children and options
in served order, skipping items no longer found in the form. A sitting with no served paper gets
the same path as before.

**Builds on:** slice 1
**Touches:** freedom_ls/form_engine/conditions.py, freedom_ls/form_engine/tests/test_conditions.py, freedom_ls/form_engine/tests/test_queries.py, freedom_ls/form_engine/tests/test_exports.py

1. `SittingPath` carries served order. Reword the class docstring: it describes "the pages,
   questions and content blocks one sitting is asked, in the order it is asked them", keeps the
   existing definitions of authored number and position, and drops "in authored order".

   Two new fields, placed before the `init=False` fields, both defaulted so `_path` callers that
   have no served paper pass nothing:

   ```python
   # Served option order per question; None when the sitting has no served paper.
   served_options_by_question: Mapping[UUID, tuple[QuestionOption, ...]] | None = None
   # True when the served paper names a page, child or option the form lacks.
   has_missing_served_items: bool = False
   ```

   Page order comes from `children_by_page` insertion order, worked out once in `__post_init__`
   and kept in a new `init=False` field `_numbered: tuple[tuple[int, FormPage], ...]`:

   ```python
   def __post_init__(self) -> None:
       authored = {page.id: (number, page) for number, page in enumerate(self.all_pages, start=1)}
       numbered = tuple(authored[page_id] for page_id in self.children_by_page)
       object.__setattr__(self, "_numbered", numbered)
       object.__setattr__(
           self,
           "_page_positions",
           {number: position for position, (number, _) in enumerate(numbered, start=1)},
       )
       ...  # _question_positions as it is, set after _numbered because questions() reads it

   def numbered_pages(self) -> list[tuple[int, FormPage]]:
       """(authored number, page) for each on-path page, in the order the sitting meets them."""
       return list(self._numbered)
   ```

   `pages`, `questions()` and `question_positions()` read `numbered_pages()`, so they follow
   served order with no further change.

   Position-based navigation. `_page_positions` is `{authored number: position}` in served order:

   ```python
   def _number_at(self, position: int) -> int | None:
       """The authored number of the page at this position, or None when there is none."""
       if not 1 <= position <= len(self._numbered):
           return None
       return self._numbered[position - 1][0]

   def _first_number_above(self, number: int) -> int | None:
       """The first page, in path order, whose authored number is greater than `number`."""
       return next((n for n in self._page_positions if n > number), None)

   def next_page_number(self, after: int) -> int | None:
       if after in self._page_positions:
           return self._number_at(self._page_positions[after] + 1)
       return self._first_number_above(after)

   def previous_page_number(self, before: int) -> int | None:
       if before in self._page_positions:
           return self._number_at(self._page_positions[before] - 1)
       return next((n for n in reversed(self._page_positions) if n < before), None)

   def first_page_number_at_or_after(self, number: int) -> int | None:
       return number if number in self._page_positions else self._first_number_above(number)

   def reached_position(self, number: int) -> int:
       """How far along the path a sitting that reached authored page `number` has got.

       A number off the path counts as every page before the one it would land
       on, so a stored number an author's edit has shifted still compares.
       """
       if number in self._page_positions:
           return self._page_positions[number]
       landing = self._first_number_above(number)
       return self.page_count if landing is None else self._page_positions[landing] - 1

   def options_of(self, question: FormQuestion) -> list[QuestionOption]:
       """The question's options in the order this sitting is served them."""
       if self.served_options_by_question is None:
           return list(question.options.all())
       return list(self.served_options_by_question.get(question.id, ()))
   ```

   `last_page_number` and `landing_page_number` keep their bodies; they now read a served-order
   mapping. For a path in authored order every method returns what it returns today.

2. `served_path`:

   ```python
   def served_path(form: Form, served_paper: ServedPaper) -> SittingPath:
       """The path a served paper records, rebuilt over the form's current tree.

       An item missing from the form is skipped, whether it was deleted or
       moved to another form. A question moved to another page of this form is
       still shown under the page it was served on.
       """
       prefetch_related_objects([form], *SERVED_TREE_LOOKUPS)
       all_pages = tuple(form.pages.all())
       pages_by_id = {str(page.id): page for page in all_pages}
       children_by_id = {str(c.id): c for page in all_pages for c in page.children()}
       served_option_ids = served_paper["options"]
       missing = False
       children_by_page: dict[UUID, tuple[FormChild, ...]] = {}
       served_options_by_question: dict[UUID, tuple[QuestionOption, ...]] = {}
       for served_page in served_paper["pages"]:
           page = pages_by_id.get(served_page["id"])
           if page is None:
               missing = True
               continue
           children = tuple(
               children_by_id[i] for i in served_page["children"] if i in children_by_id
           )
           missing = missing or len(children) != len(served_page["children"])
           # A page that was empty when served is kept, as compute_path keeps it;
           # one whose children have all gone has nothing left to show.
           if served_page["children"] and not children:
               continue
           children_by_page[page.id] = children
           for child in children:
               if not isinstance(child, FormQuestion):
                   continue
               live = {str(option.id): option for option in child.options.all()}
               served_ids = served_option_ids.get(str(child.id), [])
               options = tuple(live[i] for i in served_ids if i in live)
               missing = missing or len(options) != len(served_ids)
               served_options_by_question[child.id] = options
       return _path(all_pages, children_by_page, served_options_by_question, missing)
   ```

   Extend `_path` with the two optional arguments and pass them through to `SittingPath`.

1. `form_engine/models.py`:

   ```python
   def record_page_reached(self, page_number: int, path: SittingPath) -> None:
       """Remember that this sitting has been shown `page_number`.

       Only ever moves forward along the path: stepping back to an earlier
       page does not forget the later one. The stored value stays an authored
       page number, the same meaning it has for every form.
       """
       if path.page_position(page_number) <= path.reached_position(self.furthest_page_reached):
           return
       self.furthest_page_reached = page_number
       self.save(update_fields=["furthest_page_reached", "last_updated_time"])
   ```

   `complete()`: inside the existing local-import block, import `ensure_served_paper` and call
   `ensure_served_paper(self)` as the first statement inside `transaction.atomic()`, before
   `current_path(self)`. `complete()` returns early for a completed sitting before this point.

2. `form_engine/paging.py`, each comparing served positions:

   ```python
   def _furthest_answered_page(path: SittingPath, answered_ids: set[UUID]) -> int | None:
       """The page furthest along the path carrying an answer to an on-path question, if any."""
       # the last match in numbered_pages() order, None when nothing is answered

   def _resume_page_number(form_progress: FormProgress, path: SittingPath) -> int:
       numbered = path.numbered_pages()
       if not numbered:
           return 1
       answered_ids = _answered_ids(form_progress)
       # furthest_page_reached is an authored number. It can outlive a page an
       # author deleted and can name a page off the path, so it is clamped to
       # the pages the form has and moved onto the path before it is compared.
       reached = path.first_page_number_at_or_after(
           min(form_progress.furthest_page_reached, len(path.all_pages))
       )
       candidates = (
           form_progress.get_current_page_number(path, answered_ids),
           _furthest_answered_page(path, answered_ids),
           reached if reached is not None else numbered[-1][0],
       )
       return max((n for n in candidates if n is not None), key=path.page_position)
   ```

### Slice 6: quiz scoring and results count only served questions

Behaviour: a sitting with a served paper is scored, reviewed and checked for an outdated score
over its served questions only. A sitting with none is scored over the whole form as today.

**Builds on:** slices 1, 2, 3, 4, 5
**Touches:** freedom_ls/form_engine/models.py, freedom_ls/form_engine/tests/, freedom_ls/learner_interface/views.py, freedom_ls/learner_interface/tests/, freedom_ls/learner_progress/tests/, freedom_ls/course_applications/tests/

1. `form_engine/models.py`. One private method holds the choice of questions, so the score and
   the incorrect-answers list can never disagree about which questions count:

   ```python
   def _quiz_questions(self, path: SittingPath | None) -> list[FormQuestion]:
       """The questions this quiz sitting is marked on.

       A sitting with a served paper is marked on the questions it was served.
       One without is marked on every question the form currently has.
       """
       if self.served_paper is None:
           return [
               child
               for page in self.form.pages.all()
               for child in page.children()
               if child.content_type == "FORM_QUESTION"
           ]
       if path is None:
           # Local import: conditions imports this module.
           from .conditions import sitting_path

           path = sitting_path(self)
       return path.questions()
   ```

     `self._quiz_questions(path)`. The body per question is unchanged, and still judges against

   - `score_quiz(self, path: SittingPath | None = None) -> None`:
     `self.scores = self.compute_quiz_scores(path)`. The default keeps the existing

   - `get_incorrect_quiz_answers(self, path: SittingPath | None = None)`: loop over
