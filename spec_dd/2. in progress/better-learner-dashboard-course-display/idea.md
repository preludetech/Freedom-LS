Currently, the learner dashboard shows courses in a fairly indiscriminate way. The first few are displayed and then the learner can go and redirect to the full course list if they want to see anything else. if they are logged in and they have already signed up for a course and their course is at the top. If they've signed up for multiple courses, then all of the courses are at the top. And that can be quite a lot if they are signed up for a lot of things.

We need a way to group different courses so that they can be displayed to the user in a more intentional way.

We may need to be able to configure how courses are grouped and ordered.

- Some courses should be highlighted for all learners. For example, we might have certain introductory courses that we want to always show at the top, like some kind of headline.
- Courses that are coming soon might need to be lower down.
- We might want to group courses by category of some sort, for example, we might have a bunch of technical courses and a bunch of emotional courses, doesn't matter, we might have different categories and those categories should show up in a given order or potentially certain categories should be displayed by default and others not.
- There should also be a way to paginate on the learner dashboard without needing to visit the full course list page.
