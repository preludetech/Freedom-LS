# Frontend QA: remove unnecessary admin panel functionality

Every page here is in the Django admin (unfold theme). Judge each page on this branch's server only.

## Setup

1. Start the server: `uv run python manage.py runserver $PORT`. Base URL: `http://127.0.0.1:$PORT`.
2. Seed the data. Each command is idempotent:
   - `uv run python manage.py qa_create_deadlines_seed` (superuser `demodev@email.com`, an
     organisation, a cohort, registrations, course progress records with pauses and extensions)
   - `uv run python manage.py qa_create_standalone_form_sitting` (a completed form sitting)
   - `uv run python manage.py qa_create_application_review_accounts` (a staff reader with view-only
     permissions on form progress, answers and answer files)
   - At least one form sitting with a file answer and at least one course application must exist.
     If the dev database has none, ask the QA data helper for one completed `FormProgress` with a
     `QuestionAnswerFile`, and one `CourseApplication` that links to it.
3. Log in at `/admin/` as `demodev@email.com` / `demodev@email.com` (superuser) unless a test says
   otherwise.

Check each page at the three QA viewports. A page that errors (500, 400, a blank filter, a broken
inline) fails, whatever the step says.
