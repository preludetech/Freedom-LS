# Frontend QA: semantic icons app, standalone

Icons now load from the app's bundled data, overlaid with the full upstream data that
`SEMANTIC_ICONS_ICONIFY_DIR` points at. No template changed, so every page should draw the same
icons as before, at the same sizes. These tests look for missing, blank or mis-sized icons, and for
authored glyphs outside the bundled set.

## Setup

- Start the server: `uv run python manage.py runserver $PORT`. The base URL is
  `http://127.0.0.1:$PORT`.
- Before starting, run `uv run python manage.py check`. Expect no `icons.*` line in its output: no
  W002 to W004, no E002, no E008.
- Log in at `/accounts/login/` with the QA login from `.claude/sdd/config.md` (`## QA Login`). That
  account is an admin and an educator.
- The demo content must be loaded, including the "functionality demo content widgets" course.
  Ask the QA data helper to load it if it is missing.
- Run every test at desktop 1920×1080. Re-run the tests marked **(viewports)** at mobile 375×812.
- Throughout, watch the browser console and the server log. Expect no `KeyError`,
  `IconResolutionError` or 500 response.

## Test 1: icons draw across the learner interface (viewports)

1. Open the home page and the course list.
2. Open a course, then a topic inside it.
3. Expect on each page:
   - Every icon draws as a visible glyph, not an empty box or a missing gap: the header menu, the
     table-of-contents toggle, the next and previous arrows, status markers (complete, in
     progress, locked) and course card icons.
   - Icons sit at their usual size next to text. None is stretched to fill its container, and none
     is tiny.
   - Mobile: the menu and table-of-contents toggles show their icons, and there is no sideways
     scroll.

## Test 2: an authored glyph outside the bundled data still renders

1. In the "functionality demo content widgets" course, open the "interactive widgets" topic.
2. Scroll to the "Custom type: Regulation" section.
3. Expect:
   - The Regulation admonition shows its label "Regulation" with a scales icon (heroicons `scale`),
     not a fallback info icon and not a blank space. Inspect it: the `<svg>` has
     `data-icon` naming `scale`.
   - The other admonitions on the page (note, warning, tip and similar) each show their own icon.

## Test 3: icons draw across the educator interface (viewports)

1. Open the educator interface from the header menu.
2. Visit the dashboard, a cohort list, a cohort's detail page, and a learner's page.
3. Open a row's "more options" menu, open a quick view and close it, then open a filter.
4. Expect:
   - The more-options (vertical ellipsis), close (×), quick view (eye), filter, sort, download and
     pagination arrows all draw.
   - The solid and mini variants used in buttons and badges draw at their small size (16 or 20 px),
     not at 24 px and not clipped.

## Test 4: error pages still carry icons

1. Visit a URL that does not exist, e.g. `/this-page-does-not-exist/`.
2. Expect: the 404 page renders (not a 500), and any icon on it draws.
