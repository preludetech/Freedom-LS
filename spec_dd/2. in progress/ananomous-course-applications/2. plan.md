# Implementation plan: anonymous course applications

Source: `1. spec.md` in this directory. The three `research_*.md` files beside it hold the
codebase facts the spec rests on.

Code snippets below are shapes, not finished files: they omit imports, and the implementer adds
them with full type hints on every function and no `Any`. Comments and docstrings inside the
snippets are written to be copied as they are. Nothing else in this document is: never copy a
sentence that names a slice into code, a test name or a template comment.

Every slice is committed on its own with `uv run manage.py makemigrations --check` clean, the
default test suite green (`uv run pytest` runs under `settings_dev`, where `ACCOUNT_RATE_LIMITS`
is `False`, so no stale rate-limit bucket can leak between tests) and the pre-commit hooks passing.
Follow TDD inside each slice: the tests a slice names are written first. Each test bullet below
is one behaviour, so it is one test; where a bullet lists several outcomes of one action, write one
test per outcome around a shared arrange helper.

## Decisions the plan makes

- **The session helpers say "allow", not "grant".** `domain-glossary` reserves "grant" for role and
  object permissions. The spec now says "allows" too.
- **The details step copies the form page's field markup instead of including it.**
  `form_engine/question.html` and `inputs/text_input.html` read `question.id`,
  `question.rendered_question` and the answers dictionary, and name their input
  `question_<uuid>`. A Django form field cannot be fed through them, so a partial in
  `course_applications` carries the same legend and input classes, with a `{% comment %}` saying
  why the class string is repeated.
- **Anonymous uploads are keyed by sitting, not by user.** `fls-dev:file-storage` wants every
  `user_uploads/` object prefixed by its user. There is no user yet, so the key is
  `user_uploads/anonymous/<form_progress_id>/form_answers/<pk><ext>`; the sitting id is the
  erasure prefix, and deletion stays row-driven through the post_delete receiver. Files keep this
  key after a claim, so a bucket-level sweep by user id does not find them and erasure goes through
  the rows (the user erasure cascades through `AnonymousApplicant` and the sitting).
- **The invalid-link page answers 200.** A scanner or a guess learns nothing from the status, and
  the page is the same for a bad signature, a used link, an unsubmitted application and an address
  owned by another site.
- **`_start_application` grows keyword arguments** (`user` or `anonymous_applicant`) instead of
  being duplicated. `get_or_create(user=None, ...)` filters on `IS NULL`, so the race safety the
  docstring describes still holds. Two simultaneous first POSTs can still both fire
  `record_application_submitted` (the signed-in path has the same window today); accepted.
- **No `site=` is passed when the claim creates rows.** The applicant is read through the
  site-filtered manager, so the claiming request's site is the applicant's, and
  `SiteAwareModelBase.save` fills `site` on the new `User` and `LegalConsent` rows.
- **Two applicants with one new address claimed in the same instant** both see no account and the
  second create hits the unique email. The second click then sees the account and attaches.
  Accepted; not handled.
- **A claim followed while signed in as somebody else** flushes that session (Django's `login`
  does this) and signs in the claimant. Accepted.
- **A mail-server error while sending the claim email propagates.** Deployments that queue mail
  never see it in the request; one that does not has an operator-visible 500 rather than a quiet
  loss.
- **Form courses keep the old login path until their slice.** Slice 1 ships the anonymous path for
  form-less courses only; an anonymous visitor on a course with a form still gets the acquisition
  login redirect until Slice 4 removes that guard. Each intermediate commit therefore works.
- **The honeypot message is parameterised.** The check and the logging stay shared and
  identical; the details step passes application wording because the person is applying, not
  signing up.

**Behaviour.** Nothing a user sees changes. `accounts/forms.py` exposes the pieces the details

### `freedom_ls/accounts/forms.py`

```python
HONEYPOT_SIGNUP_MESSAGE = _(
    "We couldn't process this sign-up. If you used autofill or a password manager, "
    "please try typing your details in by hand."
)


def honeypot_field() -> forms.CharField:
    """The honeypot: bots fill it, people never see it. The name must not be one
    that browsers or password managers autofill, or real people get rejected."""
    return forms.CharField(required=False, widget=HoneypotInput(attrs={...}),
                           label=_("Leave this field empty"))


def reject_honeypot(form: forms.Form, request: HttpRequest | None, message: StrPromise) -> None:
    """Refuse a submission whose honeypot is filled, logging the site and IP, never the values."""
    if not form.cleaned_data.get("fax_number"):
        return
    _log_honeypot_trip(request)
    # Don't say which check failed, but give a person a way forward.
    form.add_error(None, message)


def apply_signup_name_policy(form: forms.Form, policy: SiteSignupPolicy | None) -> None:
    """Make first_name optional when the site's policy does not require a name."""
    if not get_effective_require_name(policy):
        form.fields["first_name"].required = False
        form.fields["first_name"].label = _("First name (optional)")
```

`_log_honeypot_trip` becomes a module function taking the request and keeps its `request is
None` branch and the "Signup honeypot tripped" wording. `SiteAwareSignupForm` sets `fax_number =
honeypot_field()`, its `clean` calls `reject_honeypot(self, _get_request_or_none(),
HONEYPOT_SIGNUP_MESSAGE)`, and its `__init__` calls `apply_signup_name_policy(self, policy)` in
place of the inline block. The consent block and the `RuntimeError` branch stay in `__init__`
for now.

## Slice 1: anonymous apply on a form-less course, end to end

**Behaviour.** An anonymous visitor who opens Apply on a form-less `application_gated` course is
sent to the applicant details step. A valid POST (email, names per `SiteSignupPolicy`, honeypot)
stores an `AnonymousApplicant`, remembers it in the session, and lands on `apply.html`, whose
Previous goes back to the details step. Its POST creates an unverified `CourseApplication` and
redirects to the status page, which says the application was received. No `User` is created and
no `User` row is read. Signed-in apply is unchanged. An anonymous visitor on a course with a form
still gets the login redirect.

### Model and migration: `freedom_ls/course_applications/models.py`

```python
class AnonymousApplicant(SiteAwareModel, TimestampedModel):
    """What an anonymous visitor said about themselves when applying to one course.

    No User exists until the claim link in the post-submit email is followed:
    creating one earlier would collide with the globally unique email and fire
    signup side effects for an address nobody has proven they own. The consent
    evidence lives here for the same reason and is copied into LegalConsent rows
    once there is a user to attach it to.
    """

    course = models.ForeignKey("freedom_ls_content_engine.Course", on_delete=models.CASCADE,
                               related_name="anonymous_applicants")
    # Stored stripped and lowercased, so the rate-limit key and the claim lookup
    # see one spelling of an address.
    email = models.EmailField()
    first_name = models.CharField(max_length=200, blank=True, default="")
    last_name = models.CharField(max_length=200, blank=True, default="")
    terms_version = models.CharField(max_length=64, blank=True, default="")
    terms_git_hash = models.CharField(max_length=64, blank=True, default="")
    privacy_version = models.CharField(max_length=64, blank=True, default="")
    privacy_git_hash = models.CharField(max_length=64, blank=True, default="")
    consent_ip_address = models.GenericIPAddressField(null=True, blank=True)
    consented_at = models.DateTimeField(null=True, blank=True)
    user = models.ForeignKey(settings.AUTH_USER_MODEL, null=True, blank=True,
                             on_delete=models.CASCADE, related_name="anonymous_applications")
    # Set once. A claim link whose applicant carries this is already used.
    claimed_at = models.DateTimeField(null=True, blank=True)
```

### Session map: `freedom_ls/course_applications/anonymous_session.py` (new)

```python
ANONYMOUS_APPLICANTS_SESSION_KEY = "course_applications_anonymous_applicants"


def _session_map(request: HttpRequest) -> dict[str, str]:
    stored: dict[str, str] = request.session.get(ANONYMOUS_APPLICANTS_SESSION_KEY, {})
    return stored


def remember_anonymous_applicant(request: HttpRequest, applicant: AnonymousApplicant) -> None:
    # A new dict, not an in-place write, so the session middleware's dirty
    # check sees the change.
    request.session[ANONYMOUS_APPLICANTS_SESSION_KEY] = {
        **_session_map(request), str(applicant.course_id): str(applicant.pk)
    }


def forget_anonymous_applicant(request: HttpRequest, applicant: AnonymousApplicant) -> None:
    request.session[ANONYMOUS_APPLICANTS_SESSION_KEY] = {
        course_id: pk for course_id, pk in _session_map(request).items()
        if pk != str(applicant.pk)
    }


def anonymous_applicant_for_course(request: HttpRequest, course: Course) -> AnonymousApplicant | None:
    """The applicant this session holds for the course, until somebody claims it.

    The application rides along, because every caller asks for it next.
    """
    pk = _session_map(request).get(str(course.pk))
    if pk is None:
        return None
    return (
        AnonymousApplicant.objects.filter(pk=pk, course=course, user__isnull=True)
        .select_related("course_application__form_progress__form")
        .first()
    )


def application_of(applicant: AnonymousApplicant) -> CourseApplication | None:
    # hasattr, because a missing reverse one-to-one raises rather than returning None.
    return applicant.course_application if hasattr(applicant, "course_application") else None


def owned_applications(request: HttpRequest) -> QuerySet[CourseApplication]:
    """The applications this request may act on.

    A signed-in user owns the applications that name them. An anonymous visitor
    owns an unverified application whose applicant their session remembers; the
    moment a claim sets `user`, only that signed-in user reaches it. Site
    isolation is automatic through the manager, so another host's session
    resolves nothing.
    """
    if request.user.is_authenticated:
        return CourseApplication.objects.filter(user=request.user)
    return CourseApplication.objects.filter(
        user__isnull=True, anonymous_applicant__pk__in=list(_session_map(request).values())
    )
```

```python
def _anonymous_login_redirect(request: HttpRequest) -> HttpResponse:
    return redirect_to_auth(request, next_url=request.get_full_path(),
                            auth_url=acquisition_auth_url(request))


def _anonymous_apply(request: HttpRequest, course: Course) -> HttpResponse:
    if course.application_form is not None:
        return _anonymous_login_redirect(request)
    if course.visibility == CourseVisibility.COMING_SOON:
        return redirect("learner_interface:course_detail", course_slug=course.slug)
    applicant = anonymous_applicant_for_course(request, course)
    if applicant is None:
        return redirect("course_applications:applicant_details", course_slug=course.slug)
    app = application_of(applicant)
    if app is not None:
        if not app.is_submitted and app.form_progress is not None:
            return redirect(_resume_url(app, app.form_progress))
        return redirect("course_applications:status", pk=app.pk)
    if request.method == "POST":
        app = _start_application(course, anonymous_applicant=applicant)
        record_application_submitted(request, course)
        return redirect("course_applications:status", pk=app.pk)
    return render(request, "course_applications/apply.html", {
        "course": course,
        "previous_page_url": reverse("course_applications:applicant_details",
                                     kwargs={"course_slug": course.slug}),
    })
```

```python
def allow_anonymous_form_progress(request: HttpRequest, form_progress: FormProgress) -> None:
    """Let this session act on a sitting that has no user.

    resolves it for this session the way it resolves a signed-in owner's.

    pk = str(form_progress.pk)

    """The sittings this request may act on: the signed-in user's, or the
    user-less ones this session was allowed. A sitting that gains a user drops
    out of the anonymous branch at once."""
    if request.user.is_authenticated:

    return FormProgress.objects.filter(user__isnull=True, pk__in=_allowed_pks(request))
```

```python
CLAIM_TOKEN_SALT = "freedom_ls.course_applications.claim"


@dataclass(frozen=True)
class ClaimLink:
    applicant: AnonymousApplicant
    expired: bool


def claim_token(applicant: AnonymousApplicant) -> str:
    return signing.dumps(str(applicant.pk), salt=CLAIM_TOKEN_SALT)


def claim_url(request: HttpRequest, applicant: AnonymousApplicant) -> str:
    return request.build_absolute_uri(
        reverse("course_applications:claim", kwargs={"token": claim_token(applicant)})
    )


def read_claim_token(token: str) -> ClaimLink | None:
    """The applicant a claim token names, and whether the token has expired.

    None for a token that was never ours, or whose applicant this site cannot
    see. The expiry matches the signup confirmation link, so one setting
    governs both.
    """
    max_age = timedelta(days=allauth_account_settings.EMAIL_CONFIRMATION_EXPIRE_DAYS)
    try:
        pk = signing.loads(token, salt=CLAIM_TOKEN_SALT, max_age=max_age)
        expired = False
    except signing.SignatureExpired:
        # The signature is good; only its age failed. The applicant is still
        # needed, to offer a fresh link to the same address.
        pk = signing.loads(token, salt=CLAIM_TOKEN_SALT)
        expired = True
    except signing.BadSignature:
        return None
    applicant = AnonymousApplicant.objects.filter(pk=pk).select_related("course").first()
    return None if applicant is None else ClaimLink(applicant, expired)


@dataclass(frozen=True)
class ClaimOutcome:
    user: User
    user_was_created: bool


def attach_claimed_application(request: HttpRequest, application: CourseApplication) -> ClaimOutcome | None:
    """Attach an unverified application to the account that owns its address.

    One transaction, with the applicant row locked, so two clicks on the same
    link converge on one claim. None means nothing changed: the link was
    already used, or the address belongs to an account this site may not touch.
    """
    with transaction.atomic():
        applicant = AnonymousApplicant.objects.select_for_update().get(
            pk=application.anonymous_applicant_id
        )
        if applicant.claimed_at is not None:
            return None
        # _base_manager: the request's site filter would hide an account on
        # another site, and the globally unique email would then refuse the
        # create with an IntegrityError instead of a quiet refusal.
        existing = User._base_manager.filter(email__iexact=applicant.email).first()
        if existing is not None:
            return None
        user = _create_claimed_user(applicant)
        _write_legal_consents(applicant, user)
        _attach(application, applicant, user)
    announce_user_registered(request, user)
    # The attribution receiver listens here; sending the signal keeps its
    # best-effort handling rather than copying it.
    user_signed_up.send(sender=User, request=request, user=user)
    return ClaimOutcome(user, user_was_created=True)


def _attach(application: CourseApplication, applicant: AnonymousApplicant, user: User) -> None:
    application.user = user
    application.save(update_fields=["user", "updated_at"])
    if application.form_progress is not None:
        application.form_progress.user = user
        application.form_progress.save(update_fields=["user", "last_updated_time"])
    applicant.user = user
    applicant.claimed_at = timezone.now()
    applicant.save(update_fields=["user", "claimed_at", "updated_at"])


def _create_claimed_user(applicant: AnonymousApplicant) -> User:
    user = User(email=applicant.email, first_name=applicant.first_name,
                last_name=applicant.last_name)
    # The applicant chooses a password right after the claim; create_user
    # demands one up front, so the row is built directly.
    user.set_unusable_password()
    user.save()
    # Verified by construction: the claim link only ever went to this address.
    EmailAddress.objects.create(user=user, email=user.email, verified=True, primary=True)
    return user


def _write_legal_consents(applicant: AnonymousApplicant, user: User) -> None:
    for doc_type, version, git_hash in (
        ("terms", applicant.terms_version, applicant.terms_git_hash),
        ("privacy", applicant.privacy_version, applicant.privacy_git_hash),
    ):
        if not version:
            continue
        LegalConsent.objects.create(user=user, document_type=doc_type, document_version=version,
                                    git_hash=git_hash, ip_address=applicant.consent_ip_address,
                                    consent_method="application_details_step")
```

### `views.py` and `urls.py`

```python
def claim_application(request: HttpRequest, token: str) -> HttpResponse:
    """Follow the emailed link: confirm on GET, claim on POST.

    GET changes nothing because mail scanners fetch links. Every way the link
    can be unusable renders the same page, so a guessed or reused token learns
    nothing about who applied.
    """
    link = read_claim_token(token)
    application = application_of(link.applicant) if link is not None else None
    if (link is None or link.applicant.claimed_at is not None
            or application is None or not application.is_submitted):
        return _render_claim(request, "invalid")
    if link.expired:
        return _render_claim(request, "expired", link.applicant)
    if request.method != "POST":
        return _render_claim(request, "confirm", link.applicant)
    outcome = attach_claimed_application(request, application)
    if outcome is None:
        return _render_claim(request, "invalid")
    forget_anonymous_applicant(request, link.applicant)
    if not outcome.user.is_active:
        return redirect("account_login")
    # Logging in cycles the session key, so the anonymous session's identifier
    # never carries over into the signed-in one.
    get_adapter(request).login(request, outcome.user)
    status_url = reverse("course_applications:status", kwargs={"pk": application.pk})
    if outcome.user_was_created:
        return redirect(f"{reverse('account_set_password')}?{urlencode({'next': status_url})}")
    return redirect(status_url)
```

### `freedom_ls/course_applications/emails.py` (new)

```python
def send_application_claim_email(request: HttpRequest, applicant: AnonymousApplicant) -> None:
    """Email the applicant the link that attaches their application to an account.

    The same email goes to every applicant, whether or not the address already
    has an account, so nothing about the send depends on what the mailbox
    owner will find out when they follow it. Once the per-address limit is
    hit the send is skipped and the caller's page is unchanged; a different
    response would say which addresses are busy.
    """
    if not ratelimit.consume(request, action="application_claim_email",
                             key=email_rate_limit_key(applicant.site, applicant.email)):
        return
    get_adapter(request).send_mail(
        "course_applications/email/application_claim",
        applicant.email,
        {"course": applicant.course, "claim_url": claim_url(request, applicant),
         "site_name": site_display_name_for_request(request)},
    )
```

### `freedom_ls/course_applications/erasure.py` (new)

```python
def erase_anonymous_applicant(applicant: AnonymousApplicant) -> None:
    """Erase an applicant and everything they left behind.

    The application cascades from the applicant. The sitting does not: the
    application names it with RESTRICT, so it is removed by hand once the
    application is gone, which takes the answers and, through the file row's
    post_delete receiver, the stored files.
    """
    application = application_of(applicant)
    form_progress_id = application.form_progress_id if application is not None else None
    with transaction.atomic():
        applicant.delete()
        if form_progress_id is not None:
            FormProgress.objects.filter(pk=form_progress_id).delete()
```

```python
def applicant_label(form_progress: FormProgress) -> str:
    """Who sat this form: the user, or the unverified email its application holds.

    The application is reached only through its reverse accessor; the app that
    owns it sits above this one and may not be installed.
```
