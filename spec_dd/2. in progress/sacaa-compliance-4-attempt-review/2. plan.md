## Decisions taken while planning

- The header title is the instance label, "<quiz title>, attempt N"; the subtitle carries the
  learner and the course.
- The openable check also requires the sitting's user to be the course progress record's learner.
- `detail_row` gains a generic `"datetime"` kind (slice 3).
- `QuizAttemptConfig` names no `view_capability`, as `LearnerConfig` names none; `VIEW_LEARNER`
  is enforced by the openable check.
- The groundwork slices (1 to 5) stay separate from the page slices (6 to 10).

> **Assumed default:** an organisation switch made from an attempt review lands on the other
> organisation's first visible section. Why: a sitting belongs to one organisation's learner and
> the section has no list to fall back to. To change: slice 6, "Organisation switch".

> **Assumed default:** a course another organisation owns reads "· Shared by <organisations>" in
> the header subtitle, built inline from `Course.shared_by()`. Why: the cohort and learner pages
> already build that wording the same way. To change: slice 6, "Page".

> **Assumed default:** the per-question verdict is an icon with words, not a status badge. Why:
> it matches `<c-correct-answer-mark>` and the learner results page. To change: slice 7,
> "Verdict partial".

  unchanged. `score_quiz` keeps calling it with `path` alone.
- `form_engine/queries.py`:

  ```python
  def stored_score_outdated(
      form_progress: FormProgress,
      path: SittingPath | None,
      answers: Mapping[UUID, QuestionAnswer] | None = None,
  ) -> bool:
      """Whether the score stored at submission disagrees with what the same
      answers earn under the current marking.

      Scores are frozen at submission and never rescored. max_score is
      compared too: a quiz that gained or lost a question shows a stale
      percentage the score alone cannot catch. A served item missing from
      the form shrinks the recomputed score although marking is unchanged,
      so such a sitting is never reported as outdated.
      """
      if form_progress.form.strategy != FormStrategy.QUIZ or not form_progress.scores:
          return False
      if path is not None and path.has_missing_served_items:
          return False
      current = form_progress.compute_quiz_scores(path, answers)
      return any(
          form_progress.scores.get(key) != current[key]
          for key in ("score", "max_score")
      )
  ```

- `learner_interface/views.py` (the quiz results view, around line 2185): replace the inline
  block with `score_outdated = stored_score_outdated(form_progress, path)` and pass it to the
  template under the existing context key `stored_score_outdated`, so the template is unchanged.
  `path` is already `None` there for a sitting with no `served_paper`. The block's two
  explanatory comments now live in the function's docstring; remove them from the view.

- `test_queries.py`: unchanged marking → False; a correct option changed after submission → True;

**Openable predicate.** One function, used by `authorise_instance` (one pk) and the Courses tab
(one learner's pks):

```python
def openable_sitting_ids(
    request: OrganisationScopedRequest,
    sitting_ids: Collection[UUID],
    shown_registrations: Mapping[UUID, Sequence[LearnerRegistrationProgress]]
    | None = None,
) -> set[UUID]:
    """The sittings among `sitting_ids` this educator may open: completed
    quiz sittings with a course form attempt, sat by the learner the course
    progress record belongs to, whom the educator sees in this organisation,
    on a registration the Courses tab shows them.

    A registration made through a cohort the educator cannot see is hidden
    on the tab, so its sittings must not open from a guessed URL either.

    `shown_registrations` maps a learner's pk to the registrations the tab
    already loaded for them, so the tab does not load them twice. The
    queries grow with the number of learners named, never with the number
    of sittings.
    """
    sittings = FormProgress.objects.filter(
        pk__in=sitting_ids,
        completed_time__isnull=False,
        form__strategy=FormStrategy.QUIZ,
        course_attempt__isnull=False,
        # The paper shows the sitting user's answers, so that user must be
        # the learner the educator was authorised to see.
        user_id=F("course_attempt__course_progress__learner__user_id"),
    ).select_related("course_attempt__course_progress__learner")
    records = {s.pk: s.course_attempt.course_progress for s in sittings}
    learners = {record.learner_id: record.learner for record in records.values()}
    visible_learner_ids = set(
        learners_visible_to(request.user, request.organisation, include_inactive=True)
        .filter(pk__in=list(learners))
        .values_list("pk", flat=True)
    )
    shown = shown_registrations or {}
    shown_registration_ids = {
        entry.registration.pk
        for learner_id in visible_learner_ids
        for entry in (
            shown[learner_id]
            if learner_id in shown
            else visible_registrations_with_progress(learners[learner_id], request)
        )
    }
    return {
        pk
        for pk, record in records.items()
        if record.learner_id in visible_learner_ids
        and (record.cohort_registration_id or record.learner_registration_id)
        in shown_registration_ids
    }
```

`FormProgress.objects` is the site-filtered manager; add no site filter by hand.

```python
@dataclass(frozen=True)
class QuizAttemptFacts:

    learner: Learner
    course: Course

def quiz_attempt_facts(sitting: FormProgress) -> QuizAttemptFacts:

@dataclass(frozen=True)
class QuizAttemptResult:
    score: int | None
    max_score: int | None
    percentage: int | None
    passed: bool | None

    """The stored score and the verdict against the quiz's current pass mark."""
```

**Section config.**

```python
class QuizAttemptConfig(OrganisationSectionConfig, ListViewConfig):
    url_name = "quiz-attempts"
    menu_label = "Quiz attempts"
    model = FormProgress
    list_view = None
    in_menu = False
    instance_view = QuizAttemptInstanceView

    @classmethod
    def authorise_instance(cls, request: HttpRequest, instance: Model) -> None:
        scoped = cast(OrganisationScopedRequest, request)
        if instance.pk not in openable_sitting_ids(scoped, [instance.pk]):
            raise OrganisationScopeDenied

    @classmethod
    def get_instance_label(cls, instance: Model) -> str:
        facts = quiz_attempt_facts(cast(FormProgress, instance))
        return f"{facts.sitting.form.title}, attempt {facts.attempt_number}"

    @classmethod
    def get_back_link(cls, request: HttpRequest, instance: Model) -> tuple[str, str]:
        facts = quiz_attempt_facts(cast(FormProgress, instance))
        organisation = cast(OrganisationScopedRequest, request).organisation
        return (
            f"Back to {facts.learner.user.display_name}",
            interface_path(organisation, f"learners/{facts.learner.pk}/__tabs/courses"),
        )
```

**Context builder** in `quiz_attempt.py`:

```python
QuestionVerdict = Literal["correct", "incorrect", "not_marked"]

@dataclass(frozen=True)
class QuestionMark:
    verdict: QuestionVerdict
    answered: bool

def _mark(
    question: FormQuestion,
    path: SittingPath,
    answers: Mapping[UUID, QuestionAnswer],
) -> QuestionMark: ...

def quiz_attempt_paper_context(sitting: FormProgress) -> dict[str, object]:
    """Every page of the sitting's path with its children, the learner's
    answers and a mark per question.

    The path is the only source of pages, children, option order and
    numbering, so the review stays right when what a path holds changes.
    """
    # Options for every question in one query, so marking a sitting with no
    # served paper costs no more queries than one with.
    prefetch_related_objects([sitting.form], *SERVED_TREE_LOOKUPS)
    answers = answers_by_question(sitting)
    path = sitting_path(sitting, answers)
    return {
        "paper_pages": [
            {"position": position, "page": page, "page_children": path.children_of(page)}
            for position, page in enumerate(path.pages, start=1)
        ],
        "total_pages": path.page_count,
        "sitting_path": path,
        "question_positions": path.question_positions(),
        "existing_answers": answers,
        "show_answer_key": True,
        "question_marks": {q.id: _mark(q, path, answers) for q in path.questions()},
        "score_outdated": stored_score_outdated(sitting, path, answers),
        "has_missing_served_items": path.has_missing_served_items,
        "predates_served_order": sitting.served_paper is None,
    }
```

- `stored_score_outdated` takes `path` as it is: `compute_quiz_scores` reads a path only for a
  sitting with a served paper, so a sitting without one is scored as the learner view scores it.
- `_mark`: `options = path.options_of(question)`; the answer is `answers.get(question.id)`;
  selected ids come from its prefetched `selected_options.all()`. Verdict is `"not_marked"` when
  no option has `correct is True`, else `"correct"` when
  `is_quiz_answer_correct(selected_ids, options)`, else `"incorrect"`. `answered` is True when
  the answer exists and has a selected option, a text answer or a file. It reads nothing but the
  prefetched answers and `options_of`.
- A sitting with no answers at all shows every question as "Did not answer", which the verdict
  partial handles.
