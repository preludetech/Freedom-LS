Currently, when an anonymous user tries to apply for a course, then we only send them an email to validate their email address when they've finished filling in the application. Instead, let's send it as soon as they've submitted the first page.

Also, If an anonymous user exits their course application and goes back to the dashboard, then they don't see their incomplete application at the top of the page, but they should. It is stored in the session somehow, and so they should be able to jump back into it if they're on the same browser, because it's stored there.
