## Conventions for every new module

Copy the shape of `freedom_ls/educator_interface/panels/common/filters.py`:

```python
"""<one line: what the module holds>."""

from __future__ import annotations

# absolute imports only

__all__ = [
    # every name the module defines, underscore names included,
    # in the order ruff RUF022 sorts it
]
```

Let `uv run ruff check --fix` sort `__all__` (RUF022), and let ruff (F401, F821) decide which imports each new module needs and which ones each flat module drops. Never hand-guess an import list.

Production docstrings:

- `panels/staff/filters.py`: "The role filter for the educator interface's Staff table."
- `panels/staff/quick_view.py`: "The quick view of a staff member on the Staff table."
- `panels/staff/actions.py`: "Staff role helpers, refusals and the actions on staff members and their roles."
- `panels/staff/data_tables.py`: "The Staff table of the educator interface."
- `panels/staff/config.py`: "The Staff section of the educator interface."

Test module docstrings follow the same rule, for example "Tests for the staff actions."

## Shared test helpers and fixtures

Each slice moves the helpers and fixtures its tests need, under their current names, into:

- `freedom_ls/educator_interface/tests/helpers.py` for plain helpers;
- `freedom_ls/educator_interface/tests/conftest.py` for fixtures.

The flat test file then imports a helper from `tests/helpers.py` instead of defining it, and relies on the conftest fixture. A test module never imports from another test module. Helpers that serve only the moved tests move with them into the new test file.

Before cutting any slice, re-run the dependency check on that slice: list every module-level helper and fixture defined inside the slice that a staying test uses, and every one defined outside it that a moved test uses. A small `ast` script that collects `Name` and `arg` nodes on each side does this; write it to the session scratchpad, not the repo. The lists below are what that check found on the starting tree.

Some private helper names are defined in more than one flat test file with different bodies: `_staff_member_row` (`test_views.py` and `test_actions.py`), `_cohort_url` (`test_actions.py` and `test_views.py`) and `_remove_triggers` (`test_actions.py` and `test_views.py`). Each file keeps or carries its own definition unchanged. A file that defines one of these locally does not also import the same name from `tests/helpers.py`, so the local definition is the one it uses.
