Conventions for every slice:

- Tests of plugin scripts live in `tests/`, carry `pytestmark = pytest.mark.dev_tooling`, build their
  own git repositories under `tmp_path`, and run the script as a subprocess. A check repeated over
  a list of files or values is one parametrized test, never a loop in a test body.
- New Python scripts are stdlib only, typed, and take `--project-root` (default: the current
  directory) so a test can point them at a `tmp_path` tree. A usage error exits 64: the parser's
  `error` method is overridden, since argparse's own exit code is 2.
- sdd and ds stay generic: no FLS name, path or value goes into either, and no ds path or skill
  name goes into sdd, examples and test fixtures included. A new sdd script names no plugin
  directory except its own (`Path(__file__).resolve().parents[1]`).
- A file moved out of a command goes under `claude_plugins/sdd/resources/`, never under
  `commands/`: every `.md` under `commands/` becomes a slash command.
- A slice that returns `blocked` or `paused` on something only the user can do first adds an
  unticked `(user)` line to `todo.md` with `sdd:protected:update_todo`.

### Slice 1: Prompt-size baseline

Delivers `measure_prompt_size.py` and the baseline it prints, taken before any prompt changes
(Requirement 18).

**Builds on:** none
**Touches:** claude_plugins/sdd/scripts/measure_prompt_size.py, tests/test_measure_prompt_size.py, claude_plugins/sdd/commands/init.md, .claude/settings.json, spec_dd/2. in progress/spec_dd_efficiency_and_docs/token_baseline.md

`measure_prompt_size.py [--project-root DIR]` prints a markdown table, one row per file, sorted by
path, then a total row, then an `## Unmeasured` list (or `(none)`):

```
| File | Lines | Words | Approx tokens |
```

```python
MEASURED_DIRS = ("commands", "resources", "agents", "skills")   # under the script's own plugin
PLUGIN_ROOT_REFERENCE = re.compile(r"\$\{CLAUDE_PLUGIN_ROOT\}/([\w./-]+)")

def measured_files(project_root: Path) -> tuple[list[Path], list[str]]:
    """The files an SDD run loads, and the references that could not be measured."""
    files: set[Path] = set()
    unmeasured: set[str] = set()
    # A README is the human guide: no command reads it, so it is not prompt size.
    files |= every *.md under PLUGIN/<dir> for dir in MEASURED_DIRS, except README.md
    for name in (".claude/sdd/config.md", ".claude/sdd/config.local.md"):
        for value in bullet values of project_root / name:      # "- Key: value"
            a skill name ("plugin:skill")                     -> unmeasured
            path-shaped and a file under the project root     -> files
            path-shaped and missing, or outside the root      -> unmeasured
            anything else (blank, a number, a URL, a sentence) is ignored
    for each ${CLAUDE_PLUGIN_ROOT}/<path> in a measured sdd file:
        a file under PLUGIN -> files; anything else -> unmeasured
    return sorted(files), sorted(unmeasured)

def approx_tokens(text: str) -> int:
    return len(text) // 4
```

A config value is path-shaped when its first whitespace-separated word contains `/`, ends in a
file extension and holds no `://`, so a command such as `scripts/check.sh --capacity` resolves to
its script. Every path is resolved before it is read, and one that leaves the project root or the
plugin is never opened.

Tests (`tests/test_measure_prompt_size.py`). The script always measures its own plugin, so each
test runs it with `--project-root` pointing at a `tmp_path` that holds only a
`.claude/sdd/config.md`:

- parametrized over each `claude_plugins/sdd/commands/*.md` file except `README.md`: the file has
  a row;
- `README.md` has no row;
- a config value naming a file under the project root has a row whose lines, words and tokens
  equal the figures the test fixed when it wrote that file;
- a config value naming a missing path, one naming a path outside the project root (`../x.md`),
  and a skill name are each listed under `## Unmeasured` (parametrized);
- a URL value and a plain-word value are neither a row nor unmeasured (parametrized).

Allow entry, so a mechanic can run the script unprompted: add
`Bash(python3 claude_plugins/sdd/scripts/measure_prompt_size.py:*)` to `.claude/settings.json`. In
`init.md` Step 1, after item 2, add an item: for each Python script the commands call by name
(this one; slices 3 and 16 extend the list), add
`Bash(python3 <PLUGINS_ROOT>/claude_plugins/sdd/scripts/<name>.py:*)` if absent. Extend
verification item 2 to check it.

Then run the script from the project root and save the output as `token_baseline.md` in this
directory, with one line above the table naming the commit it was measured at.

### Slice 3: Full-run record and the checkpoint tier

Delivers Requirement 1: `run_test_tier.md` accepts `<tier>: checkpoint`, and a passing full run
writes the full-run record.

**Builds on:** slice 2
**Touches:** claude_plugins/sdd/scripts/full_run_record.py, tests/test_full_run_record.py, claude_plugins/sdd/commands/protected/run_test_tier.md, claude_plugins/sdd/commands/init.md, .claude/settings.json

`full_run_record.py` has three verbs:

```python
RECORD_DIR = ".sdd-work"
FULL_SHA = re.compile(r"[0-9a-f]{40}")
Tier = Literal["none", "targeted", "full"]
Verdict = Literal["pass", "fail", "incomplete"]

def current_branch(project_root: Path) -> str | None:
    """The checked-out branch (`git symbolic-ref --quiet --short HEAD`), or None when
    HEAD is detached."""

def record_path(project_root: Path, branch: str) -> Path:
    # Percent-encoding keeps "/" out of the file name without letting two branch names
    # ("a/b" and "a_b") share one record.
    return project_root / RECORD_DIR / f"full_run_record_{quote(branch, safe='')}.txt"

def read(project_root: Path) -> str | None:
    """The recorded commit SHA. None when HEAD is detached, when there is no record, or
    when the file holds anything but one full-length SHA: the value reaches git and the
    selector as an argument, so nothing else is let through."""

def commit_exists(project_root: Path, sha: str) -> bool:
    """git rev-parse --verify --quiet <sha>^{commit}"""

@dataclass(frozen=True)
class Resolution:
    tier: Tier
    diff: str          # the selector's diff arguments for a targeted run, else ""
    why: str

def selected_tier(project_root: Path, selector: list[str], *diff: str) -> Tier:
    """The tier the selector prints for a diff. A selector that fails, or prints no tier
    line, counts as full: an unknown change is never skipped."""
    run [*selector, *diff] with cwd=project_root, never through a shell;
    return the value of its first "tier:" line

def resolve(project_root: Path, selector: list[str] | None) -> Resolution:
    if selector is None:
        return Resolution("full", "", "no tier selector")
    if selected_tier(project_root, selector, "--range", "origin/main..HEAD") == "none":
        return Resolution("none", "", "the branch holds no test-visible change")
    sha = read(project_root)
    if sha is None:
        return Resolution("full", "", "no full-run record")
    if not commit_exists(project_root, sha):
        return Resolution("full", "", f"recorded commit {sha[:7]} no longer resolves")
    # `git diff A..HEAD` compares two trees, so the range still works after a rebase
    # moved the recorded commit off the branch. --working-tree adds uncommitted edits,
    # which the range alone would leave out of a "nothing changed" answer.
    diff = ("--range", f"{sha}..HEAD", "--working-tree")
    tier = selected_tier(project_root, selector, *diff)
    if tier == "none":
        return Resolution("none", "", f"no test-visible change since full green at {sha[:7]}")
    if tier == "targeted":
        return Resolution("targeted", " ".join(diff), f"range {sha[:7]}..HEAD")
    return Resolution("full", "", f"the selector escalates over {sha[:7]}..HEAD")

def write(project_root: Path, verdict: Verdict) -> str:
    """Record HEAD after a passing full run on a clean tree. Returns what happened."""
    if verdict != "pass":
        return f"not recorded: verdict {verdict}"
    if current_branch(project_root) is None:
        return "not recorded: HEAD is detached"
    # Untracked files do not block the record: a stray one would otherwise force a full
    # run at every checkpoint.
    if `git status --porcelain --untracked-files=no` prints anything:
        return "not recorded: working tree not clean"
    write HEAD's SHA to record_path(...)
    return f"recorded: {sha}"
```

CLI: `read` prints the SHA or nothing. `resolve [--selector "<command>"]` prints `tier:`, `diff:`
and `why:` lines. `write --verdict pass|fail|incomplete` prints the returned line. `--selector` is
split with `shlex.split`, and its first word must resolve to a file under the project root;
anything else is a usage error. All three exit 0; a usage error exits 64.

> **Assumed default:** the selector reaches the script as a `--selector` argument that
> `run_test_tier.md` takes from the tier definition, confined to a file under the project root.
> Why: the tier definition is prose in another plugin, so the script cannot read the selector's
> path from it, and a new config key would duplicate what `Test tiers` already names. To change:
> this slice.

Tests (`tests/test_full_run_record.py`), each in a temporary repository with an origin, with a
`pyproject.toml` whose `[tool.test_tiers]` marks `spec_dd/**` as `none`, and a copy of the
repository's own selector script inside the temporary project as `--selector`:

- no record → `full`;
- a record, then only `spec_dd/**` changed → `none`, and the `why:` names the recorded SHA;
- a record, then an app file changed → `targeted` with `diff: --range <sha>..HEAD --working-tree`;
- a record, then an uncommitted edit to an app file → `targeted`;
- a record, then `uv.lock` changed → `full`;
- a record file holding a SHA that does not exist, and one holding `--help` → `full`
  (parametrized);
- a record written before the branch was rebased onto a moved `origin/main` → the tier of what
  changed since, with main's escalating change forcing `full`;
- a spec-only branch with no record → `none`;
- no `--selector` → `full`; a `--selector` outside the project root → exit 64;
- branches `a/b` and `a_b` write two different record files;
- `write` with `fail`, with `incomplete`, with `pass` on a tree holding an uncommitted tracked
  change, and with `pass` on a detached HEAD each leave no record file (parametrized);
  `write --verdict pass` on a clean tree, and on a tree with one untracked file, records HEAD.

### Slice 6: Spec-only upstream changes do not pause

Delivers Requirement 12.

**Builds on:** slice 5
**Touches:** claude_plugins/sdd/scripts/upstream_change_scan.sh, tests/test_upstream_change_scan.py, claude_plugins/sdd/commands/protected/pre_step_rebase.md

`upstream_change_scan.sh`:

- Both `git diff -z --name-only` calls (`upstream` and `own`) gain `--no-renames`. With rename
  detection on, a code file moved under the spec root is listed only by its new path, and its
  removal from the code would go unseen.
- The spec-only check, from the `upstream` array:

  ```bash
  SPEC_ROOT=spec_dd

  # A change under the spec root cannot alter what a spec builds on, so a rebase that brought in
  # nothing else never pauses the spec.
  spec_only=no
  if [[ ${#upstream[@]} -gt 0 ]]; then
      spec_only=yes
      for path in "${upstream[@]}"; do
          if [[ "$path" != "$SPEC_ROOT"/* ]]; then
              spec_only=no
              break
          fi
      done
  fi
  ```

- The header gains `- Spec-only: yes|no`. The exit codes become: 0, no signal fired; 2, a signal
  fired and the upstream change holds a path outside the spec root; 3, a signal fired and the
  upstream change is spec-only. Update the header comment.

Tests (`tests/test_upstream_change_scan.py`):

- a new done-spec directory with nothing else incoming exits 3 and prints `Spec-only: yes`

EXEMPT = frozenset({"overview"})

FENCED_BLOCK = re.compile(r"^(```|~~~).*?^\1", re.MULTILINE | re.DOTALL)
STEP_HEADING = re.compile(r"^#{1,3}\s+(Step \d+(?:\.\d+)?\b.*?)\s*$", re.MULTILINE)
STEP_LABEL = re.compile(r"^Step (\d+(?:\.\d+)?)(?![\d.])")

def step_headings(markdown: str) -> list[str]:

def labels(svg: Path) -> list[str]:

def shows(label: str, heading: str) -> bool:

def misses(svg: Path, sources: list[Path]) -> list[str]:
