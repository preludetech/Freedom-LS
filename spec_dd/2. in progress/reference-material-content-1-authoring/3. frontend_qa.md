# Frontend QA: Reference material, authoring

The only page this work changes is the Django admin's course change page, which gains a read-only "Course reference parts" inline. The learner and educator pages are not changed.

## Setup

- Start the server with `uv run python manage.py runserver $PORT`. Base URL is `http://127.0.0.1:$PORT`.
- Load the demo content so the new demo course exists: `uv run python manage.py content_save ./demo_content DemoDev`.
- Log in at `http://127.0.0.1:$PORT/admin/` as `demodev@email.com`, password `demodev@email.com`.

## Test 1: the inline lists a course's reference parts in order

1. Go to `http://127.0.0.1:$PORT/admin/freedom_ls_content_engine/course/`.
2. Search for "Reference Material" and open "Functionality Demo - Reference Material".
3. Scroll to the inlines below the fieldsets.

Expect:

- The existing collection items inline lists one row: the "Flying Basics" part.
- A reference parts inline lists two rows, in this order: "Airspace Rules" with order 0, then "Glossary" with order 1.
- Neither "Airspace Rules" nor "Glossary" appears in the collection items inline.
- No "site" column or field appears in the reference parts inline.

## Test 2: the inline is read-only

On the same page:

- The reference parts inline has no "Add another" link.
- Its rows have no delete checkbox.
- `course_part` and `order` show as plain text, not as inputs or selects.

Then click "Save" on the course without changing anything.

Expect: the page saves with no error, and on reopening the course the two reference rows are unchanged, in the same order.

## Test 3: a course with no reference parts

1. Open "Functionality Demo - Per-placement Due Dates" from the course list.

Expect: the page loads with no error. The reference parts inline is empty, with no add link. The collection items inline still lists the "Core Concepts" part.

## Test 4: the rest of the course admin still works

1. Go back to the course list at `/admin/freedom_ls_content_engine/course/`.

Expect: the list loads, and the new demo course shows in it with its title and subtitle.

2. Open `/admin/freedom_ls_content_engine/coursepart/` and open "Airspace Rules".

Expect: the part's change page loads, and its collection items inline lists its two topics, "Airspace Classes" and "No-fly Zones". The part page has no reference parts inline.

## Test 5: reloading the content changes nothing

1. In a terminal, run `uv run python manage.py content_save ./demo_content DemoDev` again.

Expect: the output ends with the `✓ Successfully saved all content` line and holds no line starting `Removed part placement`.

2. Reload the "Functionality Demo - Reference Material" change page.

Expect: the same two reference rows, in the same order, and the same single row in the collection items inline.
