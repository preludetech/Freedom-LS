# Frontend QA: learner reference

Learners can now open a course's reference listing and read reference topics from the course
player. The public course page names the course's reference parts. The pages are the reference
listing, the reference topic page, the player sidebar on every player page, and `course_detail`.

## Setup

- Start the server with `uv run python manage.py runserver $PORT`. The base URL is
  `http://127.0.0.1:$PORT`.
- Load the demo content: `uv run python manage.py content_save ./demo_content DemoDev`.
- Log in at `http://127.0.0.1:$PORT/accounts/login/` as `demodev@email.com`, password
  `demodev@email.com`.
- The demo course is "Functionality Demo - Reference Material". Its learning path is one part,
  "Flying Basics". Its reference parts are "Airspace Rules" (topics "Airspace Classes", then
  "No-fly Zones"), then "Glossary" (topic "Terms"). "Glossary" lives in
  `demo_content/shared_reference_material/` and is reached through a `../` path.
- Find the course's slug from `http://127.0.0.1:$PORT/courses/`: open the course card; the detail
  URL is `/courses/<course-slug>/detail/`. Below, `<course-slug>` means that slug.
- If the detail page offers a registration button ("Enrol for free" or similar), click it so
  `demodev` is registered. If it says "Start course" or "Continue", `demodev` is already registered.

Check each page at 1920x1080, 375x812 and 768x1024 unless a test names one width. At every width:
no horizontal scroll, no console errors.

## Test 1: the Reference outline in the player sidebar

1. From the course detail page, click "Start course" (or "Continue"). You land on a learning-path
   item.
2. At 1920x1080, look at the docked outline panel on the left.

Expect:

- Under the course outline rows (after the "Flying Basics" part), a "Reference" heading in the
  same eyebrow style as "Course outline" at the top of the panel, and under it the parts "Airspace
  Rules" and "Glossary" as outline part rows: folder icon, muted title, chevron at the right, no
  numbers. Their text size, icon size and row spacing match the "Flying Basics" row.
- Click the "Airspace Rules" row: it opens to "Airspace Classes" and "No-fly Zones" as outline topic
  rows (topic icon, muted linked title), indented like "Flying Basics"' children. The chevron flips
  up. "Flying Basics" does not open or close with it.
- Reload the page. "Airspace Rules" is still open and "Glossary" still closed: each reference part
  remembers its own open state, apart from the learning-path parts.
- Neither the heading nor any reference row is highlighted. The learning-path item you are on is
  the highlighted row.
- The outline still has its header (course title, progress bar) and rows as before.

3. Click Next in the footer (an HTMX swap; the page does not fully reload).

Expect: the Reference heading and its parts are still there under the outline after the swap,
with "Airspace Rules" still open.

## Test 2: the reference listing

1. Click the "Reference" heading.

Expect:

- URL is `/courses/<course-slug>/reference/`.
- Breadcrumb: the course title, then "Reference". "Reference" is plain text, not a link.
- Page heading "Reference".
- The reference outline in course outline rows, every part open on load (even a part closed in
  the sidebar), no numbers: "Airspace Rules" with "Airspace Classes" then "No-fly Zones"; then
  "Glossary" with "Terms". Each topic is a link. The rows look like the "Course content" rows on
  the public course page: no bullets, no `<h2>` per part, no bold blue links.
- The part rows' folder icons line up with the left edge of the "Reference" heading; there is no
  empty number column in front of them.
- At 1920x1080 each part's chevron sits at the right of a reading-width column, not at the far
  right of the window.
- Clicking a part row closes it and flips its chevron down.
- No progress marks, ticks, status chips or "viewed" labels beside any topic.
- In the sidebar the "Reference" heading is highlighted like a current outline row; no outline row
  is highlighted.
- Browser tab title starts "Reference — Functionality Demo - Reference Material".

2. Open `/courses/<course-slug>/reference/#glossary` directly.

Expect: the page scrolls so the "Glossary" part row is visible, not hidden under the page header.

## Test 3: reading a reference topic

1. On the listing, click "Airspace Classes".

Expect:

- URL is `/courses/<course-slug>/reference/airspace-rules/<topic-slug>/`.
- A "Back to reference" link sits above the heading.
- Breadcrumb: course title › Reference › Airspace Rules, all three links. The topic title is the
  heading, not a crumb.
- Heading "Airspace Classes", with the body at reading width, like a learning-path topic.
- Footer: no Previous; a Next button on the right. No "Mark complete", "Finish Course" or "Home"
  button.
- Tab title is "Airspace Classes — Airspace Rules — Functionality Demo - Reference Material — …".
- In the sidebar, "Airspace Classes" is the highlighted current row, "Airspace Rules" is open, and
  the "Reference" heading is not highlighted.

2. Click Next.

Expect: "No-fly Zones" loads without a full page reload. Its footer has Previous on the left and
no Next. In the sidebar "No-fly Zones" is now the highlighted current row, under the open
"Airspace Rules" part.

3. Click Previous. Expect: back on "Airspace Classes".
4. Use the browser Back button. Expect: "No-fly Zones" again; the URL matches.
5. Click the "Airspace Rules" crumb. Expect: the listing, scrolled to the "Airspace Rules" part row.
6. Open "Terms" under "Glossary".

Expect: the shared Glossary topic renders its list of words. Its footer has neither Previous nor
Next (it is the only topic in its part). Next on "No-fly Zones" never led here. In the sidebar
"Terms" is the highlighted row and "Glossary" has opened.

7. Click "Back to reference". Expect: the listing.
8. Click the course-title crumb. Expect: you land on the learning path (your resume item), not the
   course detail page.

## Test 4: nothing is tracked

1. Note the progress percentage in the outline header on the listing page.
2. Read every reference topic.
3. Go back to the learning path.

Expect: the progress percentage is unchanged. No learning-path row changed status. The course
detail page's CTA label is the same as before (it did not switch from "Start course" to
"Continue" because of reference reading alone).

## Test 5: the mobile bottom-sheet (375x812)

1. On a learning-path item, tap "Open course outline".

Expect: the bottom-sheet shows the outline, with the Reference heading and its part rows under
the learning-path rows, in the same row style as on desktop.

2. In the sheet, tap the "Airspace Rules" row. Expect: it opens to its two topics.
3. Tap "Airspace Classes". Expect: the topic page; tap Next. Expect: "No-fly Zones". Open the
   outline sheet again: "No-fly Zones" is the highlighted row under the open "Airspace Rules" part.
4. In the sheet, tap the "Reference" heading. Expect: the listing loads and is readable at 375px;
   its rows start at the page's left edge, and long part or topic titles truncate without
   horizontal scroll.
5. Tap the course-title crumb. Expect: back on the learning path.

At 768x1024 repeat steps 1–4 and check the layout holds.

## Test 6: the public course page

1. Log out. Open `/courses/<course-slug>/detail/`.

Expect:

- Inside the "Course content" section, under the "Flying Basics" row, a "Reference" eyebrow
  heading (small, uppercase, muted), not a second large heading. There is one large heading on
  the section: "Course content".
- One muted line, "Available to registered learners.", under the eyebrow.
- "Airspace Rules" then "Glossary" as outline part rows, collapsed, matching "Flying Basics" in
  size, icon and chevron, with no numbers. Their folder icons and titles line up with the folder
  icon and title of "Flying Basics". Opening one shows its topic titles as plain text, not links.
- "Course content" and the "Reference" eyebrow are the only headings in the column; nothing in the
  sub-section looks larger or bolder than the learning-path rows.

2. Log back in as `demodev`. Open the same page. Expect: the same sub-section without the muted
   line; opened parts show topic titles as links, styled like the learning-path topic links, to
   the reference topic pages. At 768x1024 the sub-section sits under "Flying Basics" below the
   sign-up panel, with no horizontal scroll.
3. Open the detail page of another demo course with no reference parts (for example
   "Functionality Demo - Per-placement Due Dates"). Expect: no "Reference" sub-section.

## Test 7: courses without reference material

1. Open a learning-path item in a course with no reference parts (the course from Test 6 step 3,
   registering if needed).

Expect: no Reference heading in the sidebar. The outline and footer are unchanged from before:
header, rows, current-row highlight, Previous/Next behave as they did.

2. Visit `/courses/<that-course-slug>/reference/`.

Expect: the listing loads with a large centred icon and the text "No reference material yet". No
callout box.

## Test 8: refused and missing URLs

1. `/courses/<course-slug>/reference/airspace-rules/not-a-topic/` → 404.
2. `/courses/<course-slug>/reference/flying-basics/<a Flying Basics topic slug>/` (a learning-path
   part, not a reference part) → 404.
3. `/courses/<course-slug>/reference/glossary/<an Airspace Rules topic slug>/` (topic from another
   part) → 404.
4. `/courses/not-a-course/reference/` → 404.
5. Log out and open `/courses/<course-slug>/reference/` → redirected to the login page. After
   logging in you land back on the listing.
6. Ask the QA data helper for a second learner, not registered for the demo course; log in as them
   and open `/courses/<course-slug>/reference/` and a topic URL → both redirect to the course
   detail page, which still shows the "Reference" sub-section and the "Available to registered
   learners." line, with topic titles as plain text.
7. Ask the QA data helper to pause `demodev`'s pass of the demo course (an open `CoursePause` on
   its `CourseProgress`). Open the listing and a topic URL → both redirect to the course detail
   page, whose Reference sub-section shows topic titles as plain text and no "Available to
   registered learners." line. On a completed learning-path topic (still open to a paused learner)
   the sidebar still shows the Reference heading and parts; clicking the heading or a topic
   redirects to the course detail page. Then ask the helper to remove the pause.
