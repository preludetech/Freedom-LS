## How to work this plan

We follow TDD. Each slice names the tests that prove it; write each test first, watch it fail, then
make it pass.

### Three places, one worktree

The work happens in three places. Only the first is this git worktree. This table is the one
definition of the short names.

| Short name | Path | What it is |
| --- | --- | --- |
| FLS | this worktree | the FLS feature branch |
| `PKG_REPO` | `/home/sheena/workspace/software_factory/django-panel-framework.git` | the package repo (bare), `origin` at `git@github.com:preludetech/django-panel-framework.git` |
| `PKG` | `PKG_REPO/extract_panels_framework-5-package-and-install` | the package worktree paired with this FLS worktree. Slice 2 creates it, and it stays |
| `INFRA` | `/home/sheena/workspace/lms/freedom_ls_infra` | the infra directory. Not a git repository |

`PF` below means `freedom_ls/panel_framework` in FLS.

Rules that follow from this:

- **Slices 2 to 6 and slice 15 work outside this worktree.** Slices 2 to 6 commit in `PKG` with
  plain `git commit`. Each of those six slices also makes its `[batch <n>]` marker commit in FLS
  with `git commit --allow-empty` when it changed no FLS file. Slice 6's marker records the tag
  and its commit in the message body.
- **Slices 1 to 7 form a chain, and slice 15 builds on every slice**, so each of them runs alone in
  the feature worktree. A slice that works outside the worktree must never run in a batch worktree.
- **If a git, `uv`, `gh` or `docker` command outside the worktree is refused** by the permission
  system, the slice returns `status: blocked` with the exact commands it could not run. It does not
  look for another route.
- **Tags are never moved or deleted, and the package's `main` is never rewritten.** A mistake found
  after `v0.1.0` is pushed is fixed forward with `v0.1.1`, and slice 7 pins that tag instead.
- The package repo's history starts with one import commit (slice 2). Later slices add ordinary
  commits on top.
- File names the spec does not fix are chosen here: `tests/test_distribution.py`,
  `tests/clean_install_check.sh`, `tests/check_release_tag.py` and its test in the package, and the
  FLS test modules slice 1 creates.

### Decisions taken while planning

> **Assumed default:** `test_framework_copies_match_base.py` keeps its `freedom_ls.icons` cases and
> loses only the framework cases. Why: the icons app stays in FLS and the file is its only copy
> guard. To change: spec Requirements §2.

> **Assumed default:** the `INFRA` Dockerfile is edited in place and not committed. Why: `INFRA` is
> not a git repository. To change: spec Requirements §6.

> **Assumed default:** after the package CI passes on the paired branch, `main` in the package repo
> is fast-forwarded to the same commit and pushed, and `v0.1.0` tags that commit. Why: FLS `main`
> pairs with the package's `main`, and a tag should sit on `main`. To change: slice 6.

> **Assumed default:** the `fls-base` check builds stage 2 only as far as its dependency install,
> from a throwaway Dockerfile cut from the real one. A whole `docker build` with FLS as the context
> is not run. Why: stage 1 fails on FLS's own `package.json`, a fault the spec puts out of scope.
> To change: spec Success criteria, last bullet, and slice 15.

> **Assumed default:** `educator_interface` 0004 depends on `referral_tracking`'s latest migration,
> which adds an `educator_interface --> referral_tracking` edge if the app map counts migration
> dependencies. Why: spec Requirements §3 lists the app, because one of its models points at
> `ContentType`. To change: spec Requirements §3.

2. `tests/check_release_tag.py`:

   ```python
   def release_mismatches(tag: str, pyproject_text: str, changelog_text: str) -> list[str]:
       """Each way the tag, the project version and the newest changelog entry disagree."""
       version = tomllib.loads(pyproject_text)["project"]["version"]
       newest = re.search(r"^## \[([^\]]+)\]", changelog_text, re.MULTILINE)
       changelog_version = newest.group(1) if newest else None
       tagged = tag.removeprefix("v")
       mismatches = []
       if version != tagged:
           mismatches.append(f"pyproject.toml version {version} is not tag {tag}")
       if changelog_version != tagged:
           mismatches.append(f"newest CHANGELOG.md entry {changelog_version} is not tag {tag}")
       return mismatches


   def main(argv: list[str]) -> int:
       mismatches = release_mismatches(
           argv[1], Path("pyproject.toml").read_text(), Path("CHANGELOG.md").read_text()
       )
       print("\n".join(mismatches))
       return 1 if mismatches else 0
   ```

   ```python
   DISTRIBUTION = "django-panel-framework"


   def locked_commit(lock_path: Path) -> str:
       """The commit uv.lock records for the framework: the part of its git source after '#'."""
       packages = tomllib.loads(lock_path.read_text())["package"]
       source = next(p["source"] for p in packages if p["name"] == DISTRIBUTION)
       return source["git"].rpartition("#")[2]


   def installed_direct_url() -> str:
       """The installed copy's PEP 610 record, as text."""
       text = importlib.metadata.distribution(DISTRIBUTION).read_text("direct_url.json")
       if text is None:
           raise SystemExit(f"{DISTRIBUTION} was not installed from a git URL or a directory")
       return text


   def installed_state(direct_url: dict[str, object]) -> tuple[str, bool]:
       """(commit, has uncommitted changes) of the installed copy.

       A git install records its commit. An editable install records only a
       directory, so its commit and cleanliness are read from that worktree."""
       if "vcs_info" in direct_url:
           return direct_url["vcs_info"]["commit_id"], False
       directory = Path(url2pathname(urlparse(direct_url["url"]).path))
       head = _git(directory, "rev-parse", "HEAD")
       return head, bool(_git(directory, "status", "--porcelain"))


   def main(argv: list[str]) -> int:
       args = _parser().parse_args(argv[1:])  # --lock (default uv.lock), --direct-url (optional file)
       locked = locked_commit(args.lock)
       text = args.direct_url.read_text() if args.direct_url else installed_direct_url()
       commit, dirty = installed_state(json.loads(text))
       if commit == locked and not dirty:
           return 0
       print(f"installed: {commit}{' (uncommitted changes)' if dirty else ''}")
       print(f"locked:    {locked}")
       print(
           "Commit and tag in the package worktree, bump the pin in pyproject.toml, "
           "run `uv lock`, then re-run."
       )
       return 1
   ```

   `_git(directory, *args)` runs `["git", "-C", str(directory), *args]` with `check=True` and
   returns stripped stdout. Narrow `direct_url`'s values with `isinstance` checks instead of
   indexing an `object`. `main` catches `importlib.metadata.PackageNotFoundError` and prints one
   line saying the package is not installed, returning 1.
