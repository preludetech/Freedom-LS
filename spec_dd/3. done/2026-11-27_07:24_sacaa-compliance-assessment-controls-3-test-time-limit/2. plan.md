### Slice 2: A sitting knows its expiry, and completing it records why

`FormProgress` answers when it expires and whether a time-up post or a late page post is still in its window. `complete()` is safe under concurrency, records the completion reason and the limit in force, and stamps a time-expired sitting at its sitting expiry. Starting a quiz again after the limit lapsed completes the old sitting as `time_expired` first.

**Builds on:** slices 1
**Touches:** freedom_ls/form_engine/models.py, freedom_ls/form_engine/tests/test_models.py, freedom_ls/learner_progress/attempts.py, freedom_ls/learner_progress/tests/test_attempts.py

1. `form_engine/models.py`, beside `FormProgress`:

   ```python
   # A time-up post is honoured from this long before the sitting expiry: the
   # countdown works from a remaining time floored to whole seconds, so its zero
   # can land just ahead of the server's.
   TIME_UP_LEAD = timedelta(seconds=5)
   # A page post still saves this long after the sitting expiry, to cover the
   # network round trip of a post sent at zero.
   EXPIRY_GRACE = timedelta(seconds=10)
   ```

2. Methods on `FormProgress`. All four read `self.form.time_limit_minutes` as it is now, so a changed limit moves an open sitting's expiry and a removed one makes it untimed.

   ```python
   def expires_at(self) -> datetime | None:
       limit = self.form.time_limit_minutes
       return None if limit is None else self.start_time + timedelta(minutes=limit)

   def _open_expiry(self) -> datetime | None:
       """The sitting expiry of an open, timed sitting; None for any other."""
       return None if self.completed_time else self.expires_at()

   def is_expired(self, now: datetime) -> bool:
       expiry = self._open_expiry()
       return expiry is not None and now > expiry          # strict, as closing instants are

   def in_grace(self, now: datetime) -> bool:
       expiry = self._open_expiry()
       return expiry is not None and expiry < now <= expiry + EXPIRY_GRACE

   def accepts_time_up(self, now: datetime) -> bool:
       expiry = self._open_expiry()
       return expiry is not None and expiry - TIME_UP_LEAD <= now <= expiry + EXPIRY_GRACE
   ```

3. `complete(self, reason: CompletionReason = CompletionReason.LEARNER_SUBMITTED) -> None`. Existing callers keep the default.

   ```python

       # sitting, and save() writes every field, so work from the locked row.
   ```

   ```python
   def _complete_expired_sitting(
       user: User, course: Course, collection_item: ContentCollectionItem, now: datetime

       """Complete this learner's open sitting at the placement if its time has run
   ```

### Slice 4: A page post that lands just after expiry is saved

A `form_fill_page` POST inside the grace window, and a time-up post inside its window, save the posted page and then complete the sitting as `time_expired`. A time-up claim made early changes nothing. A page post after the window saves nothing.

**Builds on:** slices 3
**Touches:** freedom_ls/learner_interface/views.py, freedom_ls/learner_interface/tests/views/test_form_quiz_time_limit.py

1. `_save_page_and_complete` in `learner_interface/views.py`:

   ```python
   def _save_page_and_complete(
       course_progress: CourseProgress,
       sitting: FormProgress,
       page_number: int | None,
       post_data: QueryDict,
       now: datetime,
       in_window: Callable[[FormProgress, datetime], bool],   # FormProgress.in_grace or .accepts_time_up
   ) -> bool:
       """Save the posted page to a sitting whose time has just run out, then
       complete it, as one step no other request can come between."""
       with transaction.atomic():
           # Record first, then sitting: the order start_attempt takes them in.
           # complete()'s receivers write the record while the sitting is held.
           CourseProgress.objects.select_for_update().get(pk=course_progress.pk)
           locked = FormProgress.objects.select_for_update(of=("self",)).get(pk=sitting.pk)
           # False for a sitting another request completed meanwhile, too.
           if not in_window(locked, now):
               return False
           # An unsigned sitting was served nothing, so it has no page to save.
           if page_number is not None and not sitting_needs_declaration(locked):
               ensure_served_paper(locked)
               page = page_at(current_path(locked), page_number)
               if page is not None:
                   # Rejected answers are dropped: the valid ones are stored, and a
                   # rejection must not re-render the page or leave the sitting open.
                   submit_page(page, post_data, locked, require_answers=False)
           locked.complete(CompletionReason.TIME_EXPIRED)
           return locked.completed_time is not None
   ```

2. Split the `page_number` parsing out of `_posted_page` into a small function both use, so the time-up post can hand `_save_page_and_complete` a number.
3. Both page-post views read the learner's course progress record and open sitting read-only (`course_progress_for`, `get_latest_incomplete`) as their first step. Factor that lookup so `_complete_expired_sitting` and the page-post branch share it and it runs once per request.
4. `form_fill_page`, POST only, ahead of `_expired_sitting_redirect`: when the open sitting is `in_grace(now)`, call `_save_page_and_complete(..., page_number, ..., FormProgress.in_grace)` on any page; if it returns true, redirect to `course_form_complete`. Otherwise fall through unchanged, so a POST past the window meets `_expired_sitting_redirect` and saves nothing.
5. `form_submit_and_exit`, when `time_up` is in the POST, ahead of `_expired_sitting_redirect` and so ahead of the `not form.submit_on_exit and not closed` refusal:

   ```python
   if "time_up" in request.POST and sitting is not None and sitting.expires_at() is not None:
       if sitting.accepts_time_up(now):
           if _save_page_and_complete(..., FormProgress.accepts_time_up):
               return redirect(results)
           # completed by another request inside the window: fall through
       elif now < sitting.expires_at() - TIME_UP_LEAD:
           # The server never takes the client's word that time is up.
           return _form_page_redirect(course_slug, index, sitting)
       # past the grace window: fall through; nothing is saved
   # An untimed sitting has no expiry to honour, so time_up is ignored and this is a plain exit.
   ```

The window save applies to every learner, including one whose course is paused, whose item has closed or whose access has ended: the page-post branch runs ahead of the access gates on purpose (decided with the user). It writes only the requesting learner's own open sitting, one page, inside the window the server's clock decides.

Tests prove: a `form_fill_page` POST within 10 seconds after expiry saves the page, completes as `time_expired` and redirects to results, on a middle page and on the last page, with a required question unanswered and with an invalid answer; one later saves nothing and still lands on results. A time-up post from 5 seconds before to 10 seconds after expiry saves the page and completes, with a required question unanswered and with an invalid answer, on a quiz that saves on exit and on one that submits on exit; one landing 8 seconds after expiry records `completed_time` at the expiry; one with more than 5 seconds left saves nothing, completes nothing and redirects to the runner page; one more than 10 seconds late saves nothing and completes; on an untimed sitting it behaves as a plain exit. A time-up post for a sitting another request already completed saves nothing. A page post inside the window from a paused, closed-item or ended-access learner is saved; one aimed at a course where the learner has no open sitting writes nothing, and no page post ever changes another learner's sitting.

   ```js
   remaining():
     // The larger delta, so neither a changed device clock nor a suspended tab hides lost time.
     elapsed = Math.max(performance.now() - perfStart, Date.now() - dateStart) / 1000
     return Math.max(0, startRemaining - elapsed)
   tick():
     left = remaining()                    // one clock read decides the text and the submit
     text = format(left)                   // m:ss, or h:mm:ss from an hour
     if left <= 0 and not submitted: submitTimeUp()
   submitTimeUp():                          // once per page
     submitted = true
     runnerNavigating = true                // stops Next, Previous and the beforeunload guard
     form = document.getElementById("runner-page-form")
     form.action = timeUpUrl
     append <input type="hidden" name="time_up" value="1">
     form.submit()                          // fires no submit event, so the required-answer check does not run
   destroy(): clear the interval, remove both listeners
   ```

   Expose `text` as a property for `x-text`. No inline expressions: CSP build.

1. New `form_engine/sweeps.py`, in the shape of `referral_tracking/sweeps.py`:

   ```python
   class ExpiredSittingSweep(NamedTuple):
       completed: int
       failed: int

   def _expired_sittings(now: datetime) -> QuerySet[FormProgress]:
       # _base_manager: housekeeping has no request to derive a site from, and
       # every site's sittings are in scope.
       return (
           FormProgress._base_manager
           .filter(completed_time__isnull=True, form__time_limit_minutes__isnull=False)
           .annotate(expiry=ExpressionWrapper(
               F("start_time") + F("form__time_limit_minutes") * Value(timedelta(minutes=1)),
               output_field=DateTimeField()))
           # Past the grace window too: a page post may still be in flight inside it.
           .filter(expiry__lt=now - EXPIRY_GRACE)
       )

   def complete_expired_sittings() -> ExpiredSittingSweep:
       completed = failed = 0
       now = timezone.now()
       pks = list(_expired_sittings(now).values_list("pk", flat=True))   # no lock, no lower time bound
       for pk in pks:
           try:
               with transaction.atomic():
                   sitting = (_expired_sittings(now)
                              .select_for_update(skip_locked=True, of=("self",))
                              .filter(pk=pk).first())
                   if sitting is None:
                       continue            # completed meanwhile, or a request holds it
                   sitting.complete(reason=CompletionReason.TIME_EXPIRED)
                   # complete() refreshes from the locked row, so a no-op leaves this None.
                   if sitting.completed_time is not None:
                       completed += 1
           except (DatabaseError, ValueError):   # ValueError: scoring a malformed quiz
               failed += 1
       return ExpiredSittingSweep(completed, failed)
   ```

## Cross-cutting rules

- Type hints on every new function; no `Any`; no `# type: ignore`; no logging; specific exceptions only.
- Every new test that touches a site-aware model takes `mock_site_context`.
- Lock order is course progress record, then sitting. `start_attempt`, `close_left_signed_sitting`, `_complete_expired_sitting` and `_save_page_and_complete` all take it that way. Only the sweep takes the sitting alone, because `form_engine` cannot import `learner_progress`; if that ever cycles with a request, the database aborts one side, and in the sweep that is a `DatabaseError` it counts and retries on its next run.
