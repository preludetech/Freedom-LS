# Plan: course shares between organisations

Spec: `1. spec.md`. Every rule below uses the spec's terms: **owning organisation** (any
organisation in `Course.organisations`), **course share** (an owning organisation names another in
`shared_with:`), **available to an organisation** (no `organisations:`, or owned by it, or shared
with it).

**The reach table.** For an educator acting in organisation O, the spec's five rows are the
parametrisation every surface test below uses:

| Row id | Course | Listed + detail | Preview | Registerable |
| --- | --- | --- | --- | --- |
| `no_owner` | no `organisations:` | yes | yes | yes |
| `owned` | owned by O | yes | yes | yes |
| `shared` | owned by P, shared with O | yes | yes | yes |
| `held` | owned by P, not shared, O holds an inactive registration | yes | no | no |
| `unreached` | owned by P, not shared, no registration held by O | no | no | no |

Every row's course is `audience: public` and published, so audience and visibility play no part.

1. **Through-table helper** in `learner_management/queries.py`, beside
   `is_organisation_course_expression`:

   ```python
   def _through_has_organisation(
       through: type[Model], organisation: Organisation
   ) -> Exists:
       # The through table rather than a join, so the predicate adds no rows
       # to the course queryset it is embedded in. The through tables carry
       # no site manager; the outer Course queryset is site-filtered, and the
       # loader resolves every slug on the course's own site, so a row here
       # never pairs a course with another site's organisation.
       return Exists(
           through.objects.filter(course_id=OuterRef("pk"), organisation=organisation)
       )
   ```

2. **Widen `open_to_organisation_expression`:**

   ```python
   return (
       open_to_everyone_expression()
       | Q(_through_has_organisation(Course.organisations.through, organisation))
       | Q(_through_has_organisation(Course.shared_with.through, organisation))
   )
   ```

### Slice 5: reactivation refuses a course no longer available

**Behaviour:** reactivating a learner's inactive registration on a `held` course is refused with
`COURSE_NOT_OPEN_MESSAGE`, even when the course is public (the write gate would accept it).

**Builds on:** slice 3

**Touches:** `freedom_ls/educator_interface/actions.py`,
`freedom_ls/educator_interface/tests/test_actions.py`

1. In `ReactivateRegistrationAction.handle_submit`, refuse before calling `register_for_course`,
   through the same 422 branch the `CourseNotOpenError` path uses. Extract that branch so both
   share it:

   ```python
   def _refused(self, ctx: PanelContext, message: str) -> HttpResponse:
       context = self.get_context_data(ctx)
       context["refusal"] = message
       return render(ctx.request, self.template_name, context, status=422)

   def handle_submit(self, ctx: PanelContext) -> HttpResponse:
       learner = cast(Learner, ctx.instance)
       course = self._registration(ctx).course
       # The write gate accepts every public course, but an educator registers
       # only for courses available to the organisation.
       if not is_course_available_to_organisation(course, learner.organisation):
           return self._refused(ctx, COURSE_NOT_OPEN_MESSAGE)
       try:
           register_for_course(learner, course, actor=cast("User", ctx.request.user))
       except CourseNotOpenError as error:
           # The course may have gained organisations since the registration
           # was made, leaving it closed to this learner's organisation.
           return self._refused(ctx, str(error))
       return _registration_changed_response(learner)
   ```

2. The other educator register paths go through a picker queryset (`registerable_courses_for`,
   `registerable_courses_for_learner`, `CoursePickerMixin`), so they need no change. Confirm with a
   grep for `register_for_course` and `register_cohort_for_course` in `educator_interface/` that
   no other call site registers outside a picker.

**Tests** (`test_actions.py`, beside the existing `COURSE_NOT_OPEN_MESSAGE` reactivation test,

(`no_owner`, `owned`, `shared`, `held`) succeeds, or returns 422 containing the imported
