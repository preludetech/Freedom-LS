# Answers: reference-material-content-2-learner-reference

Asked by `/sdd:start` before the spec was written.

- Q: On a reference topic page, how does the learner move on? → A: Previous and Next step through the topics of the same reference part, plus a link back to the reference listing (asked up front)
- Q: What breadcrumb do reference pages show? → A: Course › Reference › Part: Course links to the course home, Reference links to the listing, the part crumb links to that part's section on the listing; the topic title is the page heading (asked up front)
- Q: Where does the Reference entry sit in the mobile outline bottom-sheet? → A: Right under the course table of contents (asked up front)
- Q: What does the reference listing show for a reference part that has no topics? → A: Hide empty parts; if no part has topics, the listing shows a single "No reference material yet" message and the Reference entry still links to it (asked up front)
