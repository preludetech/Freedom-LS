## Rules that apply to every slice

- **Browser flows.** Every slice that touches a template (2 to 8) ends by running
  `freedom_ls/learner_interface/tests/playwright/test_course_browse_flow.py` and
  `test_organisation_course_flow.py` as well as the targeted tier. A selector those flows lose is
  fixed in the slice that broke it; the `QA_VIEWPORTS` overflow loops stay green throughout.
  `get_by_role("link", name="Details")` matches by substring, so the sr-only suffix of slice 6
  needs no selector change.
- **Assertions on classes.** Four assertions name a class because the spec makes the class the
  contract: `object-cover` on a profile logo and `object-contain` on a fallback logo (§4),
  `text-muted` absent from the byline when a `class` is passed (§5.3), and `p-0` absent from the
  card shell's article (§6). Every other assertion uses `src`, `alt`, `aria-*`, `title`, `href`,
  an element count or a `data-testid`. `django_assert_num_queries(0)` is used once, where the spec
  makes zero queries the contract.
- **No loops in test bodies.** A test renders one organisation, one row or one card and asserts on
  its one element; a case that varies only by input is `@pytest.mark.parametrize`d.

## Slice 2: the organisation mark and the byline

**Delivers:** every byline already on the dashboard cards and rows draws the circle: profile
logo, else logo, else initials, else the `unknown` icon.

**Design states:** cards__b (the byline only; the card layout is slice 3)

`freedom_ls/learner_interface/templates/cotton/organisation-mark.html` (new). The circle sets
its own size and font size once; the monogram inherits the font size and the icon is sized in
`em`, so the size branch is written once:

```django
<c-vars organisation="" size="sm" class="" />
{% comment %}
The circle that stands for an organisation: its profile logo, else its logo,
else an initials monogram, else a generic icon. The mark never carries the
accessible name; the name rendered beside it does, so the image is decorative
and the monogram is hidden from assistive technology.

A profile logo is uploaded for this circle and may be cropped to it
(object-cover); a logo is usually a wordmark and must not be (object-contain).
The fill is opaque so a transparent logo stays legible on any background.

The circle's font size scales the monogram and the icon with it, so each size
is declared once.

Params:
  organisation — the organisation to draw
  size — sm (cards and rows, the default), md (the course page hero),
    lg (the course page organisation card)
  class — extra classes merged onto the circle
{% endcomment %}
<span data-testid="organisation-mark"
      class="inline-flex shrink-0 items-center justify-center overflow-hidden rounded-full bg-surface ring-1 ring-border {% if size == 'lg' %}size-12 text-lg{% elif size == 'md' %}size-8 text-sm{% else %}size-6 text-xs{% endif %} {{ class }}">
    {% if organisation.profile_logo %}
        <img src="{{ organisation.profile_logo.url }}" alt="" class="size-full object-cover" />
    {% elif organisation.logo %}
        <img src="{{ organisation.logo.url }}" alt="" class="size-full object-contain p-1" />
    {% elif organisation.initials %}
        <span aria-hidden="true"
              class="flex size-full select-none items-center justify-center bg-surface-2 font-semibold text-on-surface">
            {{ organisation.initials }}
        </span>
    {% else %}
        <span aria-hidden="true" class="flex size-full items-center justify-center bg-surface-2 text-on-surface">
            <c-icon name="unknown" class="size-[1.25em]" />
        </span>
    {% endif %}
</span>
```

## Slice 4: the named organisation

**Delivers:** `Course.single_organisation()` is the one place that decides which organisation a
course names, and the all-courses rows gain their byline through it.

`freedom_ls/content_engine/models/courses.py`, on `Course` (import `Organisation` under the
existing `if TYPE_CHECKING:` block):

```python
def single_organisation(self) -> Organisation | None:
    """The one organisation this course belongs to, or None.

    None for a course with no organisation or with several, and for the
    site's default organisation: it stands for the site itself, which the
    page chrome already brands, so no surface names it again. Reads the
    prefetched organisations when a caller supplied them and issues one
    query otherwise.
    """
    organisations = list(self.organisations.all())
    if len(organisations) != 1 or organisations[0].is_default:
        return None
    return organisations[0]
```
