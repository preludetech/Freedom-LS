# Plan: user-communication UX improvements

Implementation plan for `1. spec.md`. Every path is relative to the repo root. Line numbers are
from the worktree at the time of writing and are a guide, not a contract.

The spec's "Documentation and downstream" section (product docs, the `notifications` skill, the
`domain-glossary` skill, the roadmap row and the upgrade notes) is not implemented by this plan.
It is the documentation step's work. The one code-side exception is the `NOUNS` and `VERBS` sets
in `freedom_ls/audit_log/tests/invariants/test_vocabulary.py`, which Slice 10 extends so the new
audit action passes the invariant.

No `design.md` applies to this spec, so there is no Design section.

## Review decisions

Taken with the user after the plan review:

- The oversight open writes its audit entry only for a request carrying `HX-Request: true`; a
  plain GET is a 404 and writes nothing (Slice 10).
- The oversight list keeps the one-line excerpt per row. Only an open is audited; the disclosure
  line tells participants that admins can read (Slice 9).
- The oversight work is three slices: the disclosure line (Slice 7), the audited read-only open
  (Slice 10) and older messages under oversight (Slice 11).
- The QA seed's role grants live in the oversight list slice (Slice 9), so Slice 1 is the
  notification removal alone.

> **Assumed default:** `learner_to_educator` ships `"open"` as the spec decides, with no code
> safeguard for installs that never overrode `MESSAGING_DEFAULT_FLAGS`. Why: the spec's upgrade
> note tells such projects to set the flag or an `OrganisationMessagingConfig` row, and Slice 3
> proves the organisation row closes it. To change: Slice 3.

## Slice 4: starting a conversation from the messages page

**Delivers:** on `md` and above, "New message" swaps the picker into the thread pane and choosing a
recipient swaps in that person's composer; narrow screens and direct links use the full
`conversations:start` page, whose back link goes to `conversations:inbox`; choosing someone the
user already has a conversation with opens it; the first send lands in the new thread; a refused
send is a 422 with the draft kept.

### `freedom_ls/comms/messaging_views.py`

```python
THREAD_PANE_ID = "thread-pane"


def _targets_thread_pane(request: HttpRequest) -> bool:
    """Whether htmx asked on behalf of the messages page's thread pane."""
    return (
        request.headers.get("HX-Request") == "true"
        and request.headers.get("HX-Target") == THREAD_PANE_ID
    )


def _open_thread_response(request: HttpRequest, conversation: Conversation) -> HttpResponse:
    """Take the browser to the conversation's thread: a redirect for a plain
    request, a 204 with HX-Location for htmx so the whole page loads."""
    thread_url = reverse("conversations:thread", kwargs={"pk": conversation.pk})
    if request.headers.get("HX-Request") != "true":
        return redirect(thread_url)
    response = HttpResponse(status=204)
    response["HX-Location"] = json.dumps({"path": thread_url})
    return response


def _start_get(request: HttpRequest) -> HttpResponse:
    in_pane = _targets_thread_pane(request)
    template = "comms/partials/new_conversation_pane.html" if in_pane else "comms/start.html"
    raw = request.GET.get("recipient")
    if raw is None:
        context = {"recipient": None, "in_pane": in_pane, **_picker_context(request, request.GET.get("q", ""), in_pane=in_pane)}
        return render(request, template, context)
    recipient = get_object_or_404(_offered_recipients(request), pk=recipient_pk(raw))
    site = cast("Site", get_cached_site(request))
    existing = conversation_between(cast("User", request.user), recipient, site)
    if existing is not None:
        # One conversation per pair: choosing the person again opens it.
        return _open_thread_response(request, existing)
    context = {
        "recipient": recipient,
        "other": recipient,
        "in_pane": in_pane,
        "composer": composer_context(client_key=uuid4(), recipient=recipient),
    }
    return render(request, template, context)
```

`_send_response`'s first-send branch (`recipient is not None`) and its non-htmx redirect call
`_open_thread_response` instead of building the response by hand. `_picker_context` gains
`in_pane: bool = False` and passes it through so the results' links can target the pane.
`_start_post` is unchanged: the first send already answers `HX-Location` to the new thread for
htmx, and 422 with the composer swapped in place (`hx-target="this"`) when refused. `HX-Location`
with no `target` loads the whole page, which is what a first send wants.

### `comms/static/comms/js/alpine-components.js`

Extract the disclosure logic the bell has into one helper both components are built on. The helper
owns `open`, `loading`, `failed`, `contentVisible`, `toggle`, `openPanel`, `close`, `retry`, the
`htmx:*` listeners on `x-ref="content"`, and the mutual exclusion. Each component is
`Object.assign(headerPanel(name), {...})`, so the `contentVisible` getter stays a live getter
(an object spread would evaluate it once).

```js
// Shared by the header bell and the header messages button: one disclosure
// panel whose content loads each time it opens. Only one header panel is
// open at a time: opening one announces itself on window and the other closes.
function headerPanel(name) {
    let onOtherOpened = null;
    return {
        open: false,
        loading: false,
        failed: false,
        initPanel() {
            const content = this.$refs.content;
            // Only the panel's own content load drives loading/failed; htmx
            // events bubbling from elements inside the content must not flip
            // them, and hiding the content for those would lose keyboard focus.
            const onPanelLoad = (handler) => (event) => {
                if (event.detail.elt === content) handler();
            };
            content.addEventListener("htmx:beforeRequest", onPanelLoad(() => { this.loading = true; }));
            content.addEventListener("htmx:afterSwap", onPanelLoad(() => { this.loading = false; }));
            const onFailure = onPanelLoad(() => { this.loading = false; this.failed = true; });
            content.addEventListener("htmx:responseError", onFailure);
            content.addEventListener("htmx:sendError", onFailure);
            onOtherOpened = (event) => { if (event.detail !== name && this.open) this.close(); };
            window.addEventListener("header-panel-opened", onOtherOpened);
        },
        destroyPanel() {
            window.removeEventListener("header-panel-opened", onOtherOpened);
        },
        get contentVisible() {
            return !this.loading && !this.failed;
        },
        toggle() {
            if (this.open) { this.close(); } else { this.openPanel(); }
        },
        openPanel() {
            this.open = true;
            this.failed = false;
            window.dispatchEvent(new CustomEvent("header-panel-opened", { detail: name }));
            this.$refs.content.dispatchEvent(new CustomEvent("refresh"));
        },
        close() {
            const focusWasInPanel = this.$refs.panel.contains(document.activeElement);
            const focusWasOnTrigger = document.activeElement === this.$refs.trigger;
            this.open = false;
            if (focusWasInPanel || focusWasOnTrigger) this.$refs.trigger.focus();
        },
        retry() {
            this.openPanel();
        },
    };
}

Alpine.data("notificationBell", () => {
    let poller = null;
    return Object.assign(headerPanel("notifications"), {
        init() {
            poller = visibilityPoller(Number(this.$el.dataset.pollSeconds), this.$refs.badge);
            this.initPanel();
        },
        destroy() {
            poller.destroy();
            this.destroyPanel();
        },
    });
});

Alpine.data("messagesPanel", () => {
    let onConversationChanged = null;
    return Object.assign(headerPanel("messages"), {
        init() {
            this.initPanel();
            // A reply landing while the panel is open refreshes its rows; closed,
            // the next open loads afresh anyway.
            onConversationChanged = () => {
                if (this.open) this.$refs.content.dispatchEvent(new CustomEvent("refresh"));
            };
            document.body.addEventListener("conversationChanged", onConversationChanged);
        },
        destroy() {
            document.body.removeEventListener("conversationChanged", onConversationChanged);
            this.destroyPanel();
        },
    });
});
```

```python
class SendToLearnerAction(PanelAction):
    """The Messages tab's composer posts here, so the answer is the tab itself
    re-rendered, never a redirect to the messages page."""

    action_name = "send"
    renders_in_footer = False

    def has_permission(self, ctx: PanelContext) -> bool:
        return comms_config.MESSAGING_ENABLED and super().has_permission(ctx)

    def handle_submit(self, ctx: PanelContext) -> HttpResponse:
        request = ctx.request
        learner = cast(Learner, ctx.instance)
        own = own_conversation_with(request, learner)
        client_key = posted_client_key(request)
        draft = request.POST.get("body", "")
        result = send_message(
            sender=cast(User, request.user),
            body=draft,
            client_key=client_key,
            site=cast(Site, get_cached_site(request)),
            conversation=own.conversation,
            recipient=None if own.conversation is not None else learner.user,
        )
        panel = LearnerMessagesPanel(ctx)
        if result.message is not None:
            response = render(request, panel.template_name, panel.get_context_data())
            response["HX-Trigger"] = CONVERSATION_CHANGED
            return response
        alert = result.body_error or refusal_alert_copy(result.refusal, learner.user)
        return render(
            request,
            panel.template_name,
            panel.get_context_data(draft=draft, client_key=client_key, alert=alert),
            status=422,
        )
```

```python
def oversight_conversations_for(learner: Learner) -> QuerySet[Conversation]:
    """The learner's conversations whose other participant is one of their
    educators now, newest activity first, with an excerpt and the educator
    prefetched. A conversation with someone who has since lost their educator
    role is not in it, and a deactivated learner has none, since educators_of
    is empty for them."""
    educator_ids = educators_of(learner).values("pk")
    learner_side = ConversationParticipant.objects.filter(
        conversation=OuterRef("pk"), user=learner.user
    )
    educator_side = ConversationParticipant.objects.filter(
        conversation=OuterRef("pk"), user__in=educator_ids
    ).exclude(user=learner.user)
    return (
        Conversation.objects.filter(Exists(learner_side), Exists(educator_side))
        .annotate(last_message_body=last_message_body_subquery())
        .prefetch_related(
            Prefetch(
                "participants",
                queryset=ConversationParticipant.objects.exclude(user=learner.user).select_related("user"),
                to_attr="other_participants",
            )
        )
        .order_by(F("last_message_at").desc(nulls_last=True), "-created_at")
    )
```

`other_participant(conversation, learner.user)` then names the educator with no extra query.

```python
class ViewConversationAction(PanelAction):
    """Opens one of the learner's educator conversations read-only in the app
    modal, for someone who holds oversight of the learner. Every open is
    recorded in the learner's history, so only the page's own htmx request
    may open one: a plain GET from a prefetch or a cross-site tag must not
    leave a false entry."""

    action_name = "view_conversation"
    capability = VIEW_CONVERSATION
    renders_in_footer = False
    template_name = "educator_interface/modal/conversation_oversight.html"

    def has_permission(self, ctx: PanelContext) -> bool:
        return comms_config.MESSAGING_ENABLED and super().has_permission(ctx)

    def get_context_data(self, ctx: PanelContext) -> dict[str, object]:
        request = ctx.request
        if request.headers.get("HX-Request") != "true":
            raise Http404
        learner = cast(Learner, ctx.instance)
        conversation = get_object_or_404(
            oversight_conversations_for(learner),
            pk=uuid_or_404(request.GET.get("conversation")),
        )
        educator = other_participant(conversation, learner.user)
        viewer = cast(User, request.user)
        record_entry(
            action="conversation.viewed",
            actor=viewer,
            target=conversation,
            target_label=f"Conversation with {educator.display_name if educator else 'Deleted user'}",
            organisation=learner.organisation,
            subjects=[learner],
        )
        return {
            **read_only_thread_context(conversation, other=educator, older_url=""),
            "viewer_role_label": _oversight_role_label(viewer, learner),
        }

    def handle_submit(self, ctx: PanelContext) -> HttpResponse:
        # Opening is a read; there is nothing to submit.
        raise Http404


def uuid_or_404(raw: str | None) -> UUID:
    """A pk from a query string or a URL; a 404 when it is not a UUID."""
    try:
        return UUID(raw or "")
    except ValueError:
        raise Http404("not a uuid") from None


def _oversight_role_label(viewer: User, learner: Learner) -> str:
    """How the read-only banner names the viewer's access: a site admin reads
    through the site grant, anyone else holding the permission is an
    organisation admin of the learner's organisation."""
    if site_level_admins(learner.site).filter(pk=viewer.pk).exists():
        return "a site admin"
    return "an organisation admin"
```

```python
def older_page_response(
    request: HttpRequest,
    conversation: Conversation,
    cursor: tuple[datetime, UUID],
    *,
    older_url: str | None = None,
) -> HttpResponse:
    """The page of messages older than ``cursor``, for prepending to the log.

    The first message already on screen is re-rendered out of band, because
    its day separator and sender line depend on what now sits above it. The
    load-earlier control is replaced out of band with the next cursor, or with
    nothing once no older message exists; ``older_url`` is the address that
    control fetches from when it is not the participant's own.
    """
    older, has_more = page_before(conversation, cursor)
    boundary_message = _boundary_message(conversation, cursor)
    body = ""
    for entry in render_message_entries(older, None):
        body += render_to_string("comms/partials/message_entry.html", {"entry": entry}, request)
    if older and boundary_message is not None:
        body += render_to_string(
            "comms/partials/message_entry.html",
            {"entry": render_message_entries([boundary_message], older[-1])[0], "oob": True},
            request,
        )
    body += render_to_string(
        "comms/partials/thread_older.html",
        {
            "conversation": conversation,
            "older_cursor": encode_cursor(older[0]) if has_more and older else "",
            "older_url": older_url,
            "oob": True,
        },
        request,
    )
    return HttpResponse(body)


@messaging_view
def partial_thread_older(request: HttpRequest, pk: UUID) -> HttpResponse:
    conversation = participant_conversation(request, pk)
    cursor = decode_cursor(request.GET.get("before", ""))
    if cursor is None:
        return HttpResponseBadRequest("before must be a cursor")
    return older_page_response(request, conversation, cursor)
```

```python
@login_required_htmx_to("educator_interface:root")
def partial_oversight_thread_older(
    request: HttpRequest, organisation_slug: str, learner_pk: str, conversation_pk: str
) -> HttpResponse:
    """Older messages of a conversation under oversight. Authorised the way the
    learner page is, then by the oversight permission and the oversight set;
    records nothing, since the open that reached this page already did."""
    if not comms_config.MESSAGING_ENABLED:
        raise Http404
    _attach_organisation(request, organisation_slug)
    learner = cast(Learner, LearnerConfig.get_instance_view(request, learner_pk).instance)
    if not can(request.user, VIEW_CONVERSATION, learner):
        raise Http404
    conversation = get_object_or_404(
        oversight_conversations_for(learner), pk=uuid_or_404(conversation_pk)
    )
    cursor = decode_cursor(request.GET.get("before", ""))
    if cursor is None:
        return HttpResponseBadRequest("before must be a cursor")
    return older_page_response(request, conversation, cursor, older_url=request.path)
```

URL in `educator_interface/urls.py`, before the catch-all:

name `oversight_thread_older`.
