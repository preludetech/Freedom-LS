Source: `1. spec.md` in this directory. Research that backs the plan: `research_codebase.md`
(touch points, hazards) and `research_api_foundation.md` (library versions, DRF conventions).

## Skills and conventions for every slice

- `ds:testing` then `fls-dev:testing`: tests mirror modules (`<app>/tests/test_<module>.py`, each
  new `tests/` directory with an empty `__init__.py`); factory_boy for data; `reverse()` for URLs;
  `time_machine` for clocks; no `if`, `for` or `try` in a test body (walks go in a plain helper
  in `<app>/tests/helpers.py`, set-up and tear-down in a fixture, cases in `parametrize`); an N+1
  guard asserts an upper bound (`django_assert_max_num_queries`); expected values are hard-coded,
  never computed by the code under test. Cross-app tests live in the lowest app that depends on
  everything they touch: tests that need a live endpoint sit in
  `freedom_ls/accounts/tests/test_api.py` (accounts imports api); tests of one `api` module sit in
  `freedom_ls/api/tests/` and use `ApiKey` rows and DRF's `APIRequestFactory`, never `accounts`.
  `api_admin` tests use the root conftest's `staff_client` and
  `django.contrib.auth.get_user_model()` rather than importing `accounts`. Every test that touches
  a site-aware model takes `mock_site_context`; the only exceptions are the host-mismatch
  authentication cases, which need two real `Site` rows and say so in the module docstring. Read
  `claude_plugins/django-stack/resources/test_tiers.md` before running pytest.
- `fls-dev:multi-tenant`: `ApiKey` extends `SiteAwareModel`; the default manager filters by the
  request host, so authentication and `site_queryset` use `_base_manager` plus an explicit
  `site=` filter, and the reason is written where they do.
- `ds:app-settings` then `fls-dev:app-settings`: every tunable goes through `freedom_ls/api/config.py`;
  no `REST_FRAMEWORK` setting; Django built-ins such as `DEBUG` and `CACHES` stay direct `settings`
  reads.
- `ds:admin-interface` then `fls-dev:admin-interface`: `SiteAwareModelAdmin` only; `site` is never a
  form field. No render-only admin tests: test permissions, validation and read-only behaviour.
- `fls-dev:domain-glossary`: the spec's terms are the identifiers (`ApiKey`, `ApiScope`, "API
  scope", "revoked", "key text" for the full `flsk_…` string). Never "resource", "deactivated" or
  "token" for these.
- `sdd:planning-references-in-code` and `ds:code-comments`: no comment, docstring or test name
  cites the spec, the plan, a slice or a sibling spec. State the fact instead. A comment that says
  what the line says is deleted.
- `unslop` for every sentence a person reads (admin copy, error messages, help text).
- CLAUDE.md: type hints on every function (DRF has no stubs here, so the explicit annotations
  below are the typing), no `Any`, no `# type: ignore`, no logging, ORM only, never edit an
  existing migration, `makemigrations` then `migrate` after a model change.
- `/ds:app_map` is a pre-commit prerequisite, not documentation: `app-map-fresh` fails any commit
  made after a new app or edge exists until `docs/app_structure.md` and
  `test_organisation/import_contracts.toml` are regenerated. Slices 2 and 8 run it.
- No MCP is needed for the implementation.

KEY_TEXT_PREFIX = "flsk_"
LAST_USED_RESOLUTION = timedelta(minutes=5)


class ApiKeyStatus(models.TextChoices):
    ACTIVE = "active", "Active"
    EXPIRED = "expired", "Expired"
    REVOKED = "revoked", "Revoked"


def hash_key(key_text: str) -> str:
    return hashlib.sha256(key_text.encode()).hexdigest()


class ApiKey(SiteAwareModel, TimestampedModel):
    name = models.CharField(max_length=200)
    key_prefix = models.CharField(max_length=16, unique=True, editable=False)
    key_hash = models.CharField(max_length=64, unique=True, editable=False)
    scopes = ArrayField(models.CharField(max_length=40, choices=ApiScope.choices))
    expires_at = models.DateTimeField(null=True, blank=True)
    revoked_at = models.DateTimeField(null=True, blank=True, editable=False)
    last_used_at = models.DateTimeField(null=True, blank=True, editable=False)

    # Held in memory on the instance that was just issued, for the one
    # response that shows it. Never a column.
    issued_key: str | None = None

    class Meta:
        verbose_name = "API key"
        ordering = ("-created_at",)

    def __str__(self) -> str:
        return f"{self.name} ({self.key_prefix})"

    def clean(self) -> None:
        errors: dict[str, str] = {}
        if not self.scopes:
            errors["scopes"] = "Choose at least one API scope."
        elif len(set(self.scopes)) != len(self.scopes):
            errors["scopes"] = "Each API scope can be chosen once."
        # Only a key being issued is held to a future expiry: an issued key's
        # expiry may pass while its name is still being edited.
        if (
            self._state.adding
            and self.expires_at is not None
            and self.expires_at <= timezone.now()
        ):
            errors["expires_at"] = "The expiry must be in the future."
        if errors:
            raise ValidationError(errors)

    @classmethod
    def issue(cls, instance: ApiKey, *, site: Site) -> str:
        """Fill an unsaved key, save it and return the one full key text.

        The site is passed in rather than read from the current request: a
        key is issued from the admin on behalf of the host site, and from
        factories and scripts where there is no request at all.

        The secret carries 256 bits of entropy, so a plain SHA-256 is enough
        and a password hasher would only add cost to every request. The prefix
        is 64 random bits under a unique constraint; a collision is accepted
        as an IntegrityError rather than retried.
        """
        instance.key_prefix = secrets.token_hex(8)
        secret = secrets.token_urlsafe(32)
        key_text = f"{KEY_TEXT_PREFIX}{instance.key_prefix}.{secret}"
        instance.key_hash = hash_key(key_text)
        instance.site = site
        instance.save()
        return key_text

    def status(self, now: datetime) -> ApiKeyStatus:
        if self.revoked_at is not None:
            return ApiKeyStatus.REVOKED
        if self.expires_at is not None and self.expires_at <= now:
            return ApiKeyStatus.EXPIRED
        return ApiKeyStatus.ACTIVE

    def is_active(self, now: datetime) -> bool:
        return self.status(now) == ApiKeyStatus.ACTIVE

    def revoke(self, now: datetime) -> None:
        if self.revoked_at is not None:
            return
        self.revoked_at = now
        self.save(update_fields=["revoked_at", "updated_at"])
```

> and tests do not have. To change: make it `instance.issue(site=...)` and edit the spec line.

class ApiKeyFactory(SiteAwareFactory):
    class Meta:
        model = ApiKey

    name = factory.Sequence(lambda n: f"Key {n}")
    scopes = factory.LazyFunction(lambda: [ApiScope.USERS])

    @classmethod
    def _create(
        cls, model_class: type[ApiKey], *args: object, **kwargs: object
    ) -> ApiKey:
        # issue() is the only path that produces a prefix and hash, so the
        # factory goes through it and keeps the key text where tests read it.
        # `site` is the ambient site from mock_site_context unless a test
        # passes one, which only the host-mismatch tests do.
        site = kwargs.pop("site")
        if not isinstance(site, Site):
            raise ValueError("ApiKeyFactory needs a site: take mock_site_context or pass site=.")
        instance = model_class(*args, **kwargs)
        instance.issued_key = ApiKey.issue(instance, site=site)
        return instance
```

### 2.4 Authentication

`freedom_ls/api/authentication.py`:

```python
AUTH_FAILED_MESSAGE = "Invalid API key."
# A hash no key can match: the hash and compare run for an unknown prefix
# too, so that step costs the same either way (the row fetch does not).
_NO_MATCH_HASH = hash_key("")


def host_site(request: HttpRequest) -> Site | None:
    """The host's Site, or None when the host resolves to no row.

    Both failure shapes of site resolution end here: a rejected or unknown host
    (UnknownSite, Site.DoesNotExist) and a process with no request to resolve
    from (SiteResolutionError).
    """
    try:
        site = get_cached_site(request)
    except (Site.DoesNotExist, SiteResolutionError):
        return None
    return site if isinstance(site, Site) else None


class ApiKeyAuthentication(BaseAuthentication):
    def authenticate(self, request: Request) -> tuple[None, ApiKey] | None:
        header: str = request.META.get("HTTP_AUTHORIZATION", "")
        if not header:
            return None
        prefix, key_text = self._parse(header)
        # The Django request, not DRF's wrapper: the site cache lives on the
        # HttpRequest and the site-aware manager reads the same object.
        site = host_site(request._request)
        if site is None:
            raise AuthenticationFailed(AUTH_FAILED_MESSAGE)
        now = timezone.now()
        api_key = self._match(prefix, key_text, site, now)
        return (None, api_key)

    def authenticate_header(self, request: Request) -> str:
        return 'Bearer realm="api"'

    def _parse(self, header: str) -> tuple[str, str]:
        """The prefix and the key text of a well-formed `Bearer flsk_<prefix>.<secret>`."""
        parts = header.split()
        if len(parts) != 2 or parts[0].lower() != "bearer":
            raise AuthenticationFailed(AUTH_FAILED_MESSAGE)
        key_text = parts[1]
        prefix, dot, _secret = key_text.removeprefix(KEY_TEXT_PREFIX).partition(".")
        if not key_text.startswith(KEY_TEXT_PREFIX) or not dot:
            raise AuthenticationFailed(AUTH_FAILED_MESSAGE)
        return prefix, key_text

    def _match(self, prefix: str, key_text: str, site: Site, now: datetime) -> ApiKey:
        # The base manager: the default one filters on the host, and the
        # site match below is the explicit check this code is accountable for.
        api_key = ApiKey._base_manager.filter(key_prefix=prefix, site=site).first()
        expected = api_key.key_hash if api_key is not None else _NO_MATCH_HASH
        matched = hmac.compare_digest(hash_key(key_text), expected)
        if api_key is None or not matched or not api_key.is_active(now):
            raise AuthenticationFailed(AUTH_FAILED_MESSAGE)
        return api_key
```

```python
CURSOR_MAX_LENGTH = 512
BAD_CURSOR = "The cursor is not one this API issued."

M = TypeVar("M", bound=Model)


class ApiKeysetPagination(BasePagination):
    ordering = ("updated_at", "id")
    cursor_query_param = "cursor"
    page_size_query_param = "page_size"

    def paginate_queryset(
        self, queryset: QuerySet[M], request: Request, view: APIView | None = None
    ) -> list[M]:
        self.request = request
        self.page_size = self._page_size(request)
        position = self._decode_cursor(request, queryset.model)
        queryset = queryset.order_by(*self.ordering)
        if position is not None:
            updated_at, last_pk = position
            queryset = queryset.filter(
                Q(updated_at__gt=updated_at) | Q(updated_at=updated_at, pk__gt=last_pk)
            )
        # One row past the page says whether a next page exists without a count.
        rows = list(queryset[: self.page_size + 1])
        self.has_next = len(rows) > self.page_size
        self.rows: list[M] = rows[: self.page_size]
        return self.rows

    def get_paginated_response(self, data: list[dict[str, object]]) -> Response:
        return Response({"next": self._next_link(), "results": data})

    def _page_size(self, request: Request) -> int:
        return config.API_PAGE_SIZE

    def _next_link(self) -> str | None:
        if not self.has_next:
            return None
        last = self.rows[-1]
        cursor = self._encode_cursor(last.updated_at, last.pk)
        # replace_query_param keeps every other parameter of the request.
        return replace_query_param(
            self.request.build_absolute_uri(), self.cursor_query_param, cursor
        )

    def _encode_cursor(self, updated_at: datetime, pk: int | UUID) -> str:
        payload = json.dumps([updated_at.isoformat(), str(pk)])
        return urlsafe_b64encode(payload.encode()).decode()

    def _decode_cursor(
        self, request: Request, model: type[Model]
    ) -> tuple[datetime, int | UUID] | None:
        raw = request.query_params.get(self.cursor_query_param)
        if raw is None:
            return None
        if len(raw) > CURSOR_MAX_LENGTH:
            raise ValidationError({self.cursor_query_param: [BAD_CURSOR]})
        try:
            decoded = json.loads(urlsafe_b64decode(raw.encode()))
            # Exactly two strings: anything else is not a cursor this class wrote.
            if not (
                isinstance(decoded, list)
                and len(decoded) == 2
                and all(isinstance(part, str) for part in decoded)
            ):
                raise ValueError(BAD_CURSOR)
            updated_at = datetime.fromisoformat(decoded[0])
            if timezone.is_naive(updated_at):
                raise ValueError(BAD_CURSOR)
            pk = model._meta.pk.to_python(decoded[1])
        except (ValueError, TypeError, binascii.Error, UnicodeDecodeError, DjangoValidationError) as exc:
            raise ValidationError({self.cursor_query_param: [BAD_CURSOR]}) from exc
        return updated_at, pk
```

`pk.to_python` is what makes the ordering work for both the users' integer pk and the UUID pks of
`SiteAwareModel` rows, and turns a value of the wrong shape into a 400 instead of an ORM error.

`freedom_ls/api/throttling.py`:

```python
class ApiKeyRateThrottle(SimpleRateThrottle):
    scope = "api_key"

    def get_rate(self) -> str:
        # DRF's own get_rate reads a REST_FRAMEWORK setting this project does not define.
        return config.API_THROTTLE_RATE

    def get_cache_key(self, request: Request, view: APIView) -> str | None:
        api_key = request.auth
        if not isinstance(api_key, ApiKey):
            return None
        # The pk, never the key text or its hash, so the cache holds no secret material.
        return self.cache_format % {"scope": self.scope, "ident": str(api_key.pk)}

def _record_use(self, api_key: ApiKey, now: datetime) -> None:
    # The base manager: authentication has already matched the key to the
    # host's site, and this runs where the default manager may see no site.
    # One conditional update per key per resolution window: a crawl of
    # thousands of pages writes the row once, and update() leaves updated_at alone.
    ApiKey._base_manager.filter(pk=api_key.pk).filter(
        Q(last_used_at__isnull=True) | Q(last_used_at__lt=now - LAST_USED_RESOLUTION)

        obj.issued_key = ApiKey.issue(obj, site=site)
        record_entry(
            action="api_key.issued", actor=request.user, target=obj, target_label=str(obj),
            organisation=None, details=key_details(obj),
        )

    def response_add(
        self, request: HttpRequest, obj: ApiKey, post_url_continue: str | None = None
    ) -> HttpResponse:
        # No redirect and no messages call: the key must be shown once, and
        # a message would store it in the messages cookie or the session.
        context = {
            "api_key": obj,
            "key_text": obj.issued_key,
            "changelist_url": reverse("admin:freedom_ls_api_apikey_changelist"),
            **admin_page_context(request, self, "API key issued"),
        }
        response = TemplateResponse(request, "admin/api_admin/key_issued.html", context)
        patch_cache_control(response, no_store=True)
        return response

    @admin.display(description="Scopes")
    def scope_list(self, obj: ApiKey) -> str:
        return ", ".join(ApiScope(scope).label for scope in obj.scopes)

    @admin.display(description="Status")
    def status(self, obj: ApiKey) -> str:
        return obj.status(timezone.now()).label


def key_details(api_key: ApiKey) -> dict[str, JSONValue]:
    return {
        "name": api_key.name,
        "key_prefix": api_key.key_prefix,
        "scopes": list(api_key.scopes),
        "expires_at": api_key.expires_at.isoformat() if api_key.expires_at else None,
    }
```

Django's `changeform_view` wraps the add in `transaction.atomic`, so the audit entry written inside
`save_model` rolls back with the key. `log_addition` runs after `save_model` on the same `obj`, so
the admin `LogEntry` links the saved row.

class ApiKeyStatusFilter(admin.SimpleListFilter):      # filters.py
    title = "status"
    parameter_name = "status"

    def lookups(self, request: HttpRequest, model_admin: ModelAdmin) -> list[tuple[str, str]]:
        return list(ApiKeyStatus.choices)

    def queryset(self, request: HttpRequest, queryset: QuerySet[ApiKey]) -> QuerySet[ApiKey]:
        now = timezone.now()
        match self.value():
            case ApiKeyStatus.ACTIVE:
                return queryset.filter(revoked_at__isnull=True).filter(
                    Q(expires_at__isnull=True) | Q(expires_at__gt=now)

            case ApiKeyStatus.EXPIRED:
                return queryset.filter(revoked_at__isnull=True, expires_at__lte=now)
            case ApiKeyStatus.REVOKED:
                return queryset.filter(revoked_at__isnull=False)
        return queryset

```python
# views.py
def revoke_view(request: HttpRequest, *, model_admin: ApiKeyAdmin) -> HttpResponse:
    """Confirm on GET, revoke on POST, for the keys named by `ids`.

    admin_view supplies login and CSRF; the change permission is checked
    here because neither the list action nor the detail button can be
    reached without it, and this URL can be typed by hand.
    """
    if not model_admin.has_change_permission(request):
        raise PermissionDenied
    keys = list(model_admin.get_queryset(request).filter(pk__in=_ids_from(request)))
    if not keys:
        raise Http404
    if request.method == "POST":
        count = _revoke(request, keys)
        message = ngettext(
            "Revoked %(count)d API key. Scripts using it stop at once.",
            "Revoked %(count)d API keys. Scripts using them stop at once.",
            count,
        )
        model_admin.message_user(request, message % {"count": count})
        return redirect(_back_url(keys))
    context = {
        "to_revoke": [key for key in keys if key.revoked_at is None],
        "already_revoked": [key for key in keys if key.revoked_at is not None],
        "ids": ",".join(str(key.pk) for key in keys),
        "cancel_url": _back_url(keys),
        **admin_page_context(request, model_admin, "Revoke API keys"),
    }
    return TemplateResponse(request, "admin/api_admin/revoke_confirm.html", context)


def _ids_from(request: HttpRequest) -> list[UUID]:
    raw = request.POST.get("ids", "") if request.method == "POST" else request.GET.get("ids", "")
    try:
        return [UUID(part) for part in raw.split(",") if part]
    except ValueError as exc:
        raise Http404 from exc


def _revoke(request: HttpRequest, keys: list[ApiKey]) -> int:
    now = timezone.now()
    revoked = 0
    with transaction.atomic():
        for key in keys:
            if key.revoked_at is not None:
                continue
            key.revoke(now)
            record_entry(
                action="api_key.revoked", actor=request.user, target=key,
                target_label=str(key), organisation=None, details=key_details(key),
            )
            revoked += 1
    return revoked


def _back_url(keys: list[ApiKey]) -> str:
    # One key came from its change page; several came from the list.
    if len(keys) == 1:
        return reverse("admin:freedom_ls_api_apikey_change", args=[keys[0].pk])
    return reverse("admin:freedom_ls_api_apikey_changelist")
```
