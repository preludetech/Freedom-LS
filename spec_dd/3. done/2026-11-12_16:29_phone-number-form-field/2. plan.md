# Plan: phone number form field

Spec: `1. spec.md`. Research: `research_codebase.md` in this directory.

The `phone` question type gains a country `<select>`, strict validation through
`phonenumberslite`, E.164 storage and international display. No model column, no migration, no
JavaScript.

## What exists and is reused

- `freedom_ls/form_engine/typed_answers.py`: `answer_error`, `format_answer`, `RejectedAnswer`.
  The phone branch slots into each. The message shape `You entered "<text>". Enter ...` is the
  one every other type uses.
- `freedom_ls/form_engine/submissions.py`: `submitted_text_answer`, `has_submitted_answer`.
  `has_submitted_answer` is not changed.

  `<legend>` and the one error paragraph `question_<id>_error`. The new input template sits inside
  it. Both consuming apps render questions through this template, HTMX re-renders included.

- `templatetags/form_engine_tags.py`: `upload_limits` is the pattern for a simple tag that
  returns a `dict[str, object]`; `answer_display` already calls `format_answer`.

## Facts checked against `phonenumberslite` 9.0.43

- `SUPPORTED_REGIONS` has 245 countries. `example_number` returns a number for every one, and
  Babel's `en_US` locale names every one. The "no example number" branch therefore needs a test
  that makes the lookup miss: `monkeypatch` `phonenumbers.example_number`. It is the only thing a
  test patches. The "Babel cannot name it" branch is reached without a patch: Babel's Chechen
  locale (`ce`) has no name for `MK`, so `country_choices()` under `translation.override("ce")`
  yields `("MK", "MK (+389)")`.
- `example_number("IT")` is `02 1234 5678` nationally and `+390212345678` in E.164: the leading
  `0` stays.
- For every supported country, the fixed-line, mobile and toll-free example numbers formatted
  nationally parse back, with that country, to the same E.164. Slice 5 still refills in a
  different form: the number after its calling code, which is the only form strict entry accepts.
- `parse(text, "ZA", keep_raw_input=True)` silently strips a trunk `0` (`082…`), a calling code
  typed without `+` (`27…`, `country_code_source == FROM_NUMBER_WITHOUT_PLUS_SIGN`) and an IDD
  prefix (`0027…`). All three give `+27821234567`, so slice 5 compares the typed digits with
  `national_significant_number` to tell them apart.
- `parse("082 123 4567", "ZA")` → `+27821234567`, international `+27 82 123 4567`, national
  `082 123 4567`.
- `parse("+27 82 123 4567", "GB")` → `+27821234567`.
- `parse("0800 FLOWERS", "ZA")` succeeds (letters become digits), so letters need their own check.
- `parse("082 123 4567 ext. 12", "ZA")` succeeds with `extension == "12"`.
- `parse("hello", "ZA")` raises `NumberParseException`.
- `parse("082 123 4567", None)` raises `NumberParseException` (no country).
- `region_code_for_number(parse("+27821234567"))` → `"ZA"`.

Expected values in tests are hard-coded strings like the ones above. A valid input may come from
`example_number(country)`; the expected output is never recomputed with the same library call.

## Slices

### Slice 1: a phone answer is checked against the chosen country and stored as E.164

A learner or applicant picks a country, types a number and submits. A valid number is stored as
E.164. An invalid one comes back with its message, the typed number and the chosen country.

This slice carries the whole check, extensions and letters included, with its export and
browser tests (decided): a thinner first slice would store `ext. 12` and `0800 FLOWERS` as
numbers nobody typed until a later slice landed.

2. Create `freedom_ls/form_engine/phone_numbers.py`. It imports `phonenumbers`, `babel`,
   `unicodedata`, `functools`, `django.conf.settings` and `django.utils.translation`: never
   `models`. Add
   `"phone_numbers"` to the parametrised list in `tests/invariants/test_import_independence.py`.

   ```python
   """Phone answers: the countries on offer, the check a submission must pass, and
   the one stored form.

   Every call into `phonenumbers` lives here, so the rest of the form engine
   speaks in countries and strings. Imports no `models`, which reaches this
   module through `typed_answers`.
   """

   # The library's word for a country. Re-exported so callers that only need
   # membership do not import the library themselves.
   SUPPORTED_REGIONS = phonenumbers.SUPPORTED_REGIONS


   def _active_language() -> str:
       # None while translations are deactivated, as in a management command.
       return translation.get_language() or settings.LANGUAGE_CODE


   @functools.cache
   def _locale(language: str) -> Locale:
       """Babel's locale for a Django language code.

       Django writes "en-us" where Babel wants "en_US". A language Babel does
       not know falls back to the site's default instead of failing the page.
       """
       try:
           return Locale.parse(translation.to_locale(language))
       except UnknownLocaleError:
           return Locale.parse(translation.to_locale(settings.LANGUAGE_CODE))


   def _country_name(country: str, language: str) -> str:
       """The country's name in `language`, or its code when Babel has no name."""
       return _locale(language).territories.get(country, country)


   def _sort_key(name: str) -> str:
       # Accent-folded, so "Åland Islands" sorts under A instead of after Z.
       folded = unicodedata.normalize("NFKD", name)
       return "".join(ch for ch in folded if not unicodedata.combining(ch)).casefold()


   @functools.cache
   def _country_choices(language: str) -> tuple[tuple[str, str], ...]:
       named = [(country, _country_name(country, language)) for country in SUPPORTED_REGIONS]
       named.sort(key=lambda pair: _sort_key(pair[1]))
       return tuple(
           (country, f"{name} (+{phonenumbers.country_code_for_region(country)})")
           for country, name in named
       )


   def country_choices() -> list[tuple[str, str]]:
       """One `(country, label)` pair per supported country, sorted by name."""
       return list(_country_choices(_active_language()))
   ```

   ```python
   def _parsed(text: str, country: str) -> PhoneNumber | None:
       """`text` as a phone number, or None when it does not parse.

       A leading + wins over the selected country: a pasted or autofilled
       international number is read as typed, whatever the picker says. For any
       other number the library strips the country's own trunk prefix, so no
       digit is added or removed by hand.
       """
       default_country = None if text.startswith("+") else country or None
       try:
           return phonenumbers.parse(text, default_country)
       except NumberParseException:
           return None


   def phone_answer_error(text: str, country: str) -> str | None:
       """Why `text`, with `country` selected, is not an acceptable phone answer."""
       if not text.startswith("+") and not country:
           return (
               f'You entered "{text}". Choose a country, or start the number '
               f"with + and its country code."
           )
       number = _parsed(text, country)
       if number is None:
           return _invalid_message(text, country)
       if number.extension:
           # E.164 cannot hold an extension, and dropping it without a word would
           # store a different number than the one typed.
           return f'You entered "{text}". Enter the number without an extension.'
       # The library reads letters as keypad digits ("0800 FLOWERS"). A typed word
       # is far more often a mistake than a vanity number.
       if any(ch.isalpha() for ch in text) or not phonenumbers.is_valid_number(number):
           return _invalid_message(text, country)
       return None


   def _invalid_message(text: str, country: str) -> str:
       if text.startswith("+"):
           return (
               f'You entered "{text}". Enter a valid phone number, starting '
               f"with + and its country code."
           )
       name = _country_name(country, _active_language())
       example = phonenumbers.example_number(country)
       like = (
           f", like {phonenumbers.format_number(example, PhoneNumberFormat.NATIONAL)}"
           if example is not None
           else ""
       )
       return f'You entered "{text}". Enter a valid phone number for {name}{like}.'


   def e164_phone_answer(text: str, country: str) -> str:
       """The E.164 form of an answer `phone_answer_error` accepted."""
       number = _parsed(text, country)
       if number is None:
           raise ValueError(f"not a phone number: {text!r}")
       return phonenumbers.format_number(number, PhoneNumberFormat.E164)
   ```

   The extension check runs before the letters check, so `ext. 12` gets the extension message
   and not the letters one.

   def submitted_phone_country(question: FormQuestion, post_data: QueryDict) -> str:
       """The country selected beside a phone question, or "" for none.

       The key sits outside the `question_` prefix: the exam runner counts every

6. `templatetags/form_engine_tags.py`: add the simple tag `phone_field_state`. In this slice it
   knows the rejected answer and the stored text only.

   ```python
   @register.simple_tag(takes_context=True)
   def phone_field_state(context: Context) -> dict[str, object]:
       """What the phone question's two controls show: the selected country, the
       number, and the countries on offer.

       Reads `question`, `rejected` and `existing_answers` from the context the
       question template already holds, so no view computes anything for it.
       """
       question = context["question"]
       rejected = context.get("rejected")
       if rejected:
           # An empty choice stays empty: someone who cleared the picker and
           # was refused must not find a country chosen for them.
           country, number = rejected.country, rejected.text
       else:
           answer = (context.get("existing_answers") or {}).get(question.id)
           country, number = "", answer.text_answer if answer else ""
       return {"country": country, "number": number, "choices": country_choices()}
   ```

   cleanly because the leading `+` carries the country.

### Slice 3: a stored answer refills the country and the number

Someone who returns to a page they already answered sees their country selected and their number
in national format, as they typed it.

**Builds on:** slices 1, 2
**Touches:** freedom_ls/form_engine/phone_numbers.py, freedom_ls/form_engine/templatetags/form_engine_tags.py, freedom_ls/form_engine/tests/test_phone_numbers.py, freedom_ls/form_engine/tests/templatetags/test_form_engine_tags.py

1. `phone_numbers.py`, both built on `_stored`:

   ```python
   def stored_phone_country(text: str) -> str | None:
       """The country of a stored E.164 answer, or None for a legacy row or a
       number that belongs to no supported country."""
       number = _stored(text)
       if number is None:
           return None
       # The library answers None for a number shared by no single country and
       # "001" for a non-geographic one; neither is a country on offer.
       country = phonenumbers.region_code_for_number(number)
       return country if country in SUPPORTED_REGIONS else None


   def national_phone(text: str) -> str:
       """A stored answer in national format, for refilling the number input.

       The raw text when there is no country to select beside it: a national
       number with no country would not resubmit to the number that is stored.
       """
       number = _stored(text)
       if number is None or stored_phone_country(text) is None:
           return text
       return phonenumbers.format_number(number, PhoneNumberFormat.NATIONAL)
   ```

1. `phone_numbers.browser_country`:

   ```python
   def _quality(parameters: list[str]) -> float:
       """The tag's q value: 1 when absent, 0 when unreadable, so a tag with a
       broken weight is dropped instead of promoted."""
       for parameter in parameters:
           name, _, value = parameter.strip().partition("=")
           if name.strip() == "q":
               try:
                   return float(value)
               except ValueError:
                   return 0.0
       return 1.0


   def _tag_country(tag: str) -> str | None:
       """The country a language tag names, or None when it names none on offer."""
       try:
           _language, region_subtag, *_rest = parse_locale(tag, sep="-")
       except ValueError:
           # "*", an empty tag, or anything else that is not a language tag.
           return None
       # Membership also drops the numeric and non-geographic region subtags a
       # tag can carry: "419", "001", "EU".
       return region_subtag if region_subtag in SUPPORTED_REGIONS else None


   def browser_country(accept_language: str) -> str | None:
       """The country the browser's Accept-Language header names, if any.

       Read by hand instead of through LocaleMiddleware, which would switch the
       active language for the whole site.
       """
       weighted: list[tuple[float, str]] = []
       for part in accept_language.split(","):
           tag, *parameters = part.split(";")
           quality = _quality(parameters)
           if quality > 0:
               weighted.append((quality, tag.strip()))
       # The sort is stable, so tags of equal weight keep the header's order.
       weighted.sort(key=lambda pair: -pair[0])
       countries = (_tag_country(tag) for _, tag in weighted)
       return next((country for country in countries if country is not None), None)
   ```

   `parse_locale` returns a tuple whose length differs across Babel versions; unpack only the
   first two items as above. Under the installed Babel, `parse_locale("zh-Hant-TW", sep="-")`
   gives `("zh", "TW", "Hant", None)`, `es-419` gives a second item of `"419"`, and `"*"`, `""`,
   `"en-"` and `";;;"` raise `ValueError`. Catch nothing wider.

   The header is parsed by hand (decided). Django's `parse_accept_lang_header` lives in the
   semi-private `translation.trans_real`, keeps `q=0` tags and returns nothing at all for a
   header with one malformed part.

2. `phone_field_state` reaches its finished shape. The browser country is the last resort, inside
   the no-rejection branch:

   ```python
   @register.simple_tag(takes_context=True)
   def phone_field_state(context: Context) -> dict[str, object]:
       question = context["question"]
       rejected = context.get("rejected")
       if rejected:
           # An empty choice stays empty: someone who cleared the picker and
           # was refused must not find a country chosen for them.
           country, number = rejected.country, rejected.text
       else:
           answer = (context.get("existing_answers") or {}).get(question.id)
           stored = answer.text_answer if answer else ""
           country = stored_phone_country(stored) or ""
           number = national_phone(stored)
           if not stored:
               # Only an empty question takes the browser's hint. Guessing a
               # country beside a number someone already typed could change
               # which number it means.
               request = context.get("request")
               header = request.headers.get("Accept-Language", "") if request else ""
               country = browser_country(header) or ""
       return {"country": country, "number": number, "choices": country_choices()}
   ```

   The docstring written in slice 1 stays, with `request` added to what it reads.
