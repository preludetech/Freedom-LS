# Plan: direct messaging

Implementation plan for `1. spec.md`. The spec's vocabulary is used throughout: `Conversation`,
`ConversationParticipant`, `Message`, inbox, thread, composer, picker, rollup, closed note.

The plan is a sequence of vertical slices. Each slice leaves `uv run pytest` and the pre-commit
hooks green and can be committed alone. Tests follow TDD: the test list in each slice names what the
tests prove, not their code. Every function the plan sketches is fully typed in the code (`User`,
`Site`, `UUID`, `QuerySet[Conversation]`, and so on); the sketches leave annotations out for
brevity only.

Facts that shape the plan:

- `User.pk` is an integer. `pair_key` is `f"{min(a.pk, b.pk)}:{max(a.pk, b.pk)}"`.
- `comms` may import only `accounts`, `base` and `site_aware_models`
  (`comms/tests/invariants/test_boundaries.py`). Every relationship question goes through
  `get_messaging_policy()`. `RecipientGroup` and the base `group_recipients` live in
  `comms/messaging_policy.py`; the role and cohort lookups live in `messaging_policy/policy.py`.
- `comms` templates may use `panel_framework` cotton components (template names, not imports), as the
  spec already does for `<c-panel-search-field>`.
- `SiteAwareModel.save()` fills `site` from the request's thread-local. `notify.py` passes `site_id`
  explicitly so the write works outside a request; the messaging service does the same: every
  `create()` passes `site=`, every lookup filters `site=`, and `bulk_create` is never used.
- `panel_framework` has no section visibility hook, no count-URL hook, and the quick view has no
  dirty check. Slices 12, 13 and 16 add them.
- Domain events in `HX-Trigger` are camelCase (`learnerChanged`). The messaging event is
  `conversationChanged`, with no payload.
- The educator interface routes everything through one catch-all `re_path`; new educator URLs go
  before it in `freedom_ls/educator_interface/urls.py`.
- `interface_walk.py` asserts every `ListViewConfig` has an `instance_view`, so the section's list
  and thread page land in one slice.
- Views that return an htmx partial are named `partial_*` (`ds:htmx`); the spec fixes URL names,
  not Python function names.
- Migrations come from `uv run manage.py makemigrations comms -n <name>`, never by hand.
  `docs/app_structure.md` and `test_organisation/import_contracts.toml` are regenerated with
  `/ds:app_map` at the end of every slice that adds a module or a cross-app or test import, never
  edited by hand.
- Every new module gets its mirrored test file (`<app>/tests/test_<module>.py`); the slices name
  them. No new `tests/` subpackage is added, so `mirroring_exemptions.txt` is untouched.

## Slices

### Slice 1: a thread with sending

**Delivers:** the three models, the service's create and send paths, and the thread page with its
composer, behind `MESSAGING_ENABLED`. With a factory-made conversation a participant can open the
thread by URL, read its messages and send a reply. A refused or invalid send returns 422 with the
draft kept. A double click posts once.

Settings (`freedom_ls/comms/config.py`): add `MESSAGING_ENABLED` (False), `MESSAGE_MAX_LENGTH`
(2000) and `MESSAGE_PAGE_SIZE` (30) to `CommsConfig` with `declared_settings`.
`config/settings_base.py`: `MESSAGING_ENABLED = False` beside `NOTIFICATIONS_ENABLED`;
`config/settings_dev.py`: `True`. The other two settings arrive with the slices that read them.

Glossary: add `Conversation`, `Message`, inbox and thread to
`.claude/skills/domain-glossary/SKILL.md` now, since the names enter the code here.

Models (`freedom_ls/comms/models.py`; `uv run manage.py makemigrations comms -n conversation_message`):

```python
class Conversation(SiteAwareModel):
    # "<low user pk>:<high user pk>", written only by get_or_create_conversation.
    pair_key = models.CharField(max_length=64)
    created_at = models.DateTimeField(auto_now_add=True)
    last_message_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        constraints = [models.UniqueConstraint(fields=["site", "pair_key"], name="comms_conversation_pair_per_site")]


class ConversationParticipant(SiteAwareModel):
    conversation = models.ForeignKey(Conversation, on_delete=models.CASCADE, related_name="participants")
    user = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name="conversation_participants")
    # The created_at of the newest message this participant was shown, never "now", so a message
    # that lands between render and mark stays unread.
    last_read_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        constraints = [models.UniqueConstraint(fields=["conversation", "user"], name="comms_participant_once_per_conversation")]
        indexes = [models.Index(fields=["user", "site"], name="comms_participant_user_site_idx")]


class Message(SiteAwareModel):
    conversation = models.ForeignKey(Conversation, on_delete=models.CASCADE, related_name="messages")
    # Null once the sender's account is deleted; the text stays for the other participant.
    sender = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.SET_NULL, null=True, blank=True, related_name="sent_messages")
    body = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
    client_key = models.UUIDField(null=True, blank=True)

    class Meta:
        constraints = [models.UniqueConstraint(fields=["conversation", "sender", "client_key"], condition=Q(client_key__isnull=False), name="comms_message_client_key_once")]
        indexes = [models.Index(fields=["conversation", "created_at", "id"], name="comms_message_cursor_idx")]
```

def pair_key_for(user_a, user_b) -> str: ...

def conversation_between(user_a, user_b, site) -> Conversation | None:
    return Conversation.objects.filter(site=site, pair_key=pair_key_for(user_a, user_b)).first()

def get_or_create_conversation(*, user_a, user_b, site) -> Conversation:
    existing = conversation_between(user_a, user_b, site)
    if existing is not None:
        return existing
    try:
        with transaction.atomic():
            conversation = Conversation.objects.create(site=site, pair_key=pair_key_for(user_a, user_b))
            for user in (user_a, user_b):
                ConversationParticipant.objects.create(site=site, conversation=conversation, user=user)
    except IntegrityError:
        # Two first messages raced; the row the other transaction committed is the conversation.
        return Conversation.objects.get(site=site, pair_key=pair_key_for(user_a, user_b))
    return conversation

def send_message(*, sender, body, client_key: UUID, site, conversation=None, recipient=None) -> SendResult:
    body = normalise_body(body)
    if not body.strip():
        return SendResult(conversation=conversation, body_error=BLANK_BODY)
    if len(body) > config.MESSAGE_MAX_LENGTH:
        return SendResult(conversation=conversation, body_error=TOO_LONG_BODY % {"limit": ...})
    if conversation is None and recipient is not None:
        conversation = conversation_between(sender, recipient, site)
    if conversation is not None:
        repeat = _existing_send(conversation, sender, client_key)
        if repeat is not None:
            # A retry of a send that already landed is answered with the original, whatever the policy says now.
            return SendResult(message=repeat, conversation=conversation)
        decision = reply_decision(viewer=sender, conversation=conversation)
    else:
        decision = get_messaging_policy().can_start(sender=sender, recipient=recipient, site=site)
    if not decision.allowed:
        return SendResult(conversation=conversation, refusal=decision.reason)
    with transaction.atomic():
        if conversation is None:
            conversation = get_or_create_conversation(user_a=sender, user_b=recipient, site=site)
        locked = Conversation.objects.select_for_update().get(pk=conversation.pk)
        repeat = _existing_send(locked, sender, client_key)   # a same-key send may have committed while we waited for the lock
        if repeat is not None:
            return SendResult(message=repeat, conversation=locked)
        message = Message.objects.create(site=site, conversation=locked, sender=sender, body=body, client_key=client_key)
        locked.last_message_at = message.created_at
        locked.save(update_fields=["last_message_at"])
        mark_conversation_read(user=sender, conversation=locked, up_to=message.created_at)
    return SendResult(message=message, conversation=locked)

// A poll timer that stops while the tab is hidden and fires once when it comes back,
// dispatching a "refresh" DOM event the element's hx-trigger listens for.
function visibilityPoller(seconds, target) {
    let timer = null;
    const stop = () => { if (timer) clearInterval(timer); timer = null; };
    const refresh = () => target.dispatchEvent(new CustomEvent("refresh"));
    const start = (refreshNow) => { stop(); if (refreshNow) refresh(); timer = setInterval(refresh, seconds * 1000); };
    const onVisibility = () => (document.visibilityState === "visible" ? start(true) : stop());
    document.addEventListener("visibilitychange", onVisibility);
    start(false);
    return { destroy() { stop(); document.removeEventListener("visibilitychange", onVisibility); } };
}

Alpine.data("refreshTimer", () => {
    let poller = null;   // a closure, not reactive state: Alpine must not proxy the timer object
    return {
        init() { poller = visibilityPoller(Number(this.$el.dataset.pollSeconds), this.$refs.target || this.$el); },
        destroy() { poller.destroy(); },
    };
});

```python
def write() -> None:
    if not notification_category.rollup:
        create_and_enqueue(rollup_key=None)
        return
    rollup_key = f"{ContentType.objects.get_for_model(target).pk}:{target.pk}"
    if update_unread_rollup(rollup_key):
        return
    try:
        with transaction.atomic():
            create_and_enqueue(rollup_key=rollup_key)
    except IntegrityError:
        # A concurrent raise created the unread row first; this event folds into it.
        update_unread_rollup(rollup_key)

def update_unread_rollup(rollup_key: str) -> bool:
    # An update re-surfaces the row and re-lights the badge; it enqueues no delivery.
    return bool(Notification.objects.filter(user=user, site_id=site_id, rollup_key=rollup_key, read_at__isnull=True)
                .update(data=data, created_at=timezone.now(), seen_at=None))
```
