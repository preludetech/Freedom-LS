# Answers: educator-intercface-small-ui-polish

Asked by `/sdd:start` before the spec was written.

- Q: In the course content preview modal, what should Next/Previous step through, and what happens at the ends? → A: The whole course in outline order, across parts; Previous is disabled on the first item and Next on the last (asked up front)
- Q: With Next/Previous replacing the Close button in the preview modal footer, how does the educator close the modal? → A: The modal's header X, Esc and backdrop click; only the footer Close button goes (asked up front)
- Q: If the button-text misalignment turns out to be caused in the First Class concrete repo rather than the FLS theme, what should this spec do? → A: Fix whatever is in FLS; a First Class cause is recorded as a downstream note for that repo (asked up front)
- Q: On the course page's cohort and direct registration panels, what should "remove a registration" do? → A: Reuse the existing functionality from the cohort and learner pages; educators can take the same actions on the course page (asked up front)
- Q: Where does the Reference outline go, and does Next/Previous cover it? → A: Reference sits in the Content tab, collapsed by default; Next/Previous in a reference preview steps through reference items only (asked up front)
- Q: Which quiz stats does the quiz top-level preview show? → A: Quiz facts and settings only (pages, questions, pass mark and the quiz settings); no learner results (asked up front)
