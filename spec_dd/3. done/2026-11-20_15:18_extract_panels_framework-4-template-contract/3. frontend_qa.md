# Frontend QA: panel framework templates, JS and CSS stop assuming FLS

The panel framework now draws its buttons, chips, menus, pagination, callouts and dates through its
own `panel-*` primitives and its own stylesheet. FLS overrides every primitive with a thin wrapper,
so the educator interface must look and behave exactly as it did before this change. The framework also
ships a minimal shell that the reference page can run in. This run checks both: FLS unchanged, and
the minimal shell working.

Substitute the literal port number from `.claude/ds/scripts/find_available_port.sh` wherever this
document writes `$PORT`. Shell variables do not survive between tool calls. Never use port 8000.

Viewports for every layout check: 375×812, 768×1024, 1920×1080.

## §0 Setup

### 0.1 Build and server

1. `uv run python manage.py migrate`.
2. `npm run tailwind_build`. It must finish with no error, and afterwards both
   `tailwind.panel_framework.css` and
   `freedom_ls/panel_framework/static/panel_framework/css/reference.css` exist while `git status`
   lists neither.
3. `.claude/ds/scripts/find_available_port.sh`: note the number and use it literally from here on.
4. Start `uv run python manage.py runserver $PORT` backgrounded, as its own call.
5. Open `http://127.0.0.1:$PORT/` and confirm `#debug-branch-badge` names
   `extract_panels_framework-4-template-contract`. If not, go back to step 3.

### 0.2 Data and login

1. `uv run python manage.py content_save demo_content DemoDev`.
2. Log in as `demodev@email.com` (password = email).
3. Through `sdd:qa-data-helper`, make sure one cohort has at least 25 learners, so its learner
   table paginates and can be bulk-selected.

## §4 The minimal shell

The reference page runs in the minimal shell when the framework's own
`panel_framework/reference/base.html` is the one that loads. FLS overrides that template, and its
`panel-*` wrappers shadow the framework primitives, all by template path. So this section's
settings put the framework's template directory ahead of FLS's, the way the framework's own test
tiers do: the page then extends the minimal shell and draws the framework primitives it is styled
for.

1. In the scratchpad directory, write `qa_minimal_shell_settings.py` holding these two lines:

   ```python
   from config.settings_dev import *
   TEMPLATES[0]["DIRS"] = [str(BASE_DIR / "freedom_ls/panel_framework/templates"), *TEMPLATES[0]["DIRS"]]
   ```
2. Take a second free port and start
   `PYTHONPATH=<scratchpad directory> uv run python manage.py runserver <that port> --settings=qa_minimal_shell_settings`.
3. Log in through `/admin/login/` on that port, then open `/panel-framework/components/`.

Expected, at each viewport:

- The page has no FLS header or footer. It has a main region and the examples. The reference page
  is a component catalogue: it sets no page title and no menu groups, so the sidebar is empty and
  there is no navigation toggle.
- It is styled: buttons, chips, cards and tables look finished, in neutral colours. An unstyled
  page means `reference.css` did not load; check the network tab for a 404.
- The class list of a button holds `panel-btn`, and of a chip `panel-chip`.
- Every icon shows: the close control, the dropdown chevrons, the search field's glass, the sort
  arrows and the loading spinner. They are the framework's own `c-panel-icon` bodies, each about
  the size of the text beside it. An icon that fills its container means the size class has no
  rule in `reference.css`.
- The navigation bottom sheet is not checked here, because this page has no navigation. It is
  checked on the educator pages in §1 (page h at 375 wide).
- The console shows no error, and no Alpine warning about `panelDropdownMenu`, `sidePanel`,
  `appModal` or `quickView`.
- The reason dialog examples render their fields in place, and the select in "choices" shows one
  chevron.
- The child-rows table expands and collapses a row; the compact table has tighter rows from 768
  up; the lazy panel shows its "as of" time.
- No horizontal scrollbar.

The reference page is a static catalogue: it has no live dropdown menu, quick view, dialog that
opens over the page or htmx request, so none is checked here. The framework's standalone Playwright
tier exercises those under the minimal shell (`freedom_ls/panel_framework/tests/playwright/`:
the quick view, instance dialog and create modal flows).

Do not open the educator interface on this server. The template order above shadows every FLS
wrapper of a framework primitive, `c-panel-icon` included, so FLS's sidebar icon names reach the
framework's default `c-panel-icon`, which raises `TemplateDoesNotExist` for a name it has no body
for, as the host contract says. §1 covers the educator interface on the normal server.

Stop that server and delete the scratchpad settings file.
