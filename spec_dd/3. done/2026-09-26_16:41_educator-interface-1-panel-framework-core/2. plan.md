### 2. Field display (requirement 7)

New file `freedom_ls/panel_framework/field_display.py`. Header: origin `django/contrib/admin/utils.py`, Django 6.0.4, "Copyright (c) Django Software Foundation and individual contributors", then the BSD-3-Clause text in full (copy it from `.venv/lib/python3.13/site-packages/Django-6.0.4.dist-info/` or Django's `LICENSE`).

Vendor, in this order: `FieldIsAForeignKeyColumnName`, `NotRelationField`, `get_model_from_relation`, `get_fields_from_path`, `_get_non_gfk_field`, `lookup_field`, `label_for_field`, `display_for_field`, `display_for_value`. Import `pretty_name` from `django.forms.utils` and `LOOKUP_SEP` from `django.db.models.constants`; nothing from `django.contrib.admin`.

Adaptations, each recorded in the module docstring so the parity test can list them:

- `model_admin` and `form` parameters dropped from `lookup_field` and `label_for_field`; the `hasattr(model, name)` branch is the method/property path.
- `label_for_field(name, model) -> str`. For a `__` path it returns the leaf field's `verbose_name` from `get_fields_from_path(model, name)[-1]`, not Django's `pretty_name` of the whole path. Unresolvable names raise `AttributeError("Unable to lookup '{name}' on {app_label}.{Model}")`.
- `lookup_field(name, obj) -> tuple[Field | None, object]`. For a `__` path it walks `getattr` per segment for the value and returns the leaf field from `get_fields_from_path`, so choices and booleans across a relation display like local ones. A missing segment returns `(None, None)`.
- `display_for_field(value, field, empty_value_display)`: a `bool` value on a `BooleanField` is returned as the `bool`; `None` on a nullable `BooleanField` falls through to the `empty_values` check. The `password`, `URLField` and `FileField` branches are gone; those values fall through to `display_for_value`. Choices, dates, decimals, ints, floats and JSON keep Django's formatting.
- `display_for_value(value, empty_value_display)`: `bool` returns the `bool`; `EMPTY_VALUES` returns the placeholder; the rest as Django.

Tests (`test_field_display.py`), using `StubModel` extended in task 15: choices label, `None` placeholder, `bool` round-trip, property, method, annotation (`StubModel.objects.annotate(...)`), `__` path through `StubChild.parent`, acronym `verbose_name` survives (`capfirst` is applied in the template, not here), and the parity test that imports `django.contrib.admin.utils` and asserts equality over a fixed input list except for the divergences named above.

### 3. Panels (requirements 2-6)

Rewrite `freedom_ls/panel_framework/panels.py`. Delete `freedom_ls/panel_framework/tabs.py`.

```python
class Panel:
    title: str = ""
    template_name: str = "panel_framework/panels/panel.html"
    region_template_name: str | None = None
    model: type[Model] | None = None
    children: dict[str, type[Panel]] = {}   # only containers set it
    child_segment: str = ""                 # "__panels" or "__tabs" on containers

    def __init__(self, ctx: PanelContext) -> None:
        self.ctx = ctx
        self.request = ctx.request
        self.instance = ctx.instance
        if self.model is not None and ctx.instance is None:
            raise ImproperlyConfigured(f"{type(self).__name__} declares model and needs an instance")

    def has_permission(self, request) -> bool: return True   # (plan note, not code: its docstring states what it gates, that it runs per request, and that the educator rules come later; cite no documents)
    def is_shown(self) -> bool:
        if not self.has_permission(self.request): return False
        return not self.children or bool(self.get_children())
    def get_actions(self) -> list[PanelAction]: return []
    @cached_property
    def _shown_children(self) -> list[Panel]:
        bound = [cls(replace(self.ctx, base_url=f"{self.ctx.base_url}/{self.child_segment}/{name}", name=name))
                 for name, cls in self.children.items()]
        return [child for child in bound if child.is_shown()]
    def get_children(self) -> list[Panel]: return self._shown_children
    def child(self, name) -> Panel:   # Http404 when missing or hidden
    @property
    def region_id(self) -> str:
        return "panel-" + re.sub(r"[^\w-]+", "-", self.ctx.base_url).strip("-")
    def get_context_data(self) -> dict[str, object]:
        actions = [a for a in self.get_actions() if a.has_permission(self.request, self.instance)]
        return {"panel": self, "request": self.request, "name": self.ctx.name,
                "base_url": self.ctx.base_url, "title": self.title,
                "actions": actions, "region_id": self.region_id,
                "region_template_name": self.region_template_name}
```

The child machinery lives on `Panel` with `children = {}` so leaves need no code and no intermediate class is introduced. `get_children()` is bound once per bound panel (`cached_property`), so `is_shown()`, `get_context_data()` and `get_active_child()` share one permission pass. `get_content`, `render` and `PanelGetter` are gone.

The shared `check_access`/`authorise_instance`/`required_request_attrs`/`check_access_exempt_reason` block is written once, on a plain concrete class `SectionConfigBase` that the three configs inherit. It holds real classmethods and attributes and no abstract methods, so it is the "extract repeated code" rule at work, not an abstract base class; duplicating the fail-closed contract three times would let the docstrings and the prologue drift apart. `check_access`'s fail-closed prologue (authenticated user, every `required_request_attrs` value present) is extracted into `check_request(cls, request) -> None`, which `check_access` calls first and which the `BaseViewConfig` branch of resolution calls before binding its panel, so a base view with `required_request_attrs` is enforced by the framework and not only by the host.

`InstanceView`: `panel: type[Panel]`, `__init__(instance)`, `get_actions()`, `get_action(name)`. `panels`, `tabs`, `panel_getter`, `get_tab`, `get_panel_from_tab`, `render`, `_render_*` and `render_tab` go.

Resolution. `_resolve_path(parts, sections, request)` returns a frozen `_Resolved` dataclass: `section`, `instance` (or `None`), `instance_view` (or `None`), `root` (bound root panel), `panel` (the addressed bound panel, initially `root`), `parents` (tuple of bound containers above `panel`), `action` (`_ResolvedAction | None`). Rules:

- `parts[0]` names a section, else 404.
- `ListViewConfig`: no more parts → list; `root = ListViewPanel(ctx(instance=None, base_url=section_url, name=""))` then `root.data_table = section.list_view`. A pk part → `get_instance_view`; `root = instance_view.panel(ctx(instance, base_url=instance_url, name=""))`.
- `ObjectViewConfig`: `get_object(request)`, `check_access`, then as an instance view with `base_url=section_url`.
- `BaseViewConfig`: `check_request(request)`, then `root = panel(ctx(instance=None, base_url=section_url, name=""))`.
- `__panels/<name>` requires the current panel to be a `PanelStack`, `__tabs/<name>` a `TabSet`; both call `current.child(name)` (404 when missing or hidden) and push the container onto `parents`.
- `__actions/<name>` resolves on the section (list actions), on the instance view (instance actions) or on the current panel (`get_actions()`); anything else 404.
- Bind with `_bound_root(...)` so `base_url` is `request.path` cut back to the right segment, as today.
