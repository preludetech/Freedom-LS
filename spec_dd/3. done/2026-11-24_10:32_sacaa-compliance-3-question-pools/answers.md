# Answers: sacaa-compliance-3-question-pools

Asked by `/sdd:start` before the spec was written.

- Q: What happens to a loose `FormContent` block (outside any keep-together group) on a page that draws N? → A: The validator rejects it; content on a drawing page must sit inside a group (asked up front)
- Q: Where does the draw live in the form files and in `content_save`? → A: `draw: N` on the page header only, nowhere else (asked up front)
- Q: Should the educator content preview show the pool size and N for a drawing page? → A: Yes, one line (asked up front)
