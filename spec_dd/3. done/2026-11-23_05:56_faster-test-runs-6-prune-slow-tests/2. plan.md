## Running on a machine shared with other worktrees

Other worktrees run their own suites on this machine, so CPU, memory and load change from one
run to the next. These rules hold in slices 3 to 5.

- **The long runs are counted.** Five in all: slice 3 has the first ranking run and the
  coverage-before run; slice 5 has the coverage-after run, the last ranking run and the full
  tier. No other run of the whole suite is added: no repeat for a steadier number, no interim
  ranking run in slice 4, no separate cross-check run. A sixth happens only when the last ranking
  run sends work back to slice 4 (slice 5, step 5).
- **One run at a time in this worktree.** While a ranking, coverage or tier run is in flight, start
  no other pytest and edit no file: a second run would share its `test_db_<branch>_gwN` databases
  and overwrite `.sdd-work/test_costs.json`, and an edit would make the header's commit SHA
  untrue. Wait for the completion notification.
- **Check memory before each long run.** `.claude/ds/scripts/run_tests.sh --capacity 768` must
  print 4 or more before a ranking or coverage run starts (they bypass the runner's own gate). If
  it prints less, wait and ask again; a worker killed for memory fails the run and wastes it.
- **Record load with every measurement.** The ranking header carries the load average and
  `/proc/pressure/cpu` `some avg60` at the start and at the end of the run. `timings.md` puts
  both beside every CPU and wall figure, so a reader can see whether two runs are comparable.
- **No rebase onto main between slice 3, step 2 and slice 5, step 5.** If a resumed run has
  rebased in between, do not repeat the "before" runs. Record the old and new base SHAs in
  `timings.md`, then:
  - coverage: leave out of the per-file comparison every file in
    `git diff --name-only <old base>..<new base>`, and list them as not compared;
  - target: raise or lower it by (summed first-run test cost of the node IDs main removed, taken
    from `.sdd-work/test_costs_first.json`, subtracted; summed last-run test cost of the node IDs
    main added, added) × (first run's total CPU seconds ÷ first run's summed test cost). Show the
    arithmetic.

### Slice 1: The recording plugin writes every test's cost

Behaviour: `pytest -p scripts.record_test_costs …` writes `.sdd-work/test_costs.json` holding,
per node ID, the setup, call and teardown seconds, with `django_db_setup` time taken out of the
triggering test and reported per worker; only the controller writes under xdist.

**Builds on:** none
**Touches:** scripts/record_test_costs.py, tests/test_rank_test_costs.py, pyproject.toml

#### `scripts/record_test_costs.py`

The module's only hook is `pytest_configure`, which registers one `CostRecorder` per session.
The recorder's methods are the other hooks and it holds the collected data as attributes, since
`pytest_runtest_logreport` receives no `config`. The module also owns the JSON shape that
`rank_test_costs.py` reads.

```python
DB_SETUP_FIXTURE = "django_db_setup"
DB_SETUP_PROPERTY = "django_db_setup_seconds"

class PhaseSeconds(TypedDict):
    setup: float
    call: float
    teardown: float

class CostsFile(TypedDict):
    tests: dict[str, PhaseSeconds]
    django_db_setup: dict[str, float]      # worker id -> seconds
    test_count: int
    outcomes: dict[str, int]

def costs_path(root: Path) -> Path:
    return root / ".sdd-work" / "test_costs.json"

def worker_name(config: pytest.Config) -> str:
    # "main" when the run is not distributed.
    workerinput = getattr(config, "workerinput", None)
    return workerinput["workerid"] if workerinput else "main"

def pytest_configure(config: pytest.Config) -> None:
    config.pluginmanager.register(CostRecorder(config), "record_test_costs_recorder")

class CostRecorder:
    def __init__(self, config: pytest.Config) -> None:
        self.config = config
        self.pending_db_setup = 0.0
        self.phases: dict[str, dict[str, float]] = defaultdict(dict)
        self.outcomes: dict[str, str] = {}
        self.db_setup: dict[str, float] = {}

    @pytest.hookimpl(wrapper=True)
    def pytest_fixture_setup(self, fixturedef, request):
        if fixturedef.argname != DB_SETUP_FIXTURE:
            return (yield)
        start = perf_counter()
        try:
            return (yield)
        finally:
            # The session-scoped database is built inside the setup phase of the first test
            # that asks for it; hold the time until that phase's report exists.
            self.pending_db_setup += perf_counter() - start

    @pytest.hookimpl(wrapper=True)
    def pytest_runtest_makereport(self, item, call):
        report = yield
        if call.when == "setup" and self.pending_db_setup:
            report.duration = max(0.0, report.duration - self.pending_db_setup)
            # user_properties travel with the report from an xdist worker to the controller.
            report.user_properties.append(
                (DB_SETUP_PROPERTY, {"worker": worker_name(self.config),
                                     "seconds": self.pending_db_setup}))
            self.pending_db_setup = 0.0
        return report

    def pytest_runtest_logreport(self, report: pytest.TestReport) -> None:
        # Runs in workers too; only the controller's copy is written.
        self.phases[report.nodeid][report.when] = report.duration
        add any DB_SETUP_PROPERTY entry in report.user_properties to self.db_setup[worker]
        outcome: a failed setup or teardown is "error"; a setup skip is "skipped";
        otherwise the call report's outcome

    def pytest_sessionfinish(self, session: pytest.Session) -> None:
        if hasattr(self.config, "workerinput"):
            return
        build a CostsFile (each missing phase 0.0, keys sorted) and write it to
        costs_path(self.config.rootpath): mkdir parents, write a temp file in the same
        directory, then os.replace
```

Type the two wrapper hooks with pytest's own types (`pytest.FixtureDef[object]`,
`pytest.FixtureRequest`, `pytest.Item`, `pytest.CallInfo[None]`, `Generator[...]`); no `Any`.

Behaviour: `uv run python scripts/rank_test_costs.py` runs the ranking run, measures its CPU and

**Builds on:** slice 1
**Touches:** scripts/rank_test_costs.py, scripts/record_test_costs.py, tests/test_rank_test_costs.py, tests/fixtures/rank_test_costs, pyproject.toml

#### `scripts/rank_test_costs.py`

Same shape as `generate_icon_subset.py`: module docstring, `REPO_ROOT`, the `sys.path.insert`,
`main(...) -> int`, `if __name__ == "__main__": sys.exit(main())`. Pure functions are kept apart
from the subprocess so the tests reach the rendering with no pytest run. `CostsFile`,
`costs_path` and the key constants are imported from `scripts.record_test_costs`, so the writer
and the reader cannot drift.

```python
REPO_ROOT = Path(__file__).resolve().parents[1]
COSTS_PATH = costs_path(REPO_ROOT)
RANKING_PATH = REPO_ROOT / "test_organisation" / "test_cost_ranking.md"
PYTEST_COMMAND: list[str] = [
    sys.executable, "-m", "pytest", "-p", "scripts.record_test_costs", "-p", "no:randomly",
    "-n", "4", "--no-cov",
    "-m", "not ci_only and not weasyprint and not playwright",
    "--ignore=freedom_ls/educator_interface/tests/invariants/test_permission_matrix.py",
    "--ignore=tests/test_rank_test_costs.py",
]
TOP_FILES = 50
TOP_FUNCTIONS = 200

class PytestRun(NamedTuple):
    returncode: int
    cpu_seconds: float      # RUSAGE_CHILDREN user + sys, after minus before
    wall_seconds: float     # monotonic

@dataclass(frozen=True)
class RunInfo:
    """Everything the header needs that test_costs.json does not hold."""
    date: str
    commit: str
    cpu_seconds: float
    wall_seconds: float
    conditions: tuple[str, ...]

def function_key(nodeid: str) -> str:
    # Paths and function names hold no "[", so the first one opens the parameter id, which
    # may itself hold "::" or "[".
    return nodeid.split("[", 1)[0]

def area_of(nodeid: str) -> str:
    # freedom_ls/<app> and claude_plugins/<plugin> are areas; tests/ is one area.
    parts = nodeid.split("::")[0].split("/")
    return "/".join(parts[:2]) if parts[0] in {"freedom_ls", "claude_plugins"} else parts[0]

def render_ranking(costs: CostsFile, run: RunInfo,
                   top_files: int = TOP_FILES, top_functions: int = TOP_FUNCTIONS) -> str: ...

def run_pytest(command: list[str]) -> PytestRun:
    # cwd=REPO_ROOT, env PYTHONPATH=REPO_ROOT so -p can import the plugin

def main(command: list[str] | None = None, output: Path | None = None) -> int:
    COSTS_PATH.unlink(missing_ok=True)       # a stale file must never be ranked
    run = run_pytest(command if command is not None else PYTEST_COMMAND)
    if run.returncode != 0:
        print why; return run.returncode
    if not COSTS_PATH.exists():
        print why; return 1
    write render_ranking(...) to output or RANKING_PATH
    print the path and the totals; return 0
```

Rendering rules:

- First line exactly `Generated by uv run python scripts/rank_test_costs.py. Do not edit by hand.`
- Header: date (`datetime.now(UTC).date().isoformat()`, which ruff's DTZ rules accept), commit
  SHA (`git rev-parse HEAD`, with `-dirty` appended when
  `git status --porcelain --untracked-files=no` prints anything), test count, total CPU seconds,
  wall seconds, summed test cost, database-setup seconds (sum over workers, with the worker
  count), run conditions (the pytest arguments after `-m pytest`, Python version,
  `os.cpu_count()`, and `os.getloadavg()` and the `some avg60` figure of `/proc/pressure/cpu`
  both at the start and at the end of the run; a missing pressure file reads as `n/a`). `main`
  gathers these around `run_pytest`; `render_ranking` only formats what `RunInfo.conditions`
  holds.
- Test cost per test = setup + call + teardown (setup already has the database time out).
- Area rollup: area, test count, seconds, share of summed test cost. All areas.
- Top files (`nodeid.split("::")[0]`): file, test count, seconds, share.
- Top functions: function key, case count, total seconds, mean per case, setup share (group's
  setup seconds ÷ group's total), share, cumulative share.
- Seconds to one decimal, shares to whole percent. Rows sorted by rounded seconds descending, then
  key ascending. Cumulative share is summed from unrounded values, then rounded.
- Markdown tables; the file ends with one newline.

`pyproject.toml`: add `"scripts/rank_test_costs.py" = ["T20", "S603"]` beside the
`generate_icon_subset.py` line in `[tool.ruff.lint.per-file-ignores]` (the script prints and runs
a subprocess built from `sys.executable`, so no `S607`). Not a `[tool.test_tiers]` key.

### Slice 4: Prune down the ranking

Behaviour: the costliest test functions are merged, rewritten or removed, each with its reason
recorded, until the CPU target is met or the next candidate is under the 0.5% rule threshold.

**Builds on:** slice 3
**Touches:** freedom_ls, tests, claude_plugins/fls-content, test_organisation/mirroring_baseline.txt, test_organisation/import_baseline.txt, test_organisation/test_cost_ranking.md, spec_dd/2. in progress/faster-test-runs-6-prune-slow-tests/pruned_tests.md

Which tests change is known only once slice 3's ranking exists, so this slice is a procedure.
Walk the top-functions table from the top. For each candidate function:

1. Read the test and its fixtures. Name where its cost sits: setup share high → fixtures/data;
   case count high → parametrization; teardown high → `transaction=True`.
2. Pick the cheapest change that keeps the behaviour asserted:
   - **Fewer cases.** Keep one case per distinct code path and every boundary; drop cases that
     only repeat a path. A dropped case is a removal: name the kept case that asserts the same
     behaviour.
   - **`build()` for `create()`.** Only where the code under test never needs a saved pk, a
     related row or a query. Check against `factory_boy.md`.
   - **Drop `django_db(transaction=True)`.** Only where no test in that scope needs a real commit
     (`transaction.on_commit`, a second connection, threads, `select_for_update` semantics inside
     the test, `live_server`). Run the test without it; a pass in random order and under `-n 4`
     is the evidence.
   - **Shared class- or module-scoped data.** Only in a module (or class) with no
     `transaction=True` test, whose flush would wipe the shared rows; otherwise reset the mutable
     part per test, idempotently. Follow `demo_site`: create under
     `django_db_blocker.unblock()`, flush when the scope ends, and hand tests only rows they never
     mutate. `--dist loadfile` keeps a module on one worker.
   - **Merge.** Parametrize when the assertion shape is the same. Use labelled assertions
     (`assert x, "learner sees the locked badge"`) only when they are facets of one behaviour the
     test name states without "and"; otherwise share cheaper setup instead of merging. No
     `if`/`for`/`try` in the body.
   - **Remove.** Only when another test asserts the same behaviour, not merely runs the same
     lines. Name that test.
   - **Leave it.** When none of the above saves anything without weakening a check, record a
     one-line reason under "candidates left unchanged".

   A rewrite imports no factory, fixture or helper from an app its test module's app has no edge
   to in `docs/app_structure.md`. If one is needed, stop and raise it before committing.
3. TDD still holds for any rewrite: the rewritten test must fail when the behaviour breaks. Break
   the code under test briefly to see it fail, then restore it.
4. Run the file's tests with random order on (the default) and under `-n 4`, `--no-cov`.
5. If a whole test file is removed or renamed: run `check_test_mirroring.py` and `lint-imports`
   (the pre-commit hooks do), and edit only that file's lines in
   `test_organisation/mirroring_baseline.txt` and `test_organisation/import_baseline.txt`.
6. Add the row to `pruned_tests.md`: node ID, action, seconds before, seconds after, the test
   that still asserts the behaviour and any difference, the reason. Both figures come from the
   same targeted command on the test's file (`-p scripts.record_test_costs -n 0 -p no:randomly
   --no-cov`), run once before the edit and once straight after it, so both are taken under the
   same load. The ranking's figure, from a `-n 4` run at another time, picks the candidate; it is
   not the "before".
7. Commit per candidate (or per small group in one file), with the `pruned_tests.md` row.

No ranking run happens in this slice. Keep a running total in `pruned_tests.md` of the seconds
saved (before minus after, summed over the rows) and turn it into estimated CPU seconds with the
ratio recorded in `timings.md`. Stop when the first run's total CPU seconds minus that estimate
is at or under the target, or when the next function's test cost in the first ranking is under
the 0.5% rule threshold, whichever comes first. Slice 5's ranking run is the measurement.

Do not change `freedom_ls/conftest.py` or the root `conftest.py`: concrete projects star-import
the first, and both are shared by every test.

### Slice 5: The last ranking run and the coverage comparison close the records

against the target, and `pruned_tests.md` shows no `freedom_ls/` file losing coverage.

**Touches:** test_organisation/test_cost_ranking.md, spec_dd/2. in progress/faster-test-runs-6-prune-slow-tests/timings.md, spec_dd/2. in progress/faster-test-runs-6-prune-slow-tests/pruned_tests.md
