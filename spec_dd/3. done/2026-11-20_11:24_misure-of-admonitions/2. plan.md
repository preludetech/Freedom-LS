{% comment %}
A static, toned status box in an app page, panel or dialog: a tone icon, an
optional bold first line and the slot. It has no outer margin, so the parent
spaces its children, and no text size, so it reads at its context's size.

Attributes:

{% endcomment %}

{% partialdef callout-box %}
<div class="callout callout-{{ known_tone }}{% if class %} {{ class }}{% endif %}"{% if known_tone == "error" %} role="alert"{% elif known_tone == "success" %} role="status"{% endif %} {{ attrs }}>

            {% if title %}<strong class="block font-semibold">{{ title }}</strong>{% endif %}
            {{ slot }}
        </div>
    </div>
</div>
{% endpartialdef %}

{% if tone == "success" or tone == "warning" or tone == "error" %}
    {% with known_tone=tone %}{% partial callout-box %}{% endwith %}
{% else %}
    {% with known_tone="info" %}{% partial callout-box %}{% endwith %}
{% endif %}
```

COMMENT_BLOCK = re.compile(r"{%\s*comment\s*%}.*?{%\s*endcomment\s*%}", re.DOTALL)

def app_templates() -> list[Path]:
    """Every app template, leaving out the content engine's own, where the widgets live and nest."""


def without_comments(text: str) -> str: ...


def violations_in(text: str) -> list[str]:
    """Each banned tag the text uses outside a comment, matched as <c-NAME(?![\\w-]),
    plus "level=" when a callout outside a comment carries it."""
```

Tests (no loops or branches in a test body; parametrise):
