## How the tests drive the scripts

Both scripts live in `claude_plugins/django-stack/scripts/`, whose hyphenated path is not
importable, and `mypy` skips `claude_plugins/`. So the tests run the scripts as CLIs, the way
`tests/test_rebase_lost_change_check.py` runs its shell script:

```python
subprocess.run(  # noqa: S603
    [sys.executable, str(SCRIPT), *args], cwd=project, capture_output=True, text=True, check=False
)
```

`project` is a `tmp_path` tree with its own `pyproject.toml` and a namespace package holding the
apps, like FLS: `pkg/` has no `__init__.py`, and `pkg/users`, `pkg/alpha` and `pkg/beta` each have
an `apps.py`. Tests that run `lint-imports` use `[Path(sys.executable).parent / "lint-imports",
"--config", ..., "--no-cache"]` with `cwd=project`. `--no-cache` stops tests leaving an
`.import_linter_cache/` behind.

Both test files build these trees, so put a small helper module in `tests/_script_trees.py` (a
plain module, not `conftest.py`, per `ds:testing`'s "`conftest.py` vs. plain module"):

```python
def write_tree(root: Path, files: dict[str, str]) -> None: ...   # relative path -> contents
def run_command(command: list[str], project: Path) -> subprocess.CompletedProcess[str]:
    return subprocess.run(command, cwd=project, capture_output=True, text=True, check=False)  # noqa: S603
def run_script(script: Path, project: Path, *args: str) -> subprocess.CompletedProcess[str]:
    return run_command([sys.executable, str(script), *args], project)
```

The `lint-imports` tests call `run_command` directly. Keeping the one `subprocess.run` in
`run_command` means only one `# noqa: S603`, which ruff's `S` rules need.

Test files: `tests/test_generate_app_map.py` and `tests/test_check_test_mirroring.py`. Each slice
adds its tests to the right file.

    # `from X import Y` records X.Y when X.Y is in known_modules (every app module's
    # module_name), the way grimp resolves it, so `from pkg.users import factories` still
    # gets its allowance line.

def source_modules(app: App) -> list[str]:

    # any other test module (factories.py, conftest.py, a root-level test_*.py) contributes
    # its own module_name. Sorted, unique.

def forbidden_modules(app: App, apps: list[App], edges: Edges) -> list[str]:

    return sorted(a.module_path for a in apps if a != app and a.short_name not in deps)

def allowance_lines(app: App, user_app: App, edges: Edges) -> list[str]:
    # [] when app is user_app or app depends on user_app at runtime; otherwise
    # f"{importer} -> {imported}" for each test_imports pair whose imported is
    # f"{user_app.module_path}.factories" or a submodule of it

def render_contracts(
    apps: list[App],
    edges: Edges,
    config: TestOrganisationConfig,
    baseline_by_app: dict[str, list[str]],
) -> str:
    # banner, then [tool.importlinter] root_packages = every app's module_path, then one
    # [[tool.importlinter.contracts]] per app that has source_modules and forbidden_modules, with
    # id = short_name, name = f"{short_name} tests import only {short_name}' runtime deps",

## Slice 7: the Mirroring check

**Behaviour.** `check_test_mirroring.py` fails on any collected app test file that doesn't mirror
a module and isn't in the mirroring baseline, and on stale baseline lines.
`--print-violations` lists the current violations. The live tree passes against a seeded
baseline, and pre-commit and CI run it.

**Changes.**

- New `claude_plugins/django-stack/scripts/check_test_mirroring.py`: stdlib-only, typed, with a
  module docstring and `# ruff: noqa: T201` like its sibling. Pseudocode:

  ```python
  COLLECTED = ("test_*.py", "*_tests.py", "tests.py")   # pytest's python_files

  @dataclass(frozen=True)
  class Violation:
      path: str        # repo-relative posix path
      expected: str    # repo-relative module path it should mirror, or where the test should live

  def find_violations(apps: list[App], project_root: Path) -> list[Violation]:
      for app in apps:
          for path in app python files (skip SKIP_DIRS), name matching COLLECTED:
              within = path.relative_to(app.directory)
              if within.parts[:2] == ("tests", "playwright"): continue
              if within.parts[0] == "tests" and path.name.startswith("test_"):
                  sub, name = within.parts[1:-1], path.stem.removeprefix("test_")
                  module = app.directory.joinpath(*sub, f"{name}.py")
                  if module.exists() or app.directory.joinpath(*sub, name, "__init__.py").exists():
                      continue
                  expected = module
              else:
                  expected = mirrored_test_path(app, within)
              yield Violation(...)

  def mirrored_test_path(app: App, within: Path) -> Path:
      # where a misnamed or misplaced test file should live, under <app>/tests/:
      sub = within.parts[1:-1] if within.parts[0] == "tests" else within.parts[:-1]
      if within.name == "tests.py":
          return app.directory.joinpath("tests", *sub, "test_<module>.py")   # literal placeholder
      stem = within.stem.removesuffix("_tests").removeprefix("test_")
      return app.directory.joinpath("tests", *sub, f"test_{stem}.py")
      # tests/foo_tests.py   -> tests/test_foo.py
      # sub/foo_tests.py     -> tests/sub/test_foo.py
      # sub/test_x.py        -> tests/sub/test_x.py
      # tests.py             -> tests/test_<module>.py  (split it, one file per module)
  ```

  The baseline is read with `iter_entries` from `generate_app_map.py`. Each remaining line is a
  path.

  `main()`: `load_config(Path.cwd())`. With no table, print that nothing is configured and exit 0.
  Otherwise `find_apps(Path.cwd())`, find violations, read the mirroring baseline, and collect
  failures:
  - a violation not in the baseline: names the file and its expected path;
  - a baseline line not among the current violations (the file is gone, now conforms, or sits
    under `tests/playwright/`): a stale line.

  Every failure message names the file and the expected module path, and lists the three ways
  out: rename or move the file, add a reasoned mirroring exemption, or delete the stale line.
  It also points at "Mirroring" in `claude_plugins/django-stack/resources/testing.md`. Exit 1
  on any failure, 0 when clean.

  `--print-violations` prints the violations (minus exemptions, once Slice 8 adds them) in
  baseline format: a `# <app>` header per app, apps and lines sorted. It writes nothing and exits
  0. The import baseline was grouped by hand in Slice 6, so this is the only code that writes the
  format. Keep it in this script.
- New `test_organisation/mirroring_baseline.txt`: the import baseline's header wording, then the

- `.github/workflows/tests.yml`: add the same command as the lint job's last step.
