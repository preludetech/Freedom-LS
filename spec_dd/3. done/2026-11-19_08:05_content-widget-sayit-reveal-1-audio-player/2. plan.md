**Redirect view.**

- New `freedom_ls/content_engine/views.py`:

  ```python
  from uuid import UUID

  from django.http import HttpRequest, HttpResponseRedirect
  from django.shortcuts import get_object_or_404
  from django.views.decorators.cache import never_cache
  from django.views.decorators.http import require_safe

  from freedom_ls.content_engine.models import File


  @require_safe
  @never_cache
  def audio_file(request: HttpRequest, pk: UUID) -> HttpResponseRedirect:
      """Redirect to a freshly signed URL for an audio file.

      The page holds this URL rather than a signed one, so a page left open past
      the signature's lifetime still plays. It needs no login and never expires:
      the UUID lookup is site-scoped and limited to audio files, and checks no
      course access or publication state, so anyone holding the UUID can play
      the file for as long as the row exists.
      """
      file_obj = get_object_or_404(File, pk=pk, file_type=File.FileType.AUDIO)
      return HttpResponseRedirect(file_obj.file.url)
  ```

  `require_safe` gives GET and HEAD only (405 otherwise). `File.objects` is site-aware, so the
  lookup is never filtered on `site` by hand.
- New `freedom_ls/content_engine/urls.py` with `app_name = "content_engine"` and

**Alpine component, play and stop.**

- In `freedom_ls/content_engine/static/content_engine/js/alpine-components.js`, add `audioFile`
  to the header comment list
  (`` `audioFile` — one shared audio element for speak buttons (cotton/audio.html) ``) and
  register it inside the existing `alpine:init` block. This slice's version:

  ```js
  // One element for the whole page: it plays one audio file at a time by
  // construction, and iOS unlocks it once from the first press. Web Audio is
  // not used because the iPhone silent switch mutes it.
  let sharedAudio = null;
  let owner = null;
  // Alpine hands each method a fresh scope proxy, so `this` is not a stable
  // identity; widgets are compared by this id instead.
  let nextAudioFileId = 0;

  function audioElement() {
      if (sharedAudio) return sharedAudio;
      sharedAudio = new Audio();
      sharedAudio.addEventListener("playing", () => owner?._setState("playing"));
      sharedAudio.addEventListener("ended",   () => owner?._setState("idle"));
      return sharedAudio;
  }

  Alpine.data("audioFile", () => ({
      _id: nextAudioFileId++,
      idle: true, loading: false, playing: false,

      toggle() {
          const audio = audioElement();
          if (owner?._id === this._id && !this.idle) {
              audio.pause();
              audio.currentTime = 0;
              this._setState("idle");
              return;
          }
          owner = this;
          this._setState("loading");
          // src only, never <source type>: the stored mime type can be empty.
          audio.src = this.$el.dataset.src;
          // Called synchronously inside the click so iOS treats it as user-initiated.
          audio.play();
      },
      _setState(state) {
          this.idle = state === "idle";
          this.loading = state === "loading";
          this.playing = state === "playing";
      },
  }));
  ```

  `this.$el` in `toggle` is the button (the element with `x-on:click`), which carries `data-src`.
  Every transition goes through `_setState`, so exactly one of `idle`, `loading` and `playing` is
  true. Nothing plays on page load and nothing about the learner is stored.

> **Assumed default:** the shared element and its owner live at module scope, as the spec requires,
> although `ds:alpine-js` prefers self-contained components. Why: the shared value is one browser
> audio element that iOS unlocks once, not UI state. To change: move `owner` into an
> `Alpine.store`, in this slice's Alpine component.

### Slice 4: a failed load shows an error line, and the next press tries again

- `audioFile` changes:

  ```js
  failed: false,

  sharedAudio.addEventListener("error", () => owner?._fail());

  toggle() {
      …stop branch as before…
      if (owner) {
          owner.failed = false;
          owner._setState("idle");
      }
      this.failed = false;
      owner = this;
      …
      audio.play().catch((error) => {
          // AbortError means another press replaced this load; not a failure.
          if (error.name !== "AbortError" && owner?._id === this._id) this._fail();
      });
  },
  _fail() {
      this.failed = true;
      this._setState("idle");
  },
  ```

  The button stays enabled after a failure. Pressing another widget clears the previous owner's
  error line, so only the widget being played can show one.
