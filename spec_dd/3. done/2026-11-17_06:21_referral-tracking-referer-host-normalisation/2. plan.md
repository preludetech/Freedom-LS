## Slices

### Slice 1: `normalised_host` reduces a bare host to a comparable form

**Behaviour:** `normalised_host(host: str) -> str` strips whitespace, lowercases, drops the port
(with bracketed and bare IPv6 handled), strips trailing dots and strips one leading `www.`.

**Builds on:** none

**Touches:** `freedom_ls/referral_tracking/referers.py`,
`freedom_ls/referral_tracking/tests/test_referers.py`

TDD, red first:

1. Create `freedom_ls/referral_tracking/tests/test_referers.py` with a parametrised test over the
   spec's `normalised_host` table (all 13 rows, including `www.` → `www`, `[::1]:8080` → `::1`,
   `::1` → `::1`, `[::1` → `[::1` and `""` → `""`).
2. Create `freedom_ls/referral_tracking/referers.py` with a module docstring saying what the
   helpers are for (reducing a host or `Referer` value to one comparable form, read-side only;
   the stored referer stays raw) and implement:

```python
from urllib.parse import urlsplit

_WWW_PREFIX = "www."


def normalised_host(host: str) -> str:
    """Reduce a bare host (a `request.get_host()` value, a `Site.domain` or a
    `urlsplit(...).hostname`) to one comparable form, so that `www.google.com`,
    `google.com.` and `google.com:443` all compare equal."""
    value = host.strip().lower()
    value = _without_port(value)
    # Trailing dots go first, so a lone `www.` has become `www` and is kept.
    value = value.rstrip(".")
    return value.removeprefix(_WWW_PREFIX)


def _without_port(value: str) -> str:
    if value.startswith("["):
        # A bracketed IPv6 literal keeps its address; without a closing
        # bracket there is no address to extract, so the value is kept.
        close = value.find("]")
        return value[1:close] if close != -1 else value
    if value.count(":") == 1:
        return value.partition(":")[0]
    # Two or more colons with no brackets is a bare IPv6 literal, kept whole.
    return value
```

The order matters: trailing dots are stripped before the `www.` prefix, so `www.` becomes `www`
and is left alone. Any value that still starts with `www.` at that point has something after it,
so a plain `removeprefix` meets "strips one leading `www.` if anything is left after it".

3. Add a parametrised test asserting `normalised_host` returns a `str` and does not raise on
   hostile input: `"\x00\x01\x7f"`, `"]]:[["`, `"[]:80"`, `"[]"`, `".:."`, `"www.."`. Keep it to
   `assert isinstance(result, str)`; the exact outputs for these are not part of the contract.

### Slice 2: `referer_host` reads the comparable host out of a raw `Referer`

**Behaviour:** `referer_host(referer: str) -> str` returns `normalised_host(hostname)` for an
`http`/`https` referer, the lowercased package name for an `android-app` referer, and `""` for
everything else, including any value `urlsplit` rejects. Neither helper raises on any `str`.

**Builds on:** slice 1

**Touches:** `freedom_ls/referral_tracking/referers.py`,
`freedom_ls/referral_tracking/tests/test_referers.py`

TDD, red first:

1. Add a parametrised test over the spec's `referer_host` table (all 16 rows, including
   `http://a.com:abc/` → `a.com`, `http://[::1]:8080/` → `::1`, `http://[::1` → `""` and the
   `android-app` rows).
2. Add a parametrised test asserting `referer_host` returns a `str` and does not raise on hostile
   input: `"\x00\x01\x7f"`, `"http://\x00a.com"`, `"http://a]b["`, `"http://["`, `"]]:[["`,
   `"[]:80"`, `"http://a.com:\n80"`, `"android-app://["`. Keep it to
   `assert isinstance(result, str)`.
3. Implement in `referers.py`:

```python
_WEB_SCHEMES = frozenset({"http", "https"})
_ANDROID_APP_SCHEME = "android-app"


def referer_host(referer: str) -> str:
    """Return the comparable host of a raw `Referer` value, or "" when it has none.

    A referer cut short at the stored length cap still yields its host,
    because the host comes first."""
    try:
        parts = urlsplit(referer.strip())
        hostname = parts.hostname
    except ValueError:
        return ""
    # `.port` is never read: it raises on a non-numeric port, and `.hostname`
    # has already dropped the port, the userinfo and the IPv6 brackets.
    if not hostname:
        return ""
    if parts.scheme in _WEB_SCHEMES:
        return normalised_host(hostname)
    if parts.scheme == _ANDROID_APP_SCHEME:
        # The host of an android-app referer is the app's package name,
        # returned bare: no `www.` or port handling applies to it.
        return hostname.lower()
    return ""
```

`urlsplit` already lowercases the scheme and `.hostname` already lowercases the host; the explicit
`.lower()` on the package name states the contract rather than relying on that.
