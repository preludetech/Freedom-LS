# Frontend QA: course prices

A course can now carry a price. The price shows on the course card, the course row, the course
page's stats strip and its sign-up panel, and in the course page's JSON-LD. The admin can edit it.

This run checks the four kinds of price in each place. It also hunts for two things beyond the
golden path:

- **Nothing about access may change.** A priced course keeps its "By application" badge, its
  acquisition copy and its Apply CTA. A course with no price looks exactly as it did before.
- **A stale sale must never show.** A discount whose end date has passed shows as a fixed price, on
  the page and in JSON-LD, with nobody editing the course.

Substitute the literal port number chosen by `.claude/ds/scripts/find_available_port.sh` wherever
this document writes `<PORT>`. Shell variables do not survive between tool calls.

Amounts are formatted for the project's locale. The dev settings leave `PRICE_LOCALE` unset and use
`LANGUAGE_CODE = "en-us"`, so a ZAR amount reads `ZAR 1,499.00`, not `R1 499,00`. Where this
document writes an amount, check the digits and the currency, not the exact separators.

## §0 Setup

### 0.1 Server

1. Run `.claude/ds/scripts/find_available_port.sh`. Note the number and use it literally from here
   on.
2. Start `uv run python manage.py runserver <PORT>` backgrounded, as its own call.
3. Open `http://127.0.0.1:<PORT>/` and confirm `#debug-branch-badge` names the `course-prices`
   branch. If it names another branch, another server holds the port. Go back to step 1.

### 0.2 Seed data

Missing data is created through the `fls-dev:qa-data-helper` agent, never by hand.

1. **Migrations applied.** `uv run python manage.py migrate`.
2. **Demo content loaded.** `uv run python manage.py content_save demo_content DemoDev`. Confirm
   it exits without a validation error. This gives "Functionality Demo - Application gated course"
   a discounted price: original 1499.00, sale 999.00, ZAR, tax note "incl. VAT", no end date.
3. **Superuser.** `demodev@email.com`, password in `.claude/fls-dev/config.md`.
4. **Learner A.** A learner account, no staff flag, verified email, password equal to the email,
   registered for no course.
5. **Learner B.** The same, but registered for "Functionality Demo - Application gated course"
   (an active `LearnerCourseRegistration`).
6. **Three more priced courses**, published, each with at least one topic, none of them registered
   to Learner A:
   - "QA Fixed price": kind `fixed`, amount 250.00, currency USD, tax note "excl. tax".
   - "QA Range price": kind `range`, low 1200.00, high 3000.00, currency ZAR.
   - "QA On request": kind `on_request`.
7. **One expired sale.** "QA Expired sale": kind `discounted`, amount 800.00, sale 500.00,
   `price_sale_ends_on` set to yesterday, currency ZAR.
8. **One coming-soon priced course.** "QA Coming soon priced": visibility `coming_soon`, kind
   `fixed`, amount 100.00, currency ZAR.
9. Note one existing course with no price, for example "Functionality Demo - Standard markdown".

Log in at `http://127.0.0.1:<PORT>/accounts/login/`.

## §2 Course page, anonymous

### 2.1 Discounted, application-gated

Open the detail page of "Functionality Demo - Application gated course"
(`/courses/<slug>/detail/`, reachable from the row's title link).

1. The stats strip has a "Price" cell directly before the "Enrolment" cell. It shows the
   struck-through 1,499.00 and 999.00, with no tax note. The text is readable against the hero
   gradient (white, like the other cells).
2. The sign-up panel shows the same price above the acquisition heading, this time followed by
   "incl. VAT".
3. The acquisition heading, subtext and the Apply CTA read exactly as they do on `main`. Click the
   CTA. It goes where it went before (login or the application form). The price changes nothing
   about the flow.
4. View the page source. There is a `<script id="course-jsonld" type="application/ld+json">`.
   Parse its contents. `offers` is
   `{"@type": "Offer", "price": "999.00", "priceCurrency": "ZAR"}` with no `priceValidUntil`.
   `isAccessibleForFree` is still present and unchanged.

### 2.2 The other kinds

Open each course's detail page and check the stats cell, the sign-up panel and the JSON-LD.

| # | Course | Stats cell | Sign-up panel | JSON-LD `offers` |
| --- | --- | --- | --- | --- |
| 2.2.1 | QA Fixed price | 250.00 USD | 250.00 USD and "excl. tax" | `Offer`, `"price": "250.00"`, `"priceCurrency": "USD"` |
| 2.2.2 | QA Range price | `From` 1,200.00 | 1,200.00 – 3,000.00 (the full range) | `AggregateOffer`, `"lowPrice": "1200.00"`, `"highPrice": "3000.00"`, no `offerCount` |
| 2.2.3 | QA On request | `Price on request` | `Price on request` | no `offers` key at all |
| 2.2.4 | QA Expired sale | 800.00 only | 800.00 only | `Offer`, `"price": "800.00"`, no `priceValidUntil` |
| 2.2.5 | The course with no price | no "Price" cell | no price | no `offers` key |

Prices in JSON-LD are strings with the currency's decimal places, never bare numbers and never
`"250.000"`.

### 2.3 Catalogue JSON-LD

View the source of `/courses/`. The `catalogue-jsonld` script tag has
`type="application/ld+json"` and its contents parse as JSON.

## §5 Admin

Log in as the superuser and open the admin's Course change page for "QA Fixed price".

1. There is a "Price" fieldset with eight fields: kind, amount, sale amount, sale ends on, low
   amount, high amount, currency, tax note. All are editable.
2. **Switch kind.** Change the kind to `range`, clear the amount, set low 100.00 and high 200.00,
   save. The save succeeds and the course row on `/courses/` now reads `From` 100.00.
3. **Stray field.** Set kind `fixed` and amount 250.00 but leave low and high filled in. Save. The
   form re-renders with an error against the low and high amount fields, not a server error page
   and not a generic "constraint violated" message at the top. Clear them and save.
4. **Missing field.** Kind `discounted`, amount 250.00, sale amount blank. The error is on the sale
   amount field.
5. **Ordering.** Kind `discounted`, amount 250.00, sale amount 250.00. Rejected on the sale amount.
   Try 300.00. Rejected. Try 200.00. Saved.
6. **Range ordering.** Kind `range`, low 300.00, high 100.00. Rejected.
7. **Zero and negative.** Amount 0, then -5. Both rejected.
8. **Unknown currency.** Currency `ZZZ`. Rejected on the currency field.
9. **Decimal places.** Currency `JPY`, amount 1500.50. Rejected on the amount. Amount 1500 saves,
   and the course page shows it with no decimals. Currency `KWD`, amount 1.234 saves.
10. **On request with extras.** Kind `on_request` with a currency or a tax note filled in.
    Rejected. With every other price field empty, it saves.
11. **Amounts with no kind.** Kind blank, amount 250.00. Rejected on the kind field. With every
    price field empty it saves, and the course shows no price anywhere.
12. **Blank currency.** Kind `fixed`, amount 250.00, currency blank. The dev settings have no
    `DEFAULT_CURRENCY`, so expect an error on the currency field that mentions the setting.
13. **Tax note markup.** Set the tax note to `<b>incl</b> <script>alert(1)</script>`. Save, open
    the course page. The note shows as literal text. Nothing is bold and no script runs. Restore
    it afterwards.
14. **Title breakout.** Rename a priced course to `QA </script><script>alert(1)</script>`. Open its
    detail page. No alert fires, the page renders whole, and the JSON-LD block still parses with
    the title intact. Restore the title.

## §6 Content loader

Work on a copy of a demo course outside `demo_content/`, in the scratchpad directory, so the
repo's content is untouched. Load it with `uv run python manage.py content_save <copy-dir> DemoDev`.

1. **Admin price survives a re-save.** Give the copied course a price in the admin. Re-run the load
   with no `price:` key in its `course.md`. The price is still there.
2. **`price: null` clears it.** Add `price: null`, re-run. The price is gone from the row, the
   course page and the admin fieldset (all eight fields empty).
3. **Switching kind.** Load with a `range` price, then change the file to a `fixed` price and
   re-run. In the admin, low and high are empty.
4. **Bare number.** Write `amount: 1499.00` without quotes. The load fails, the message says to
   write amounts as quoted strings, and the stored price is unchanged.
5. **Unknown kind.** `kind: subscription`. The load fails and names the kind.
6. **No currency, no default.** A `fixed` price with no `currency:`. The load fails and names the
   file.

Delete the copied course from the dev database through `fls-dev:qa-data-helper` when done.
