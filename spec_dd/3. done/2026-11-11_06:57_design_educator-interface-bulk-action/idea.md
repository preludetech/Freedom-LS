The bulk action functionality in the educator interface looks bad. Follow the design:

- bulk action menu appears above the table when you start selecting items
- show a count of items
- allow select all
- allow de-select all
- clear button on right removes selection
- Bulk action buttons are just text, no outline
- More button is dropdown
- use a modal for confirmation or user-facing forms related to actions
