# Plan: retire content that is removed from the source

Spec: `1. spec.md` in this directory. Code research with line numbers: `research_codebase.md`.

## How to work

- TDD throughout: write the failing test, see it fail, make it pass. Each slice is committed with
  its own tests passing.
- Words: **retired**, **un-retire**, **retirable models**, and **live** for "not retired". Never
  "inactive", "deactivated", "removed" or "archived" for this state, in identifiers, copy or
  comments. A `ContentCollectionItem` row is a "collection item"; the object it places is its
  "child".
- The filter is always explicit. `objects`, `_base_manager` and every reverse related manager
  return retired rows. No slice changes `SiteAwareManager.get_queryset`.
- "Is this row retired" is asked through `is_retired` in Python and `not_retired()` in querysets,
  never by spelling out `retired_at is None` at a call site.
- Until slice 14 the `content_save` command does not retire anything. Slices 1 to 13 are built
  and tested through `save_content_to_db(..., retire_missing=True)`.
- Type hints on every new function, no `Any`, no `# type: ignore`, no new abstract base class, no
  logging, no edits to existing migrations.

   ```python
       def not_retired(self) -> Self:
           """Rows a learner can be served: every row no content save has retired."""
           return self.filter(retired_at__isnull=True)

       _queryset_class = RetirableQuerySet

       def not_retired(self) -> RetirableQuerySet: ...
   ```

2. **Retirable models, in one place.** In `content_save.py`:

   ```python
   # Every model a save can retire, in the order the count line names them.
   RETIRABLE_MODELS: tuple[type[Model], ...] = (
       Course, CoursePart, Topic, Activity, Article, Form, FormPage, FormContent,
       FormQuestion, QuestionOption, CourseCategory, File,
   )
   ```

3. **Mark.** One run-wide ledger, passed to every `_write_source` call instead of widening its
   return tuple:

   ```python
   def _row_key(row: Model) -> Hashable:
       """What identifies a row to a save: a File's path, any other row's pk."""
       return row.file_path if isinstance(row, File) else row.pk


   @dataclass
   class _RunLedger:
       """What one save found in the source and what it did about retirement."""
       seen: dict[type[Model], set[Hashable]] = field(default_factory=lambda: defaultdict(set))

       def saw(self, row: Model) -> None:
           self.seen[type(row)].add(_row_key(row))
   ```

   `_write_sources` creates one `_RunLedger`, so the sets are merged across paths by
   construction. `_write_source` calls `ledger.saw(...)` for every saved instance. The table in
   `research_codebase.md` section 1.2 lists each variable; the ones discarded today are the
   `save_course_categories` result, the `save_form_content` return, and the `saved_options` of
   `save_form_question`. `save_file_to_db` returns only a decision, so in the files loop add the
   path directly: `ledger.seen[File].add(_relative_to_source(source.path, file_path))`, for every
   non-content file whether or not a decision came back.

4. **Un-retire.** In `save_with_uuid`, after `fields.update(extra_fields)`:

   ```python
   # A row found in the source is live. Written with the content so the update and
   # the un-retire are one statement.
   fields["retired_at"] = None
   ```

   `model_dump(exclude_none=True)` never carries it, so it must be set here. In
   `save_file_to_db`, set `file_obj.retired_at = None` in the existing-row branch before the
   `file_obj.file.save(..., save=True)` that already persists the row.

5. **Sweep.** Called in `_write_sources` after the `for source in sources` loop and before the
   `ContentSave` row, only when `retire_missing` is true. One path for every model: read the pks,
   update by pk, keep the pks.

   ```python
   def _retire_missing(site: Site, ledger: _RunLedger, run_time: datetime) -> None:
       for model in RETIRABLE_MODELS:
           live = model._base_manager.filter(site=site, retired_at__isnull=True)
           key = "file_path__in" if model is File else "pk__in"
           pks = list(live.exclude(**{key: ledger.seen[model]}).values_list("pk", flat=True))
           # update() skips auto_now, and readers find changed rows by updated_at.
           model._base_manager.filter(pk__in=pks).update(retired_at=run_time, updated_at=run_time)
           ledger.retired[model] = set(pks)
   ```

   `ledger.retired: dict[type[Model], set[UUID]]` is a new field. `run_time = timezone.now()`,
   read once at the top of `_write_sources`. Everything runs inside the existing
   `@transaction.atomic`, so a later failure rolls it back.

6. **Opt-in.** `save_content_to_db` and `_write_sources` gain keyword-only
   `retire_missing: bool = False`. No caller passes it yet: not `command()`, not
   `demo_content_fixtures.py`.

7. **Learner outline** (`content_engine/models/courses.py`). One helper holds the rule, and the
   flat accessors take the keyword every later slice needs:

   ```python
   def live_collection_items(collection: Course | CoursePart) -> list[ContentCollectionItem]:
       """The collection's own collection items whose child is not retired."""
       return [
           item for item in collection.collection_items()
           if item.child is None or not item.child.is_retired
       ]
   ```

   ```python
   def collection_items_flat(self, include_retired: bool = False) -> list[ContentCollectionItem]:
       own = self.collection_items() if include_retired else live_collection_items(self)
       for item in own:
           flattened.append(item)
           if isinstance(item.child, CoursePart):
               # A retired part's children are never stamped themselves; they drop out
               # here, because the part was skipped above.
               flattened.extend(
                   item.child.collection_items() if include_retired
                   else live_collection_items(item.child)
               )
   ```

   `viewable_collection_items(include_retired: bool = False)` and
   `viewable_items(include_retired: bool = False)` pass the keyword down. `children_flat`,
   `lesson_count` and `includes_assessments` keep their signatures and read the filtered default.
   `collection_items()` and `children()` on both models stay unfiltered. A collection item whose
   `child` is `None` is kept, as it is today.

### Slice 2: a run that would retire a course is refused

   first `_write_source`, only when `retire_missing and not allow_course_retire`:

   ```python
   def _refuse_course_retire(site: Site, sources: Sequence[_ParsedSource]) -> None:
       source_uuids = {item.uuid for every parsed CourseSchema item in every source if item.uuid}
       missing = (
           Course._base_manager.filter(site=site, retired_at__isnull=True)
           .exclude(pk__in=source_uuids)
           .order_by("title")
       )
       if missing: raise CommandError(_refusal(...))
   ```

   uuids, the backstop looks at what the sweep did, so it catches a course whose file parsed but
   was never written.

### Slice 3: the run reports what it retired and un-retired
