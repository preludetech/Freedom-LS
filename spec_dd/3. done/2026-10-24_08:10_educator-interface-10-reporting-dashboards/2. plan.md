## Cross-app edges this plan adds

`educator_interface → reports` and `educator_interface → base` (runtime imports). Both are
acyclic: `reports` imports neither `educator_interface` nor `panel_framework`. The pre-commit hook
`app-map-fresh` fails on an undeclared runtime edge, so the slice that first imports `reports`
from `educator_interface` (slice 1) also runs
`uv run python claude_plugins/django-stack/scripts/generate_app_map.py`, which rewrites
`test_organisation/import_contracts.toml` and `docs/app_structure.md` from the code.

Tests mirror modules (`check_test_mirroring.py`): every new module gets a test file of the same
name under the app's `tests/`.

> **Assumed default:** the product documentation, roadmap row and upgrade notes the spec lists
> under "Documentation and downstream" are not plan steps. Why: this plan is implementation only;
> the documentation hooks run after it. To change: add a step to the last slice.

## Shared conventions for every slice

- `freedom_ls/educator_interface/reporting.py` (new) holds every new panel, query and the
  lazy-body helper. `views.py` imports from it. `reporting.py` imports
  `OrganisationScopedRequest` from `views.py` under `TYPE_CHECKING` only, the way
  `quick_views.py` does, so there is no runtime cycle.
- `reports` returns no tones or markup. `reporting.py` owns the tone maps (built in slice 3):

  ```python
  PROGRESS_STATUS_TONES = {
      ProgressStatus.NOT_STARTED: "muted",
      ProgressStatus.IN_PROGRESS: "info",
      ProgressStatus.COMPLETE: "success",
  }

  def progress_status_badge(completion_percentage: int) -> StatusBadge:
      status = progress_status(completion_percentage)
      return StatusBadge(tone=PROGRESS_STATUS_TONES[status], label=status.label)

  def flag_badge(flag: AtRiskFlag) -> StatusBadge:
      # A rule's severity is already a role token name, so it is the tone.
      return StatusBadge(tone=flag.severity, label=flag.label)
  ```

  `educator_tags.py` gains `{% progress_status_badge completion as badge %}` and
  `{% flag_badge flag as badge %}` wrappers, next to `learner_status_badge`.

  `c-panel-status-badge` per flag with the flag's `reason` as visible text beside it. Every

- Dates on screen use `|date:"j M Y"`, as `learner_courses.html` does today; times

## Slice 1: cohort members CSV

**Behaviour.** A URL a signed-in educator can fetch: the cohort's active learners and the
educators assigned to it, as one CSV. Slice 2 links it from the cohort page. This is the thinnest
end-to-end route and introduces the `educator_interface → reports` and `→ base` edges.

**`reports/indexes.py`.** Rename `_learner_sort_key` to the public `learner_sort_key(user: User)
-> tuple[str, str]` and update `load_roster` and `test_indexes.py` to the new name. Add the one
definition of a cohort's active members, which `load_roster` (slice 3), the screen cache (slice 3)
and the CSV all read:

```python
def load_active_memberships(cohort: Cohort, site_id: int) -> QuerySet[CohortMembership]:
    """Memberships whose learner is still active in the organisation, with the user loaded.

    Removed learners keep their membership rows, so every reader that counts
    or lists a cohort's people filters them out here, not by hand.
    """
    return CohortMembership.objects.filter(
        cohort=cohort, site_id=site_id, learner__is_active=True
    ).select_related("learner__user")
```

**`educator_interface/reporting.py`** (new module):

```python
def cohort_members_csv_response(cohort: Cohort) -> HttpResponse:
    """The cohort's active learners, then its educators, as one formula-safe CSV."""
    learners = sorted(
        (membership.learner for membership in load_active_memberships(cohort, cohort.site_id)),
        key=lambda learner: learner_sort_key(learner.user),
    )
    buffer = io.StringIO()
    buffer.write(UTF8_BOM)
    writer = csv.writer(buffer)
    writer.writerow(["Name", "Email", "Role", "Status"])
    for learner in learners:
        writer.writerow([
            escape_csv_formula(learner.user.display_name),
            escape_csv_formula(learner.user.email),
            "Learner",   # a label for the reader, not a permission role
            learner_status(learner).label,
        ])
    for user, role_display_name in cohort_educators(cohort):
        writer.writerow([
            escape_csv_formula(user.display_name),
            escape_csv_formula(user.email),
            escape_csv_formula(role_display_name),
            "",
        ])
    response = HttpResponse(buffer.getvalue(), content_type="text/csv; charset=utf-8")
    response["Content-Disposition"] = content_disposition_header(
        as_attachment=True, filename=_members_csv_filename(cohort)
    )
    return response


def _members_csv_filename(cohort: Cohort) -> str:
    organisation = slugify(cohort.organisation.name, allow_unicode=True)
    name = slugify(cohort.name, allow_unicode=True)
    return f"{organisation}-{name}-members-{timezone.localdate():%Y-%m-%d}.csv"
```

The body is built in memory rather than streamed: `panel_framework/views.py`'s
`_export_response` explains that a streamed body is read after the site thread-local is cleared,
and a cohort's membership list is small. `learner_status` reads only the loaded `User` row
(`last_login`, password), so no query runs per row.

**`educator_interface/views.py`.** Extract the organisation attach step out of `interface()` so
pages and file routes resolve a request the same way, then a cohort resolver for the file routes:

```python
def _attach_organisation(request: HttpRequest, organisation_slug: str) -> Organisation:
    """Resolve and authorise the organisation once and put it on the request.

    Everything the section configs list in required_request_attrs is set
    here, so a page and a file download start from the same scoped request.
    """
    organisation = _resolve_organisation(cast(User, request.user), organisation_slug)
    scoped_request = cast(OrganisationScopedRequest, request)
    scoped_request.organisation = organisation
    scoped_request.panel_scope_name = organisation.name
    scoped_request.panel_url_kwargs = {"organisation_slug": organisation.slug}
    return organisation


def _scoped_cohort(request: HttpRequest, organisation_slug: str, cohort_pk: str) -> Cohort:
    """The cohort named in a file URL, after the organisation and cohort checks a page runs."""
    _attach_organisation(request, organisation_slug)
    return cast(Cohort, CohortConfig.get_instance_view(request, cohort_pk).instance)


@login_required
```

## Slice 2: generate and download the PDF from the cohort page

**Behaviour.** The cohort page gains a Report tab holding a downloads panel. An educator with
`download_cohort_report` generates the report there, watches it finish, and downloads it. Anyone
who can see the tab gets the cohort members CSV link.

### `reports/services.py` (new)

Extracted from `reports/views.py`, which then calls these. The admin tests pass unchanged.

```python
IN_FLIGHT_STATUSES = (GeneratedReport.STATUS_PENDING, GeneratedReport.STATUS_RUNNING)


@dataclasses.dataclass(frozen=True)
class CohortReportState:
    in_flight: GeneratedReport | None
    ready: GeneratedReport | None
    failed: GeneratedReport | None   # newer than `ready`, or None


def has_inflight_report(cohort: Cohort) -> bool:
    """Friendly pre-check only, for the common case.

    A check-then-act pre-check loses a genuine race; the partial unique index
    behind request_cohort_report's IntegrityError clause is the guard that
    holds under concurrent requests.
    """
    return GeneratedReport.objects.filter(cohort=cohort, status__in=IN_FLIGHT_STATUSES).exists()


def request_cohort_report(cohort: Cohort, user: User) -> GeneratedReport | None:
    """Start a report for the cohort, or return None when one is already being generated."""
    if has_inflight_report(cohort):
        return None
    try:
        with transaction.atomic():
            report = GeneratedReport.objects.create(
                cohort=cohort,
                # Explicit, not thread-local-derived: this must equal the value
                # the enqueued task filters every one of its queries on,
                # independent of ambient site context. A deliberate, documented
                # exception to the usual "site_id is never set by hand" rule.
                site_id=cohort.site_id,
                requested_by=user,
            )
            transaction.on_commit(lambda: default_task_backend.enqueue(
                _generate_cohort_report_task, args=[str(report.pk), cohort.site_id], kwargs={}
            ))
    except IntegrityError:
        return None
    return report


def report_file_response(report: GeneratedReport) -> FileResponse:
    """Stream a ready report as a private attachment; anything else is a 404."""
    # The body of download_report_view from the status check down, unchanged:
    # the slugified filename, the FileNotFoundError 404 and the Cache-Control header.


def latest_cohort_reports(cohort: Cohort) -> CohortReportState:
    """The in-flight report, the newest ready one, and a failure newer than that."""
    reports = GeneratedReport.objects.filter(cohort=cohort).select_related("requested_by")
    newest_by_status: dict[str, GeneratedReport] = {}
    for report in reports.filter(status__in=IN_FLIGHT_STATUSES).order_by("-requested_at")[:1].union(
        reports.filter(status=GeneratedReport.STATUS_READY).order_by("-requested_at")[:1],
        reports.filter(status=GeneratedReport.STATUS_FAILED).order_by("-requested_at")[:1],
    ):
        newest_by_status.setdefault(report.status, report)
    in_flight = next((newest_by_status[s] for s in IN_FLIGHT_STATUSES if s in newest_by_status), None)
    ready = newest_by_status.get(GeneratedReport.STATUS_READY)
    failed = newest_by_status.get(GeneratedReport.STATUS_FAILED)
    if failed is not None and ready is not None and failed.requested_at <= ready.requested_at:
        failed = None
    return CohortReportState(in_flight=in_flight, ready=ready, failed=failed)
```

`select_related` is applied to the base queryset before the three filters so every member of the
union selects the same columns. `reports/views.py` keeps its messages and redirects; its
`generate_report_view` calls `request_cohort_report` and reads `None` as "already being
generated", and `download_report_view` calls `report_file_response` after its own `can` check.

> **Assumed default:** `latest_cohort_reports` is the one `union()` the spec describes, with the
> newer-than-ready rule applied in Python. Why: the spec names the shape, and a test asserts
> `requested_by` is not re-queried. To change: the services section above.

### Report tab (`reporting.py`)

```python
REPORT_POLL_SECONDS = 3
IN_FLIGHT_STALL = timedelta(minutes=10)
DOWNLOAD_COHORT_REPORT = "freedom_ls_learner_management.download_cohort_report"


def is_stalled(report: GeneratedReport | None, now: datetime) -> bool:
    """An in-flight report older than the stall window, which stops the page polling for it."""
    return report is not None and now - report.requested_at > IN_FLIGHT_STALL


def render_region(panel: Panel) -> HttpResponse:
    """A panel's refresh region on its own, the fragment a targeted swap replaces."""
    return render(panel.request, panel.region_template_name or panel.template_name, panel.get_context_data())


class GenerateReportAction(PanelAction):
    label = "Generate PDF report"
    action_name = "generate_report"
    capability = DOWNLOAD_COHORT_REPORT
    renders_in_footer = False   # the downloads region draws its own button from row_action_urls

    def handle_submit(self, ctx: PanelContext) -> HttpResponse:
        request_cohort_report(cast(Cohort, ctx.instance), cast(User, ctx.request.user))
        # A lost race returns None, and the region reads the in-flight row either
        # way, so the losing request sees the same state the winner does.
        return render_region(CohortReportDownloadsPanel(ctx))


class CohortReportDownloadsPanel(Panel):
    model = Cohort
    title = "Downloads"
    template_name = "educator_interface/panels/cohort_report_downloads.html"
    region_template_name = "educator_interface/panels/cohort_report_downloads_region.html"

    def get_actions(self) -> list[PanelAction]:
        return [GenerateReportAction()]

    def get_context_data(self) -> dict[str, object]:
        cohort = cast(Cohort, self.instance)
        request = cast("OrganisationScopedRequest", self.request)
        url_kwargs = {**request.panel_url_kwargs, "cohort_pk": str(cohort.pk)}
        state = latest_cohort_reports(cohort)
        context = super().get_context_data()
        context.update(
            cohort=cohort,
            can_download=can(request.user, DOWNLOAD_COHORT_REPORT, cohort),
            csv_url=reverse("educator_interface:cohort_members_csv", kwargs=url_kwargs),
            in_flight=state.in_flight,
            is_stalled=is_stalled(state.in_flight, timezone.now()),
            ready=state.ready,
            pdf_url=_pdf_url(url_kwargs, state.ready),
            failed=state.failed,
            poll_seconds=REPORT_POLL_SECONDS,
        )
        return context


def _pdf_url(url_kwargs: dict[str, str], ready: GeneratedReport | None) -> str:
    if ready is None:
        return ""
    return reverse("educator_interface:cohort_report_download", kwargs={**url_kwargs, "report_pk": str(ready.pk)})


class CohortReportStack(PanelStack):
    title = "Report"
    children = {"downloads": CohortReportDownloadsPanel}
```

```python
def _completion_statistics(completion_values: list[int]) -> CompletionStats:
    """Median and the two status counts, from one list of recomputed completions."""
    return CompletionStats(
        median_completion=round(statistics.median(completion_values)) if completion_values else 0,
        not_started_count=sum(1 for value in completion_values if progress_status(value) is ProgressStatus.NOT_STARTED),
        complete_count=sum(1 for value in completion_values if progress_status(value) is ProgressStatus.COMPLETE),
    )


def gather_cohort_progress(cohort_id: str, site_id: int) -> CohortProgressData:
    """The cohort's progress figures and at-risk flags, without the answer loaders."""
    now = timezone.now()
    core = _load_progress_core(cohort_id, site_id)
    summaries = [
        _summarise(_build_learner_detail(learner_id, core.roster, core.catalogue, core.progress, {}, now))
        for learner_id in core.roster.learner_ids
    ]
    return build_progress_data(core.cohort.pk, core.cohort.name, now, summaries)


def build_progress_data(
    cohort_id: UUID, cohort_name: str, generated_at: datetime, summaries: list[LearnerSummary]
) -> CohortProgressData:
    """Every figure derived from the learner rows, so a reader that drops rows rebuilds them here."""
    completions = [summary.completion_percentage for summary in summaries]
    stats = _completion_statistics(completions)
    return CohortProgressData(
        cohort_id=cohort_id,
        cohort_name=cohort_name,
        generated_at=generated_at,
        learners=summaries,
        attention_list=_build_attention_list(summaries),
        cohort_size=len(summaries),
        mean_completion=round(statistics.fmean(completions)) if completions else None,
        median_completion=stats.median_completion,
```

```python
SCHEMA_VERSION = 1   # bump whenever a cached dataclass changes shape

def _cache_key(site_id: int, cohort_id: UUID, kind: str) -> str:
    return f"reports:screen:{SCHEMA_VERSION}:{site_id}:{cohort_id}:{kind}"


def _active_member_ids(cohort: Cohort) -> set[UUID]:
    return set(load_active_memberships(cohort, cohort.site_id).values_list("learner_id", flat=True))


def cached_cohort_progress(cohort: Cohort, *, refresh: bool = False) -> CohortProgressData:
    """The cohort's progress gather, at most REPORTS_SCREEN_CACHE_SECONDS old.

    Learners removed since the gather ran are dropped on every read and the
    figures rebuilt, so a removal shows at once while the gather itself waits
    for expiry. The cached data is permission-neutral: callers authorise first.
    """
    key = _cache_key(cohort.site_id, cohort.pk, "progress")
    data = None if refresh else cache.get(key)
    if data is None:
        # ReportTooLargeError propagates from here and nothing is cached.
        data = gather_cohort_progress(str(cohort.pk), cohort.site_id)
        cache.set(key, data, timeout=config.REPORTS_SCREEN_CACHE_SECONDS)
    return _trim_progress(data, _active_member_ids(cohort))


def _trim_progress(data: CohortProgressData, active_ids: set[UUID]) -> CohortProgressData:
    remaining = [learner for learner in data.learners if learner.learner_id in active_ids]
    if len(remaining) == len(data.learners):
        return data
    return build_progress_data(data.cohort_id, data.cohort_name, data.generated_at, remaining)
```

### Lazy panel bodies (`reporting.py`)

```python
LOADED_PARAM = "loaded"


class LazyBodyPanel(Panel):
    """A panel whose body costs a gather: the first render is a skeleton that fetches the body.

    get_loaded_context runs only on the fetch that carries loaded=1. It may
    raise ReportTooLargeError; the region then shows the message instead of a body.
    """

    template_name = "educator_interface/panels/lazy_panel.html"
    skeleton_shape = "text"
    skeleton_lines = 3

    @property
    def is_loaded(self) -> bool:
        return self.request.GET.get(LOADED_PARAM) == "1"

    def get_loaded_context(self) -> dict[str, object]:
        return {}

    def get_context_data(self) -> dict[str, object]:
        context = super().get_context_data()
        context.update(
            is_loaded=self.is_loaded,
            loaded_url=f"{self.ctx.base_url}?{LOADED_PARAM}=1",
            skeleton_shape=self.skeleton_shape,
            skeleton_lines=self.skeleton_lines,
        )
        if self.is_loaded:
            try:
                context.update(self.get_loaded_context())
            except ReportTooLargeError as error:
                context["too_large_message"] = str(error)
        return context
```

```python

class InlineFigures:
    """The two tiles that need no gather."""

    learner_count: int
    cohort_count: int


@dataclasses.dataclass(frozen=True)

    cohort: Cohort
    completion_percentage: int
    flags: list[AtRiskFlag]


@dataclasses.dataclass(frozen=True)
class FlaggedLearnerRow:
    learner_id: UUID
    full_name: str
    sort_key: tuple[str, str]
    lowest_completion: int
    cohorts: list[CohortFlags]


@dataclasses.dataclass(frozen=True)
class CohortProgressRow:
    cohort: Cohort
    mean_completion: int | None
    learner_count: int
    flagged_count: int


@dataclasses.dataclass(frozen=True)
class ExcludedCohort:
    cohort: Cohort
    learner_count: int


@dataclasses.dataclass(frozen=True)
class GatheredFigures:
    average_progress: int | None
    attention_count: int                     # distinct flagged learners, uncapped
    attention_rows: list[FlaggedLearnerRow]  # the first ATTENTION_LIST_MAX by lowest completion
    cohort_rows: list[CohortProgressRow]
    excluded: list[ExcludedCohort]
    figures_as_of: datetime | None


def visible_active_cohorts(request: OrganisationScopedRequest) -> QuerySet[Cohort]:
    return cohorts_visible_to(request.user, request.organisation).filter(is_active=True).order_by("name")


def inline_figures(cohorts: QuerySet[Cohort]) -> InlineFigures:
    learners = CohortMembership.objects.filter(cohort__in=cohorts, learner__is_active=True).aggregate(
        n=Count("learner_id", distinct=True)
    )["n"]
    return InlineFigures(learner_count=learners, cohort_count=cohorts.count())


def _gather_visible(cohorts: list[Cohort]) -> tuple[list[tuple[Cohort, CohortProgressData]], list[ExcludedCohort]]:
    gathers, excluded = [], []
    for cohort in cohorts:
        try:
            gathers.append((cohort, cached_cohort_progress(cohort)))
        except ReportTooLargeError:
            excluded.append(ExcludedCohort(cohort, cohort_learner_count(cohort)))
    return gathers, excluded


def _average_progress(gathers) -> int | None:
    """Each learner once, at the mean of their completion across the cohorts gathered."""
    completions: dict[UUID, list[int]] = defaultdict(list)
    for _cohort, data in gathers:
        for learner in data.learners:
            completions[learner.learner_id].append(learner.completion_percentage)
    if not completions:
        return None
    return round(statistics.fmean(statistics.fmean(values) for values in completions.values()))


def _flagged_learner_rows(gathers) -> list[FlaggedLearnerRow]:
    by_learner: dict[UUID, FlaggedLearnerRow] = {}
    for cohort, data in gathers:
        for learner in data.learners:
            if not learner.flags:
                continue
            entry = CohortFlags(cohort, learner.completion_percentage, learner.flags)
            row = by_learner.get(learner.learner_id)
            by_learner[learner.learner_id] = (
                FlaggedLearnerRow(learner.learner_id, learner.full_name, learner.sort_key, learner.completion_percentage, [entry])
                if row is None
                else dataclasses.replace(row, lowest_completion=min(row.lowest_completion, learner.completion_percentage), cohorts=[*row.cohorts, entry])
            )
    return sorted(by_learner.values(), key=lambda row: (row.lowest_completion, row.sort_key))


def _cohort_rows(gathers) -> list[CohortProgressRow]:
    rows = [
        CohortProgressRow(cohort, data.mean_completion, data.cohort_size, sum(1 for learner in data.learners if learner.flags))
        for cohort, data in gathers
    ]
    # An empty cohort has no mean, so it sorts after every cohort that has one.
    return sorted(rows, key=lambda row: (row.mean_completion is None, row.mean_completion or 0, row.cohort.name))


def gathered_figures(cohorts: list[Cohort]) -> GatheredFigures:
    gathers, excluded = _gather_visible(cohorts)
    flagged = _flagged_learner_rows(gathers)
    return GatheredFigures(
        average_progress=_average_progress(gathers),
        attention_count=len(flagged),
        attention_rows=flagged[:ATTENTION_LIST_MAX],
        cohort_rows=_cohort_rows(gathers),
        excluded=excluded,
        figures_as_of=min((data.generated_at for _cohort, data in gathers), default=None),
    )
```

The cap disclosure reads `shown=attention_rows|length` and `total=attention_count`.

## Slice 5: the Report tab body

**Behaviour.** The Report tab renders the gathered report data on screen, in the PDF's order,

### `reports/screen_cache.py`

```python
def cached_cohort_report(cohort: Cohort, *, refresh: bool = False) -> CohortReportData:
    # Same shape as cached_cohort_progress with kind "report" and
    # gather_cohort_report_data(str(cohort.pk), cohort.site_id).
    return _trim_report(data, _active_member_ids(cohort))


def _trim_report(data: CohortReportData, active_ids: set[UUID]) -> CohortReportData:
    """Drop rows of learners no longer in the cohort and rebuild every figure that counts them.

    The quiz confusion blocks are left as gathered: they are cohort-wide
    tallies of first attempts, and recounting them needs the answer rows the
    cache never held, so they refresh with the entry.
    """
    learners = [learner for learner in data.learners if learner.learner_id in active_ids]
    if len(learners) == len(data.learners):
        return data
    stats = _completion_statistics([learner.completion_percentage for learner in learners])
    return dataclasses.replace(
        data,
        courses=[_trim_course(section, active_ids) for section in data.courses],
        learners=learners,
        attention_list=_build_attention_list(learners),
        cohort_size=len(learners),
        median_completion=stats.median_completion,
        not_started_count=stats.not_started_count,
        complete_count=stats.complete_count,
    )


def _trim_course(section: CourseSection, active_ids: set[UUID]) -> CourseSection:
    return dataclasses.replace(
        section,
        learner_rows=[row for row in section.learner_rows if row.learner_id in active_ids],
        summary_tables=[
            dataclasses.replace(table, rows=[row for row in table.rows if row.learner_id in active_ids])
            for table in section.summary_tables
        ],
    )
```

`_completion_statistics` and `_build_attention_list` are imported from `gather.py` for this; they
become public (`completion_statistics`, `build_attention_list`) if the implementer prefers not
to import underscored names across modules.

> **Assumed default:** removed learners are trimmed from a cached entry on read, as the spec
> describes, rather than keying the cache on the active-member set. Why: the spec chose it, and it
> keeps a membership change from re-running a gather that can take seconds. To change: replace
> `_trim_*` with the member ids folded into `_cache_key`.

```python
class RegistrationIds(NamedTuple):
    cohort: list[UUID]
    individual: list[UUID]


def _registration_ids(
    registrations: Sequence[CohortCourseRegistration | LearnerCourseRegistration],
) -> RegistrationIds:
    """The grants the loaders answer for, split by the column each kind is stored in."""
    ...


def _registration_filter(record_path: str, ids: RegistrationIds) -> Q:
    """Rows whose course progress record was minted by one of the registrations.

    record_path is the lookup path to the record, e.g. "course_progress"; empty
    when the queryset is CourseProgress itself.
    """
    path = f"{record_path}__" if record_path else ""
    return Q(**{f"{path}cohort_registration__in": ids.cohort}) | Q(**{f"{path}learner_registration__in": ids.individual})
```

`load_topic_progress_rows` (`"course_progress"`), `load_form_progress_rows` and
`load_first_attempt_ids` (`"course_attempt__course_progress"`) apply the filter in place of the
bare `cohort_registration__in`. The cohort gather passes only cohort registrations, so its queries
are unchanged in effect.

The indexes gain one way to choose their key:

```python
type ProgressKey = Literal["learner", "course_progress"]
```

`load_topic_progress_rows(..., keyed_by: ProgressKey = "learner")` selects
`course_progress__learner_id` or `course_progress_id` as the first `values_list` column, and
`fold_form_progress_rows(rows, keyed_by: ProgressKey = "learner")` reads
`fp.course_attempt.course_progress.learner_id` or `fp.course_attempt.course_progress_id`
(`course_attempt` is already `select_related`). `load_progress_index` passes `keyed_by` through.
A one-line note on `TopicProgressIndex` and `FormProgressIndex` says the `*_by_learner` maps are
keyed by course progress record when the loader was asked to.

```python
@dataclasses.dataclass(frozen=True)
class CourseRiskInput:
    """One course's view of a learner, in the shape the at-risk rules read."""

    has_any_progress: bool
    last_completed_at: datetime | None
    report_generated_at: datetime
    quiz_results: list[QuizResult]


def gather_learner_course_details(
    learner: Learner,
    registrations: Sequence[LearnerCourseRegistration | CohortCourseRegistration],
    site_id: int,
) -> list[LearnerCourseDetail]:
    """One entry per registration, in the order given, keyed by the registration's course progress record.

    A learner holding one course through a cohort and individually has two
    records, and each registration reads only its own.
    """
    now = timezone.now()
    catalogue = build_course_catalogue(registrations)
    ids = _registration_ids(registrations)
    record_id_by_registration = {
        cohort_registration_id or learner_registration_id: record_id
        for record_id, cohort_registration_id, learner_registration_id in CourseProgress.objects.filter(
            _registration_filter("", ids), learner=learner, site_id=site_id
        ).values_list("id", "cohort_registration_id", "learner_registration_id")
    }
    progress = load_progress_index(site_id, registrations, [learner.pk], catalogue, keyed_by="course_progress")
    return [
        _build_course_detail(registration, record_id_by_registration.get(registration.pk), catalogue, progress, now)
        for registration in registrations
    ]


def _build_course_detail(
    registration: LearnerCourseRegistration | CohortCourseRegistration,
    record_id: UUID | None,
    catalogue: CourseCatalogue,
    progress: ProgressIndex,
    now: datetime,
) -> LearnerCourseDetail:
    items = catalogue.course_items[registration.course_id]
    quiz_forms = [item for item in items if isinstance(item, Form) and item.strategy == FormStrategy.QUIZ]
    if record_id is None:
        # No course progress record yet: nothing to look up, so the entry is
        # built as not started rather than searching the indexes for nothing.
        completed_count, total_count, last_title, last_at = 0, len(items), None, None
        completed_items, quiz_results, has_any_progress = [], [], False
    else:
        completed_count, total_count = _completion_counts(items, record_id, progress)
        last_title, last_at = _latest_completion(items, record_id, progress)
        completed_items = _completed_items(items, record_id, progress)
        quiz_results = [r for r in (_quiz_result_for(record_id, form, progress.forms) for form in quiz_forms) if r is not None]
        has_any_progress = record_id in progress.learner_ids_with_any_progress
    completion = _completion_percentage(completed_count, total_count)
    risk_input = CourseRiskInput(has_any_progress, last_at, now, quiz_results)
    return LearnerCourseDetail(
        course_id=registration.course_id,
        course_title=registration.course.title,
        cohort_name=registration.cohort.name if isinstance(registration, CohortCourseRegistration) else None,
        completion_percentage=completion,
        completed_item_count=completed_count,
        total_item_count=total_count,
        completed_items=completed_items,
        quiz_results=quiz_results,
        last_completed_title=last_title,
        last_completed_at=last_at,
        flags=_evaluate_at_risk_flags(risk_input),
        progress_status=progress_status(completion),
    )
```

`_completion_counts`, `_latest_completion`, `_completed_items` and `_quiz_result_for` keep their
`UUID` key parameter; the no-record branch above is what keeps `None` out of them. The query
count is the record lookup, the two progress loads and the catalogue traversal, fixed by the
courses' structure. The cohort registrations passed in need `select_related("cohort", "course")`,
which `registrations_with_progress_for_learner` already does.
