### Slice 1: stepper restyle

**Behaviour.** The three steps render as numbered markers with labels; a completed step's marker
shows the `check` icon; the current step is emphasised by weight and colour; below `sm` the labels

**Files.** `partials/import_stepper.html` only.

```python
class FormatRow(NamedTuple):
    name: str
    requirement: str
    description: str
    example: str


def _format_rows(cohort: Cohort | None) -> list[FormatRow]:
    """One row per accepted column, in header order. On a cohort import the
    cohort column is never read, so its row says so instead of describing it."""
    rows = []
    for index, name in enumerate(HEADERS):
        description = HEADER_DESCRIPTIONS[name]
        if cohort is not None and name == "cohort":
            description = f"Ignored: everyone goes into {cohort.name}."
        rows.append(
            FormatRow(
                name=name,
                requirement="Required" if name == "email" else "Optional",
                description=description,
                example=FULL_EXAMPLE_ROW[index],
            )
        )
    return rows
```

The CSP build accepts a property name, a negated property name or a method name in a directive,
never a compound expression, so the three visibility states are `dragging` (a property) and the
methods `showPrompt` and `showFile`. `zoneClass` returns the whole idle or drag-over set of border
and background classes, so neither state relies on class order to win. `dragover` reuses `enter`,
which only sets a flag, so repeated firing changes nothing; the `.prevent` on it is what lets the
`drop` event fire.

`alpine-components.js`, inside the `alpine:init` listener after `localTime`:

```javascript
// Drop zone around a native file input (learner_import_upload.html). The
// label stays a working label for the input, so clicking it or tabbing to
// the input and pressing Enter opens the picker without any of this.
// Dragging adds the drop path: the dropped file is handed to the input
// through a DataTransfer, so the form submits it like a picked one.
Alpine.data("fileDropZone", () => ({
    dragging: false,
    fileName: "",
    fileSize: "",
    init() {
        this.readInput();
    },
    input() {
        return this.$el.querySelector('input[type="file"]');
    },
    enter() {
        this.dragging = true;
    },
    // dragleave fires when the pointer crosses into a child of the label
    // too; only a leave to outside the label ends the drag-over state.
    leave(event) {
        if (!this.$el.contains(event.relatedTarget)) this.dragging = false;
    },
    drop(event) {
        this.dragging = false;
        const files = event.dataTransfer && event.dataTransfer.files;
        if (!files || files.length === 0) return;
        const transfer = new DataTransfer();
        transfer.items.add(files[0]);
        const input = this.input();
        input.files = transfer.files;
        input.dispatchEvent(new Event("change", { bubbles: true }));
    },
    readInput() {
        const file = this.input().files[0];
        this.fileName = file ? file.name : "";
        this.fileSize = file ? this.formatSize(file.size) : "";
    },
    formatSize(bytes) {
        let size = bytes;
        for (const unit of ["bytes", "KB", "MB"]) {
            if (size < 1024 || unit === "MB") {
                return unit === "bytes" ? `${size} ${unit}` : `${size.toFixed(1)} ${unit}`;
            }
            size /= 1024;
        }
    },
    hasFile() {
        return this.fileName !== "";
    },
    showPrompt() {
        return !this.dragging && !this.hasFile();
    },
    showFile() {
        return !this.dragging && this.hasFile();
    },
    zoneClass() {
        return this.dragging
            ? "border-solid border-primary bg-surface"
            : "border-dashed border-border bg-surface-2";
    },
}));
```

No listener is added by hand, so there is nothing to remove in `destroy`. A `sr-only` input still
receives focus, so `focus-within:ring-2` on the label gives the focus ring. The label's `min-h-44`
keeps the touch target well above 44px.
