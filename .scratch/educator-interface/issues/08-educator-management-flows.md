# Educator management flows

Type: grilling
Status: open
Blocked by: 05

## Question

How do educators add, remove and re-scope other educators (TAs, organisation staff, instructors) inside the educator interface? Cover: account creation vs an existing user, which role at which scope, confirmation on escalation or removal, how role descriptions are shown, and how a person who is both an educator and a learner in the same organisation is handled.
